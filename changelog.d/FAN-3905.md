## Improvements

- Added bounded, privacy-aware local crash incident reports with Godot script
  backtraces, build identity, and the newest 50 class/weapon combat events.
- Strengthened redaction for authorization headers, bearer tokens, and quoted
  credential fields, including JSON-style authorization keys, before incident
  data is persisted.
- Redacted credential-bearing fields by key family (`client_secret`, cookies,
  `auth-token`, private keys, URL userinfo), Authorization-family values for
  any scheme in any letter case, and bare `<scheme> <credential>` forms, while
  a documented shape grammar keeps ordinary diagnostic prose such as
  `Basic attack.` or `Negotiate phase-change.` byte for byte.
- Preserved diagnostic Godot resource paths, user-data paths, URLs, and nearby
  punctuation while redacting Unix and Windows home paths.
- Added calibrated CPU-time profiling, additional credential formats, direct
  stack assertions, and real combat-signal regression coverage.
- Added a fixed baseline-only resolution gate so a noisy profiler cannot run or
  claim a new candidate comparison without first demonstrating 1% resolution.
- Removed clean-frame polling by coalescing incident flushes from the callback.
