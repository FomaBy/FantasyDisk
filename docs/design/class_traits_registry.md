# Class Traits Registry — канонический реестр особенностей классов

Canonical registry, resolves SCRUM-953; спорные решения приняты автономным PM-мандатом 2026-07-09.

Назначение: единый источник истины по уникальной особенности (class trait) каждого из
17 играбельных классов для волны редизайна SCRUM-894..952. Player-facing описания
(Hero Select `Особенность: <название> — <точный эффект>`, SCRUM-1064), кодекс и
тултипы берут trait ОТСЮДА.
Ни одно описание не финализируется по trait, которого нет в этой таблице.

Рабочие названия traits — черновые: копирайт-пасс SCRUM-952 может переименовать,
механика при этом не меняется без нового решения.

## Принципы выбора trait

1. Trait усиливает identity кита из редизайн-тикетов, а не живёт отдельно от него.
2. Описывается одной строкой и просто реализуется поверх текущих систем.
3. Не дублирует trait другого класса (разные оси: шанс-копия / скейл от дистанции /
   скейл от HP / сеть устройств / он-килл и т.д.).
4. Масштабируется без слома баланса: жёсткий кап, отсутствие рекурсии, либо
   фиксированный множитель.

## Hero Select projection (SCRUM-1064)

`ProgressionData.hero_select_dossier(class_id)` проецирует запись
`CLASS_TRAITS[class_id]` без ручной копии. Если запись существует, trait — первый
блок досье в формате `Особенность: <title> — <short_description>`, после него
идёт имя героя. Если будущий класс не имеет trait, весь блок скрывается без
пустой строки, и имя становится первым. Подробный `description` остаётся в
Codex; свободные `CHARACTER_CONFIGS.description/strengths/weaknesses` больше не
показываются в Hero Select.

SCRUM-1064 также сверил `ATTRIBUTE_RELEVANCE` с этими 17 traits и реальными
тремя оружиями каждого класса. Ключевые исправления: generic sustain Доктора
(`regeneration`, оба vampiric) теперь weak из-за `generic_sustain_blocked`;
crit chance Ассасина primary из-за 100%-капа/overflow; DoT Химика primary из-за
`Catalyst ×1.5`; `buff_power` Друида primary из-за прямого скейла Wild Force
Aura; defense Робота учитывает Armored Hull. Generic `damage` Тёмного мага
остаётся secondary из-за действующей per-hero damage-star прогрессии, хотя его
прямые оружейные каналы — magic/DoT. Личная мета Доктора также больше не
предлагает отключённые Plague Oath generic regen/vamp бонусы: её minor/technique
звёзды переведены на DoT, темп, health, support и ultimate, а hidden
«Горный госпиталь» начинает забег с половиной ultimate вместо неработающего
low-HP regen. Числа traits и оружия не менялись; все 51 weapon-пары прошли
balance harness после коррекции мета-профиля.

Статусы: `backlog` — trait определён в существующем Jira-тикете, ещё не реализован;
`new-ticket-needed` — решение принято этим реестром, implementation-тикета ещё нет
(заводит оркестратор, см. список ниже); `implemented` — trait в коде.

knockback + endurance×4 + leadership×3, ×`knockback_multiplier` артефакта
«Ударная тетива»), уроном НЕ скейлится, боссы/элиты — общий контроль-резист
×0.25 (`_control_resist_factor`), тест tests/ranger_kit_test.gd;

страйки атакующего не передают — дальнобой не отбрасывается). Импульс 760 при
декее 2400 px/s² даёт ≈120px смещения — за пределы типового contact_range,
контактная серия рвётся (windup сбрасывается). Таксономия —
`CombatTargetQuery.is_epic_displacement_immune`: боссы и главные элиты карты не
смещаются вовсе, мини-элиты волн (`epic_scale_profile == "mini_elite"`) отлетают
как обычные монстры; кулдаун 0.4с — документированный предохранитель от
физ/пафинг-раскачки (частота событий урона и так зажата i-frames 0.32с), тест
tests/knight_kit_test.gd;
Робот «Бронекорпус» (SCRUM-914, в паре с китом SCRUM-915/916/918) — запись в
`CLASS_TRAITS.robot` (`incoming_damage_multiplier: 0.8`), потребитель —
`Player.take_damage`: множитель применяется ПОСЛЕДНИМ, после dodge-ролла, блока
Рыцаря, absorb и defense (100 post-mitigation → 80, 5 → 4), ко ВСЕМ источникам,
идущим через `take_damage` (контакт, снаряды, удары элиток/боссов, хазарды и
тики poison_zone), статами НЕ скейлится; рантайм зажимает множитель полом 0.5
(анти-стакинг в иммунитет), худший суммарный кап митигации Робота ≈94% <
глобального гейта 98% (`global_survivability_balance_smoke`); ключ несёт только
Робот (другие классы не затронуты), тест tests/robot_kit_test.gd.
Новые traits волны добавляют свои записи в `CLASS_TRAITS` и переиспользуют
подходящий хук.

## Решения по 5 спорным классам (автономный PM-мандат, 2026-07-09)

### 1. berserk → «Ярость» (низкое HP → выше урон, кап +40%)

Классическая ярость берсерка идеально совпадает с identity «живёт в гуще боя — риск
велик, но и запас крови огромен» (SCRUM-895 сознательно не трогает механику класса,
только читаемость топора/молота — глобального trait там нет). Инфраструктура уже
есть: в `scripts/player.gd` низкий HP уже трекается для артефактов «Кровавый Рубеж» /
«Второе Дыхание» (`_low_hp_active`, SCRUM-500), так что реализация — один множитель
в исходящем уроне. Ни один другой класс не скейлится от собственного HP; артефакты
low-HP остаются стакующимся, но отдельным слоем.

РЕАЛИЗОВАН (SCRUM-1004): запись `CLASS_TRAITS.berserk` (`rage_damage_bonus_cap`
0.40); формула — единая точка `ProgressionData.class_rage_damage_bonus`:
бонус = кап × clamp(1 − health/max_health, 0, 1) — непрерывная линейная шкала
(полное HP → +0%, половина → +20%, пустое → ровно +40%), невалидные значения HP
зажимаются (отрицательное → кап, выше максимума / max<=0 → 0). Потребители —
`Player.rage_damage_multiplier`: `BerserkWeapon._rolled_damage` (все три оружия
кита, слой ПОСЛЕ обычных модификаторов урона/крита, ровно один раз за хит —
вторичные melee-эффекты наследуют dealt без повторного множения) и эхо-волна
ульты «Неистовство». Артефактные low-HP эффекты не тронуты (отдельный слой,
скейл живёт от порога 30%, trait — от непрерывной шкалы). Бюджет-зеркало:
`class_rage_expected_damage_factor` (матожидание missing_hp 0.30 ⇒ ×1.12) в
`estimate_weapon_budget_for_stats` — `budget_tuning_for` компенсирует кит.
Покрыт `tests/berserk_rage_trait_test.gd` + анти-runaway
`tests/berserk_dps_runaway_gate.gd`.

### 2. biologist → «Разбор образцов» (+20% прямого урона по заражённым)

SCRUM-896 задаёт identity «гибрид физ/маг/DoT: сначала заражай, потом дави» — trait
связывает обе оси кита: DoT-заражение (Spore Lens/Seed) делает врагов уязвимее к
прямым ударам (Injector-луч). Не дублирует Химика: тот усиливает сами тики (+50%
periodic), Биолог — прямой урон ПО заражённым; оси разные. Реализация простая —
проверка активного DoT от игрока в damage pipeline; фиксированный множитель не
ломает баланс и не требует новых статов.

### 3. guitarist → «Разогрев» (стек магического урона, пока не получает урона; сброс при ударе)

SCRUM-899 превращает Гитариста в магического кайтера-саммонера («бегай и расставляй
усилители», бас — для кайта); «Разогрев» напрямую награждает именно эту петлю: держи
дистанцию — концерт громче. Работает со всеми тремя оружиями и не делает `sound_amp`
обязательным (критерий из SCRUM-908 применён по аналогии). Кап +20% и полный сброс
при полученном ударе дают безопасный баланс-коридор; ни у кого больше нет no-hit-streak
оси. Магическая природа согласована с миграцией SCRUM-898/899.

РЕАЛИЗОВАН (SCRUM-1006, в паре с китом SCRUM-899): запись `CLASS_TRAITS.guitarist`
(`no_hit_magic_bonus_per_second` 0.02, `no_hit_magic_bonus_cap` 0.20), потребитель —
`Player.meta_damage_multiplier` только для magic-контекстов; сброс — квалифицированный
удар в `Player.take_damage` (полностью предотвращенные события — godmode/i-frames/
невидимость/уворот — стек не трогают, правило покрыто тестом); деплой-пульсы ампов
идут через владельца (ownership сохранён). Покрыт `tests/guitarist_kit_test.gd`.

### 4. dark_mage → «Тёмный распад» (убитые взрываются магическим AoE, без рекурсии)

Кит SCRUM-939..941 — сплошные area-взрывы (чейн-бурсты жезла, зеркальные AoE книги,
курс-тики черепа); он-килл взрыв превращает каждую смерть в продолжение чистки зоны и
усиливает фантазию «выжигает целые области, убивает раньше, чем дойдут». Запрет
рекурсии (жертвы взрыва не взрываются) повторяет проверенный анти-чейн паттерн
Солдата и держит trait в балансе. Ось «он-килл» не занята ни одним классом.

### 5. engineer → SCRUM-908 «Сеть мастерской» ПОДТВЕРЖДЁН (device-network)

Провизиональный trait из SCRUM-908 полностью согласуется с финальным китом
SCRUM-905..907: турели с боезапасом, орбитальные дроны и вечные мины — все три
устройства кормят сеть, сеть усиливает только устройства, Лидерство (главный стат
класса) поднимает кап. Встроенные предохранители тикета (мины со сниженным весом,
кап стеков) уже решают главный риск вечных мин. Замена не требуется — подтверждаю
«Workshop Network» как есть; выбор зафиксирован как PM-approved by autonomous mandate.

2. Biologist class trait «Разбор образцов» — РЕАЛИЗОВАН (SCRUM-1005, в паре с
