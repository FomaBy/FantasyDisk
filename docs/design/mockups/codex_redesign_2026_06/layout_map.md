# Codex Redesign — Layout Map (SCRUM-725, Phase 2)

Источник: `codex_mockup_layout.png` (OpenAI gpt-image-2, high, 1920×1088), утверждённый
композиционный мокап экрана «Кодекс». Ниже — точная карта зон, пропорций, 9-slice,
типографики, палитры и контраста для Фазы 3 (ассеты) и Фазы 4 (интеграция в
`scripts/ui_screens.gd`).

Все пропорции даны в долях от **базового холста 1920×1080** (`CODEX_V2_BASE_SIZE`).
Экран масштабируется целиком как единый layout: считать rect'ы от текущего
viewport через фактор `scale = min(vw/1920, vh/1080)` и центрировать (letterbox),
ЛИБО перейти на anchor/Container-подход (предпочтительно — устойчив к ресайзу).

Правила ресайза:
- Соотношение колонок **фиксировано** (nav:list:detail ≈ 0.20 : 0.27 : 0.485).
- Минимальные размеры панелей задать так, чтобы при `scale<1` (1280×720) 9-slice
  углы НЕ наезжали друг на друга (углы 48 px × 2 < min width).
- При произвольном ресайзе — letterbox по `min`-фактору (без растяжения пикселей),
  фон-бэкдроп покрывает весь viewport `cover` (см. §5).

## 2. Nav panel (левая колонка)
- Заголовок «CATEGORIES» (section title) сверху по центру, отступ 24 px.
- Вертикальный стек из **6 кнопок категорий**, равные высоты, gap ~16 px:
  Heroes · Monsters · Artifacts · Lore & Stats · Glossary · Ascension.
- Кнопка = `codex_pl_category_button` (NinePatch) + слева эмблема-иконка (64×64 в
  base), справа текст-лейбл. Высота кнопки ≈ (h_panel − title − 7·gap) / 6 ≈ 108 px.
- **Выбранное состояние**: золотая рамка + маркер-стрелка «▸» на правом крае
  (см. Monsters на мокапе). Невыбранные — приглушённая рамка.

## 3. List panel (центр)
- Заголовок = имя активной секции (напр. «MONSTERS»), section title.
- `ScrollContainer` с колонкой **entry-карточек** (`codex_pl_entry_card`, NinePatch),
  gap ~14 px, вертикальный скроллбар справа внутри рамки.
- Карточка (высота ≈ 132 px base): слева квадратный портрет-thumbnail (~96×96,
  рамка-инсет), справа — title-строка (card title) + 2 строки описания (card body).
- Hover/selected карточки — золотая подсветка рамки.

## 4. Detail panel (правая колонка)
- Заголовок = имя записи (напр. «WIGHT KING»), detail title по центру сверху.
- Крупный **портрет** (~16:9 бокс, ширина панели − 2·инсет, высота ~0.42 панели),
  рамка-инсет.
- Ряд **чипов-метаданных** (2–4 шт.): маленькая иконка + короткий лейбл, NinePatch
  чип. Пример: Undead · Boss · Bleakhold Catacombs · Threat: EXTREME.
- **Пергаментный инсет** (light parchment) с прокручиваемым body-текстом (dark ink),
  опциональная буквица (drop cap). Инсет = единственная светлая плашка на экране →
  единственное место тёмного текста.

## 5. Фон-бэкдроп
- `codex_pl_backdrop` рисуется под всеми панелями, `TextureRect` stretch = `keep_aspect_covered`
  (cover), `texture_filter = NEAREST`. Никакого растяжения по одной оси.
- Атмосферный, но приглушённый (тёмная библиотека/каземат + свечи + вигнетка).
- Shade-оверлей: **убрать** прежний 0.62-alpha; максимум мягкая вигнетка/град.
  0.20–0.30 по краям, чтобы центр фона читался, а панели оставались foreground.

## 6. 9-slice (рекомендуемые margin'ы источника, px в исходном арте)

| Элемент             | Corner margin | Примечание                                  |
|---------------------|---------------|---------------------------------------------|
| Nav/List/Detail panel | 48 px       | толстый орнамент углов, тянущаяся середина   |
| Header bar          | 40 px         | середина тянется по ширине                   |
| Category button     | 24 px         | компактная рамка                             |
| Entry card          | 20 px         | тонкая рамка                                 |
| Chip                | 16 px         | мелкий, углы малые                           |
| Back button         | 20 px         | почти квадрат, симметричный                  |
| Parchment inset     | 32 px         | рваные края пергамента в углах               |

Все рамки — `StyleBoxTexture`/`NinePatchRect`, `axis_stretch = STRETCH` (или TILE
для орнаментных полос), `texture_filter = NEAREST`. `expand_margin` не задавать так,
чтобы контент лез на орнамент (правило safe-area).

## 8. Палитра и контраст

| Токен                  | HEX      | rgb (0..1)         | Назначение                    |
|------------------------|----------|--------------------|-------------------------------|
| bg_deep                | #1A1512  | 0.102,0.082,0.071  | фон-бэкдроп (тёмная база)      |
| panel_fill             | #211A15  | 0.129,0.102,0.082  | заливка тёмных панелей         |
| frame_gold             | #B8934E  | 0.722,0.576,0.306  | рамки/орнамент                 |
| frame_gold_hi          | #D8B56A  | 0.847,0.710,0.416  | блики рамок/выбор              |
| text_cream             | #E8D6A8  | 0.910,0.839,0.659  | светлый текст по тёмному       |
| text_gold              | #E0BE6E  | 0.878,0.745,0.431  | заголовки/акцент               |
| parchment_fill         | #D8C9A0  | 0.847,0.788,0.627  | светлая плашка (инсет)         |
| ink_dark               | #2E2013  | 0.180,0.125,0.075  | тёмный текст ТОЛЬКО по plaque  |
| chip_fill              | #2A221B  | 0.165,0.133,0.106  | фон чипа                       |
| accent_crimson         | #B5342B  | 0.710,0.204,0.169  | «EXTREME»/опасность            |

Контраст (WCAG-приближённо):
- `text_cream` (#E8D6A8) на `panel_fill` (#211A15) → **≈ 12.5 : 1** (отлично).
- `text_gold` (#E0BE6E) на `panel_fill` → **≈ 10.5 : 1** (отлично).
- `ink_dark` (#2E2013) на `parchment_fill` (#D8C9A0) → **≈ 8.4 : 1** (хорошо).
- Крамольные старые цвета `CODEX_PL_CARD_TITLE_COLOR` (0.28/0.13/0.06) и
  `CODEX_PL_DETAIL_BODY_COLOR` (0.20/0.13/0.07) на тёмном фоне давали <2:1 —
  **заменяются** на `text_cream`/`text_gold`; тёмный текст переезжает на пергамент.
