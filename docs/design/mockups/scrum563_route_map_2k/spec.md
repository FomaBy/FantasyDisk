## Responsive Rules

- 1280x720: scale the 2K contract by 0.5; header `14,9,1252,55`, scroll viewport `14,70,1252,636`, node targets `44x44` visual minimum but click targets should remain at least current runtime size where possible.
- 1920x1080: scale by 0.75; header `21,14,1878,83`, scroll viewport `21,105,1878,954`.
- 2560x1440: use the listed base rectangles.
- 3840x2160: scale by 1.5; header `42,27,3756,165`, scroll viewport `42,210,3756,1908`.
- Horizontal scrolling stays disabled. Vertical scrolling is expected because the route canvas height is larger than the viewport.

## Interaction States

- Route node normal: quiet dark node with icon centered inside the 88x88 safe interior.
- Route node available: brighter worn-gold edge, no size shift.
- Route node locked: desaturated/dimmed, no layout shift.
- Route node completed/shop revisit: compact corner check mark inside badge-safe corner, not over the icon center.
- Tooltip hover: tooltip panel appears inside the declared top-right safe zone or clamps within viewport.
- FAB disabled/hidden: no click-blocking overlay over the map.
