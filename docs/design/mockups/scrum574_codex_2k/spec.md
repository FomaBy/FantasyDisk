# SCRUM-574 Codex 2K Redesign Spec

Jira: SCRUM-574
Owner/lane: flex-loop / Codex Design
Runtime screen: `CodexScreen` in `scripts/ui_screens.gd`
Base artboard: 2560x1440
Responsive targets: 1920x1080, 2560x1440, 3840x2160

## Source Mockup

OpenAI API generated mockup:
`docs/design/references/scrum574_codex_2k/codex_2k_mockup.png`

Annotated safe-zone preview:
`docs/design/previews/scrum574_codex_2k_safe_zones.png`

The mockup establishes the D&D + Dark Fantasy Dragon direction for Codex:
dark cathedral parchment, aged brass rails, restrained ruby accents, readable
three-column hierarchy, and visible frame ornament. Runtime does not use the
mockup as a full-screen atlas; it uses slot-exact transparent 2K frame assets.

## 2K Layout Contract

| Element | 2K rect / size | Runtime node | Content rule |
| --- | ---: | --- | --- |
| Main frame | `Rect2(32, 27, 2496, 1387)` | `CodexMainPanel` | Header, columns and back button stay inside the frame safe band. |
| Header title | `Rect2(149, 99, 1493, 85)` | `CodexHeaderTitle` | Text stays clear of top ornament and right utility button. |
| Back button | `Rect2(2245, 80, 168, 128)` | `CodexBackButton` | Arrow is centered in the empty button field, never on caps. |
| Navigation panel | `Rect2(96, 227, 405, 1163)` | `CodexNavPanel` | Tabs use `Rect2(117, 264, 344, 960)` as their content lane. |
| List panel | `Rect2(517, 227, 1113, 1163)` | `CodexContent` | Scrollable entry cards sit inside panel content margins. |
| Detail panel | `Rect2(1656, 227, 808, 1163)` | `CodexDetailPanel` | Portrait, chips and body text stay inside panel margins. |
| Detail portrait | `Rect2(1861, 301, 427, 400)` | `CodexDetailPortraitSlot` | Portrait art is cropped inside the empty field only. |
| Chip row | `Rect2(1731, 731, 648, 107)` | `CodexDetailChipRow` | Attribute chips stay in a single safe row above body text. |
| Entry card source | `963x147` | `CodexEntryCard` | Text and thumbnails use content margins `48/35/53/32`. |
| Tab button source | `333x115` | `CodexTab_*` | Labels use content margins `48/32/48/32`. |
