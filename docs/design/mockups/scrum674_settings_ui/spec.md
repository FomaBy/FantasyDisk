## Responsive Rules

- 1280x720: Settings modal remains centered and content panel stays above the
  bottom action row. Screen tab rows are dense; Apply/Revert use compact 240x72
  buttons in the same bottom row as Back, so they never push tab content onto
  frame decoration.
- 1920x1080: content panel has enough room for screen rows, pending hint, and
  buttons without scrolling. Sound sliders use compact width rather than the
  full content width.
- 2560x1440: modal scales to the 2K Settings contract, with tab switcher,
  content panel, and Back separated vertically.

## Interaction States

- Screen dropdowns update only pending values and mark the screen tab dirty.
- `SettingsApplyButton` applies pending monitor/resolution/window mode via
  `_apply_video_settings()`, persists settings, and refreshes the screen UI.
- `SettingsRevertButton` discards pending screen values and refreshes the screen
  UI without touching persisted values.
- Sound sliders and toggles remain immediate-apply through `AudioServer` and
  `user://settings.cfg`.
- Controls toggles/rebinds remain immediate-apply and persisted.
- Hover/focus/pressed/disabled states reuse existing texture-button metadata and
  must not change layout sizes.
