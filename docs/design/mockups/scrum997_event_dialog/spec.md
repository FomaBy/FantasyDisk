# SCRUM-997 — Event UI: иллюстрированный экран-диалог

Спека лейаута ДО имплементации (Required Change п.1). Экран события превращается
из центральной economy-панели в иллюстрированную встречу: полноэкранный арт
события, диалог-панель СПРАВА, ровно три карточки выбора ВНИЗУ.

Контракт узлов (SCRUM-629/639/996 — имена сохраняются, лукапы в тестах
рекурсивные): `EventScreen` (корень), `ScreenBackground_event` (+ `…Fallback_event`),
`MenuPanel_event` (диалог-панель), `EconomyMenuScroll_event`, `EventContent`,
`EventTitle`, `EventStory`, `EventChoiceRow`, `EventChoiceButton0..2`,
`EventBackButton`, `EventContinueButton` (reveal).

## 1. Формулы зон

Все зоны считаются от текущего viewport `W×H` (`get_visible_rect().size`) при
построении экрана. `round()` везде, если не сказано иное.

| Параметр | Формула | 1280×720 | 1920×1080 | 2560×1440 |
| --- | --- | --- | --- | --- |
| `m` — внешний safe-margin | `clamp(H·0.025, 12, 36)` | 18 | 27 | 36 |
| `Hb` — высота нижней зоны | `clamp(H·0.22, 142, 320)` | 158 | 238 | 317 |
| `row_top` — верх нижней зоны | `H − m − Hb` | 544 | 815 | 1087 |
| `g` — гэп между карточками | `clamp(W·0.012, 10, 32)` | 15 | 23 | 31 |
| `gv` — гэп панель↔нижняя зона | `clamp(H·0.016, 8, 24)` | 12 | 17 | 23 |
| `Wd` — ширина диалог-панели | `clamp(W·0.36, 330, 980)` | 461 (36.0%) | 691 (36.0%) | 922 (36.0%) |
| `pad` — чип-пэддинг панели | `clamp(H·0.018, 12, 26)` | 13 | 19 | 26 |
| `bh` — высота кнопок-плит | `_atlas_action_button_height()` | 72 | 88 | 104 |

Нижняя зона занимает 21.9–22.0% высоты на трёх канонических разрешениях
(контракт 20–24%); на 4K клампы держат абсолютные размеры разумными.

## 2. Зоны в px (x, y, w, h)

### Диалог-панель `MenuPanel_event` (справа)

`(W − m − Wd, m, Wd, row_top − gv − m)` — от верха safe-зоны до верха нижнего ряда.

| Разрешение | Rect |
| --- | --- |
| 1280×720 | (801, 18, 461, 514) |
| 1920×1080 | (1202, 27, 691, 771) |
| 2560×1440 | (1602, 36, 922, 1028) |

- Стиль: `_atlas_chip_style(0.90, pad)` — полупрозрачная тёмная кожа
  (bg 0.085/0.070/0.055 a=0.90), латунный кант 2px, радиус 10. Контент-маржины
  чипа: `pad·1.4` по X, `pad` по Y.
- Внутри: `EconomyMenuScroll_event` (вертикальный скролл, custom_minimum_size =
  контент-зона панели) → `EventContent` (VBox) → `EventTitle` + `EventStory`.
- `EventTitle`: золото (0.96, 0.90, 0.68), к левому краю, autowrap,
  font `_readable_font_size(32, 0, 44)`; `custom_minimum_size.x` = ширина
  контент-зоны (страховка от распирания PanelContainer лейблом).
- Под титулом — латунная отчёркивающая линия 2px (ColorRect, цвет канта).
- `EventStory`: светлый текст (0.88, 0.92, 0.98), к левому краю, autowrap,
  font `_readable_font_size(17, 13, 22)`, вертикально сверху; длинный текст
  уходит в скролл, не раздувая панель.
- Иллюстрация слева НЕ перекрывается: панель прижата к правому краю, арт
  строит сюжет в левых ~55–60% кадра (манифест SCRUM-998, правая треть тёмная).

### Нижняя зона (полоса выборов)

Полоса `(m, row_top, W − 2m, Hb)`; внутри слева направо: ряд карточек
`EventChoiceRow`, гэп `g`, колонка «Назад» шириной 260.

`card_w = floor((W − 2m − 260 − 3g) / 3)`, `card_h = Hb`.

| Разрешение | `EventChoiceRow` rect | card_w×card_h | `EventBackButton` rect |
| --- | --- | --- | --- |
| 1280×720 | (18, 544, 969, 158) | 313×158 | (1002, 587, 260, 72) |
| 1920×1080 | (27, 815, 1582, 238) | 512×238 | (1633, 890, 260, 88) |
| 2560×1440 | (36, 1087, 2195, 317) | 711×317 | (2264, 1194, 260, 104) |

«Назад» — стандартная плита 260×`bh`, вертикально по центру полосы, прижата к
правому safe-краю (не на иллюстрации: нижняя четверть арта — тёмная UI-зона).

### Карточка выбора `EventChoiceButtonN`

База — `_make_economy_choice_card` (чип Атласа, `_atlas_card_pad` =
`clamp(card_h·0.10, 18, 34)`; контент-маржины X = pad·1.4). Контент-VBox, строки:

1. **Title** — золото, 15–17px (`_readable_font_size`), autowrap, по центру.
2. **Описание-интент** — светлый, 12–13px, autowrap, EXPAND_FILL,
   `OVERRUN_TRIM_ELLIPSIS` + пост-ready ужимка `_fit_economy_choice_card_content`
   (шрифт до 12, затем max_lines) — текст никогда не выходит за чип.
3. **Hint-строка** (НОВОЕ, узел `EventChoiceButtonNHint`) — строка
   награды/чека: `Проверка: <Стат> <N>` | видимая награда («+18 зол.»,
   «+1 Сила», «Лечение 20%», «Случайный артефакт», «Бой!») | для hidden —
   «Исход скрыт». Цвет-акцент (0.94, 0.80, 0.46), 12–14px, БЕЗ autowrap,
   `OVERRUN_TRIM_ELLIPSIS`, `custom_minimum_size.x` = ширина контент-зоны
   карточки (канон clip-строк: без min width метка в 0 не схлопнется —
   родитель VBox, но min width задаём явно для детерминизма).
4. **Action** — «Выбрать» / «N зол.» / «Рискнуть» (hidden), золото 14–15px.

### Состояния карточки (`_apply_atlas_choice_card_theme`)

| Состояние | Чип | Кант |
| --- | --- | --- |
| normal | a 0.86 | латунь (0.52, 0.41, 0.24) 2px |
| hover | a 0.90 | золото (0.93, 0.77, 0.40) |
| focus | a 0.90 | золото (0.93, 0.77, 0.40) |
| pressed | a 0.94, bg светлее | золото ярче (кант 2px) |
| disabled (не хватает золота) | a 0.80 | тусклый (0.36, 0.32, 0.26); тултип «Недостаточно золота…» |
| hidden-выбор | как normal | desc = `unknown_hint`, hint = «Исход скрыт», action = «Рискнуть» (SCRUM-996: цена — только в unknown_hint) |

### Reveal-состояние (SCRUM-996)

- `EventStory.text` → `outcome_text` (+ строка «Проверка <Стат> <N> —
  пройдена/провалена»); титул остаётся.
- `EventChoiceRow.visible = false`, `EventBackButton.visible = false`.
- `EventContinueButton` («В путь», плита 260×`bh`) — по центру нижней зоны:
  `((W−260)/2, row_top + (Hb−bh)/2)`: 720 → (510, 587); 1080 → (830, 890);
  1440 → (1150, 1194). Фокус на ней, соседи замкнуты на себя.

## 3. Фон per-event

- `ScreenBackground_event` (TextureRect, full rect, KEEP_ASPECT_COVERED):
  текстура `res://assets/backgrounds/events/event_bg_<event.id>.png`, если файл
  существует (файловая конвенция = манифест SCRUM-998, `ResourceLoader.exists`,
  кэш в `screen_background_cache` под ключом `event:<id>`; НЕ каскад if-ов).
- Фолбэк для незамапленных id — текущий `ui_backdrop_arcane_lab.png`
  (`SCREEN_BACKGROUND_PATHS["event"]`); пул 12 артов полностью совпадёт с пулом
  событий после SCRUM-995 (sudden_fork / sacrifice_altar совпадают уже).
  hazard/altar-узлы маршрута открывают события sudden_fork/sacrifice_altar по
  `event_id` — фон приходит из того же маппинга автоматически.
- `ScreenBackgroundReadableShade`: a = 0.14 поверх иллюстрации события
  (арт уже держит тёмные UI-зоны), a = 0.44 (как сейчас) поверх фолбэка.
- Маппинг живёт в `scripts/main.gd` (`event_background_path()`), UI лишь
  спрашивает путь.

## 4. Responsive-правила

- Все зоны — от фактического `W×H` (матрица гоняет 1152×648…3840×2160):
  формулы §1, никаких фикс-координат.
- Панель и полоса позиционируются якорями/оффсетами вручную (не контейнером):
  канон «фикс-зоны держит Control с ручными rect», PanelContainer не растёт от
  лейблов благодаря скроллу и min-width на лейблах.
- Шрифты через `_readable_font_size` (клампы в §2); строки карточек добиваются
  `_fit_economy_choice_card_content` (desc) и `TRIM_ELLIPSIS` (hint);
  полные тексты — в tooltip карточки.
- 1152×648 (минимум матрицы): m=16, Hb=143, card_w=272 — desc ужимается до
  1–2 строк, всё внутри чипов.
- 3840×2160: Wd=980 (кламп; читаемая ширина строки), Hb=320 — панель уже
  относительно, проверки матрицы для панели: ширина ≥ min(0.30·W, 980−1).

## 5. Фокус и ввод

- Цепь фокуса (SCRUM-477): выбираемые карточки слева направо → «Назад» (если
  активна) → замкнуто; стартовый фокус — первая выбираемая карточка.
- Reveal: фокус на `EventContinueButton`, все соседи — на себя.
- Escape — run-pause досье поверх экрана (SCRUM-530/890), событие живо под ним.
- Недоступные по золоту карточки — disabled + тултип с недостачей (как сейчас).

## 6. Правило рамок / орнамента

Полой атлас-рамы на событии нет — иллюстрация и есть «рама сцены». Контент
прижат к safe-зонам манифеста арта (правая треть + нижняя четверть тёмные),
ничего не лежит на орнаменте чипов: контент карточек/панели — только в
контент-маржинах их StyleBox (AGENTS.md hard-правило соблюдено конструкцией).

## 7. Матричный гейт (event-блок, обновляется вместе с лейаутом)

Инварианты вместо «всё в одной панели»: панель справа (left ≥ 0.55·W, ширина
0.30–0.42·W либо кламп-цель), контент/титул/story внутри контент-зоны панели;
ряд карточек в нижней полосе (top ≥ 0.60·H), не пересекает панель; ≥2 видимых
карточек с чип-стейтами (normal ≥0.8, hover — золотой кант ярче); hint-узел
внутри карточки; «Назад» в нижней полосе правее карточек; фон события есть;
`UpgradeFabButton` внутри `MenuPanel_event` запрещён.

## 8. Капчеры приёмки

`docs/design/previews/scrum997_event_dialog_<WxH>_<state>.png`,
state ∈ {normal, hidden, reveal}; оконный прогон (headless невалиден),
разрешения 1280×720 / 1920×1080 / 2560×1440. normal — sudden_fork (родной арт,
чек+награда+риск), hidden — sacrifice_altar с hidden-карточкой (синтетика до
ленда SCRUM-995), reveal — исход с outcome_text + строкой проверки.
