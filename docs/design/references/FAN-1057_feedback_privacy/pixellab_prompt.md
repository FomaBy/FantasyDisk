# FAN-1057 Feedback Privacy Overlay — PixelLab Prompt

Canonical tag/name: `fan1057_feedback_privacy_overlay`

Create a complete 16:9 FantasyDisk feedback/privacy modal art layer. The page
shows a centered, near-full-height D&D dark-fantasy window over a quiet dimmed
gameplay backdrop. Use restrained aged blackened steel, obsidian leather,
hairline antique-gold rails and very small dark-ruby dragon accents. Keep the
silhouette clean and modern enough for a utility/privacy form.

The supplied shape template is authoritative. Preserve every rounded rectangle
as an empty, calm content surface: title band, large report field, 16:9
screenshot preview, screenshot include/omit row, privacy disclosure block,
status/local-fallback row, send action and cancel action. Decoration may touch
only the outer modal rail and the gaps between zones. It must never enter an
interior rectangle.

Forbidden: letters, words, numbers, pseudo-runes, glyph-like marks, logos,
watermarks, baked checkbox marks, baked icons, characters, weapons, bright
yellow hover glow, parchment clutter, oversized dragon heads, one-axis-stretched
ornament, pale/white content surfaces. All labels, copy, screenshot, checkbox,
focus outlines and button states are live Godot Controls and are not part of
the generated raster.

Output is a design-reference art layer, not a runtime atlas. Source size is
672x378 (exact 16:9 within the PixelLab UI limit); it will be proportionally reviewed at
1920x1080 without changing geometry.
