# Референс интерфейса — кит панелей/рамок (от пользователя, 2026-06-13)

5 PNG (ChatGPT) — цельный UI-кит «тёмная кожа + золотая гравированная окантовка»,
прозрачный фон, угловые кронштейны и заклёпки. Это рамки ПАНЕЛЕЙ/ОКОН (дополняют
кнопочный кит Parchment&WaxSeal из SCRUM-147, который был только про кнопки).

Состав (имена сырые ChatGPT — Designer переименует к канону):
1. `(1)` — квадратная панель-рамка (для квадратных карточек/панелей).
2. `(2)` — широкая горизонтальная панель-рамка (для баров/плашек/заголовков).
3. `(3)` — квадратная рамка с золотой галочкой внутри (пример чекбокса/иконо-рамки/
   состояния «выбрано»).
4. `(4)` — длинная тонкая горизонтальная плашка (октагон, золотой кант) — для
   мелких баров/лейблов/кнопок-плашек.
5. `(5)` — крупная квадратная рамка-окно со светящимися золотыми угловыми
   кронштейнами (главная панель/окно).

Стиль: тёмная кожа/камень, золото гравировки, мягкое свечение по канту,
заклёпки в углах. 9-slice-пригодно (тянущаяся середина, неискажаемые углы).
