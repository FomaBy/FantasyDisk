## Полноэкранные референсы (пользователь, 2026-06-12 — «интерфейсы, которые я хочу в игре»)

- `screen_settings_full_reference.png` — ЭТАЛОН экрана с центральным окном:
  мокап «Настроек» НАШЕЙ игры — готическая рамка с красными самоцветами на
  тёмном соборном фоне с факелами, золотой заголовок-леттеринг, вкладки
  Экран/Звук/Управление (активная подсвечена), дропдауны в тонкой оправе,
  золотой чекбокс, широкая кнопка «Назад» снизу.
- `screen_necromantic_lab_reference.png` — компоновка сложного экрана
  (крафт/лаборатория, зелёный некро-кит): верхние вкладки, левая панель
  списка, центральная сцена-ритуал, правая панель предпросмотра, нижняя
  главная кнопка; валюты в верхнем правом углу.
- `screen_main_menu_reference.png` — ОЖИДАЕТСЯ от пользователя: главное меню
  (красно-золотой кит «Royal Crimson»): тронный зал с витражом и факелами,
  колонна кнопок по центру (рубиновые панели в золотой оправе), левая карточка
  «Continue» с превью, правая панель новостей, верхняя полоса профиль/валюты.
- `screen_spellbook_talents_reference.png` — ОЖИДАЕТСЯ: книга
  заклинаний/таланты (серебряно-фиолетовый готический кит): левый список школ,
  центральное дерево талантов с рангами узлов (3/3) на мистической печати,
  правая карточка деталей навыка, нижний хотбар 1-8. ПРЯМОЙ референс для
  древа умений меты (SCRUM-150).
- `screen_void_conclave_reference.png` — ОЖИДАЕТСЯ: космический атлас/мета
  (чёрно-фиолетовый Eldritch Void кит): центральная сеть узлов на фоне
  туманностей, левая панель прогресса ритуалов с таймерами, правая панель
  деталей узла с требованиями и кнопкой Unlock.

## Канон (зафиксировать в visual_style_assets.md при старте SCRUM-147)

Тёмный фон с глубиной (собор/подземелье в дымке, виньетка), painterly realism,
материальность (металл/камень/кость/пергамент/чешуя), угловые орнаменты,
тёплое золото текста на тёмном, акцентные самоцветы/свечения по роли экрана.
Разные киты — под разные роли экранов (бой/смерть/награда/магазин/магия).
