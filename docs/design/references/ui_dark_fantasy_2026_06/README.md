Референсы пользователя для НОВОГО UI-канона (SCRUM-147 и все downstream
UI-задачи). К каждой Codex-генерации интерфейса прикладывать релевантные листы
отсюда (железное правило арта).

## Полноэкранные референсы

- `screen_necromantic_lab_reference.png` — компоновка сложного экрана
  (крафт/лаборатория): верхние вкладки, левая панель списка, центральная
  сцена-ритуал, правая панель предпросмотра, нижняя главная кнопка; валюты в
  верхнем правом углу. Ориентир глубины фона и свечения.
- `screen_settings_full_reference.png` — ОЖИДАЕТСЯ (пользователь пришлёт
  повторно): полный мокап экрана «Настройки» — готическая рамка на тёмном
  соборном фоне, вкладки Экран/Звук/Управление, дропдауны в оправе, чекбокс,
  широкая кнопка «Назад». Это эталон того, как должны выглядеть ЭКРАНЫ с
  центральным окном.

## Канон (зафиксировать в visual_style_assets.md при старте SCRUM-147)

Тёмный фон с глубиной (собор/подземелье в дымке, виньетка), painterly realism,
материальность (металл/камень/кость/пергамент/чешуя), угловые орнаменты,
тёплое золото текста на тёмном, акцентные самоцветы/свечения по роли экрана.
Разные киты — под разные роли экранов (бой/смерть/награда/магазин/магия).
