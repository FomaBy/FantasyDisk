# Elementalist Kit Redesign — SCRUM-947/948/949/950 (2026-07-10)

Backend-отчёт волны редизайна Элементалиста: trait «Проводник стихий» + три
оружия. Канон механик — `docs/design/systems/characters_weapons.md` (раздел
«Class Trait: Элементалист» и Weapon Matrix); данный отчёт фиксирует
баланс-эвиденс до/после.

## Механики: до → после

| Слот | До | После |
| --- | --- | --- |
| trait | нет | «Проводник стихий»: каждый magic-tagged источник бонуса ×1.30 (bonus-effectiveness; +15% источник → +19.41% факт. после softcap; UI ≈ +20%). Порядок стакинга детерминирован, источники усиливаются ровно один раз (см. systems/characters_weapons.md) |
| `elementalist_orb_ring` | «Кольцо Трех Стихий»: орбита сфер вокруг героя, magic-тики (dm 0.88, int 1.42) | «Кольцо Четырёх Стихий» (SCRUM-948): квадратная AoE в точке каста (половина стороны 0.72×aoe_radius), 4 тика тремя каналами — магия (ролл) + физика (0.45×damage-канала) + ожог `four_elements_burn` (0.70×dot-оси) + отброс от центра каждый тик (dm 1.35, int 1.52) |
| `elementalist_prism_focus` | крест из двух коротких лучей у цели (dm 1.02, int 1.30) | полнокартный X-разлом (SCRUM-949): диагонали ±45° с плечами 4800px ≥ диагонали арены 4096×2304, пирс без спада, дедуп «один луч-хит на врага за каст», центр-AoE +0.55 ролла, телеграф 0.42с (dm 1.90, int 2.30) |
| `elementalist_meteor_core` | long-cast метеор 0.68с + веер из 5 осколков (dm 1.14, int 1.88) | тяжёлый одиночный метеор (SCRUM-950): полная задержка 1.30с (телеграф 42% + видимое падение), тяжёлый magic-взрыв с falloff 0.55, догорающая зона 5×0.62с по dot-оси со спадом по рангу; веер удалён. fire_interval 4.50 — максимальный среди ВСЕХ оружий игрока (следующий — homunculus_vial 4.0) (dm 2.90) |

Ниши кита: постоянный квадрат-ореол → редкий полнокартный X → сверхредкий
нюк+зона. Разные каденции (0.90/1.36/2.66с на базовой скорости атаки), разная
геометрия (квадрат у себя / линии через всю карту / точка), разные оси
скейла (три канала / чистая магия / магия+DoT).

- Класс-профиль не менялся: `damage_budget 1.08 / solo 1.00 / aoe 1.10`
  (elementalist остаётся aoe-профилем с хрупким survival).
- Тюнинг-множители 1.21/2.34/1.81 — внутри коридора [0.28..2.80] без
  клэмп-сатурации (гейт в `tests/elementalist_kit_test.gd`).
- Плата за trait: базлайн НЕ смещён trait'ом (на пустых run_modifiers и базовых
  статах усиление тождественно), «чуть ниже база» реализована сохранением
  growth-скаляра интеллекта 0.92 (дельта атрибута гасится на 8% до усиления
  ×1.30 → нетто ≈ ×1.196 к атрибутному росту магии) и самыми медленными
  интервалами кита; забеговый рост магии дополнительно держит глобальный
  softcap SCRUM-503, к которому trait применяется ПОСЛЕ сжатия.

## Артефакты класса (согласованы с новой базой, ключи mods сохранены)

- `fourth_ring`: физический канал квадрата +60% и +1 тик поля (extra-руны, кап +2).
- `prismatic_cross`: к X добавляется крест «+» на 60% силы луча (8-лучевая звезда).
- `meteor_heart`: интервал ×1.45, центр +55%, зона догорает на 2 тика дольше.

## Остаточный риск

- Живой CSV-арбитр (`character_balance_csv`) в объём прогона не входил
  (директива ускоренного QA; SIGABRT-флак известен) — аналитические гейты
  зелёные, comfort-band сходится.
- Отброс квадрата может выносить толпу из зоны до последних тиков — фактический
  AoE-throughput кольца в live чуть ниже идеализированной модели; компенсируется
  трёхканальным уроном и статус-ожогом, который продолжает тикать вне зоны.
