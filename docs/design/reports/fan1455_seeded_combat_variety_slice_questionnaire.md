## FAN-1455 interactive A/B questionnaire

Этот протокол предназначен для независимой QA. Он не содержит вымышленных
ответов: автоматическое evidence хранится отдельно в metrics JSON, а поля ниже
заполняются только после реального прохождения.

## Setup

- Candidate SHA/tree: записать из Multica handoff FAN-1455.
- Класс/profile: `melee`, `ranged` или `summon`; повторить хотя бы по одному
  разу для каждого profile.
- Seed: выбрать из `1455001..1455017` и записать здесь.
- A (control): обычный battle node без `Особый бой: тактическая цепочка`.
- B (slice): node с этой строкой в tooltip.
- Не менять aim setting между A и B; для mouse/right stick сделать отдельные
  пары.

## Pass rule

Интерактивное evidence считается положительным, если:

- хотя бы один из вопросов 1, 3 или 5 получает `4` или `5` с конкретным
  описанием изменённого решения;
- вопросы 2, 4, 6 и 7 не ниже `3`;
- на вопрос 8 ответ `Да`, на 9 и 10 — `Нет`;
- completion/death result не противоречит автоматическому профилю; любое
  противоречие прикладывается как seed/class/weapon repro и блокирует Go.

Сводный verdict QA: `Go / Go with risks / No-Go`
