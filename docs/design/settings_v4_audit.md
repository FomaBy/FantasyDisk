# Settings v4 — аудит размеров (до редизайна)

SCRUM-805, фаза 1. Замер фактических rect'ов всех элементов меню настроек (3
вкладки) на **1920×1080** и **2560×1440**. Дата: 2026-07-02.

## Метод

Значения выведены **аналитически** из кода `scripts/ui_screens.gd` (origin/dev
@7b445da) — формулы габаритов (`_settings_v2_modal_rect`,
`_settings_v2_tab_switcher_size`, `_settings_v2_switcher_top`,
`_settings_v2_content_panel_rect`, `_scaled_frame_margins_xy`) + объявленные
`custom_minimum_size` и `size_flags` контролов + правило `_readable_font_size`
(множитель читаемости на 1080p и 1440p = **1.45**, т.к. viewport_height ≥ 864 →
t=1.0). Проверено скриптом (все числа сходятся с формулами).

> Прим.: runtime-замер живыми rect'ами (дампер из
> `tests/ui_no_overlap_matrix_test.gd`) отложен на фазу 7 (верификация) — на
> момент фазы 1 файл `ui_screens.gd` был под активной live-правкой (открытый
> редактор Godot, блок character-select), гонять Godot рядом было небезопасно
> (анти-коллизия + риск OOM/убийства инстансов). Аналитический аудит
> детерминирован и достаточен для проектирования v4; фаза 7 подтвердит по факту.

## Найденные проблемы (список)

1. **Модалка 80% ширины экрана** (1536@1080 / 2048@1440) — пользователь считает
   слишком широкой/растянутой. Референс-цель: 55–60% (P1).
2. **OptionButton'ы (Монитор/Разрешение/Режим окна/Прицеливание) с
   EXPAND_FILL** — растягиваются с 520 до ~1000/~1438 px на весь ряд. Главный
   баг «растянутости» (P3).
3. **Action-кнопки в VBox без ограничения FILL** («Сбросить звук» 420,
   «Сбросить управление» 560, bind-кнопки) — тянутся на всю ширину контент-бокса
   (~1194/1632). (P3)
4. **Разнобой объявленных ширин** контролов: 520 / 420 / 560 / 300 / 170 / 180 —
   нет единой сетки (P4).
5. **Источник арта растянут**: main_modal 640×384 → ×2.4/×3.2; tab_switcher/
   content 688 → в ~1700–2048 px. Мыльные/жирные границы (P9).
6. **Контент-панель 82–83% ширины модалки** — одна очень широкая колонка,
   нет двухколоночной сетки `label|control` (P2).
7. Слайдеры звука (SHRINK_BEGIN, 420) и нижний ряд (фикс. 784) — **корректны**,
   оставить как образец фиксированной ширины.
