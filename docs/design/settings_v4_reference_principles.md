# Settings v4 — референс-принципы вёрстки меню настроек

SCRUM-805, фаза 2. Задача: собрать из хороших игр и UX-практик принципы, по
которым перерисовать меню настроек FantasyDisk так, чтобы «ничего ни на что не
налазило, шрифт читаемый, элементы не на всю ширину экрана, кнопки не растянуты».

Дата: 2026-07-02. Метод: WebSearch/WebFetch + разбор известных референс-игр.

---

## 1. Источники (интернет)

1. **Game UI Database — категория «Settings: Menu»** —
   https://www.gameuidatabase.com/index.php?scrn=26 — курируемая база реальных
   экранов настроек из AAA/инди игр (скриншоты сотен тайтлов). Главный
   визуальный референс: видно, что почти все держат панель настроек *уже*
   ширины экрана и выравнивают контролы в колонку фиксированной ширины.
2. **indieklem — Creating an intuitive in-game menu** —
   https://indieklem.com/9-creating-an-intuitive-in-game-menu/ — «≤6–7 пунктов
   на уровень», группировка по категориям (Screen/Audio/Controls), стандартные
   иконки, немедленный визуальный отклик на действие.
3. **ProCreator — 5 Best Practices for Game UI Design** —
   https://procreator.design/blog/best-practices-for-game-ui-design/ —
   визуальная иерархия размером/контрастом/отступами, минимализм, консистентность.
4. **Justinmind — Game UI: principles & best practices** —
   https://www.justinmind.com/ui-design/game — читаемые шрифты, высокий контраст,
   на PC допустимы более плотные раскладки с клавиатурной навигацией.
5. **Pixune — Game UI Design Guide** —
   https://pixune.com/blog/game-ui-design/ — консистентный визуальный язык между
   всеми меню, чтобы игрок не переучивался.
6. **GameAnalytics — How to make your game UI shine** —
   https://www.gameanalytics.com/blog/how-to-make-your-game-ui-shine-and-increase-conversions —
   размер и расстояние между интерактивными элементами, чтобы не было промахов
   и визуального слипания.

## 2. Референс-игры (разбор раскладки настроек)

| Игра | Габарит панели | Раскладка | Ширина контролов |
|---|---|---|---|
| Baldur's Gate 3 | центр-модалка ~55–60% ширины экрана | слева вертикальный список категорий, справа `label | control` в 2 колонки | дропдауны/слайдеры фикс. ~320–420 px, выровнены по правому краю колонки |
| Diablo IV | панель ~50–60% ширины, табы сверху | 2 колонки: подпись слева, контрол справа | все контролы одной ширины, правый край выровнен |
| Hades | список категорий слева, опции справа | одноколоночный контент, но контролы фикс. ширины | слайдеры/тогглы не тянутся на всю ширину |
| Stardew Valley | вкладки-иконки сверху, узкая колонка | чекбоксы/слайдеры в выровненной колонке по центру | компактные, единый размер |
| Slay the Spire | небольшая центр-панель | слайдеры и тогглы в узкой колонке | не на всю ширину, аккуратные |
| Darkest Dungeon | панель уже экрана, свиток-рамка | подпись + контрол в ряд, орнамент рамки НЕ перекрыт контентом | контролы фикс. ширины |

Общий вывод из базы и игр: **панель настроек НЕ на всю ширину экрана**
(типично 50–65%), **контролы — фиксированной ширины в колонке, а не EXPAND на
весь ряд**, метки и контролы образуют **выровненную двухколоночную сетку**.

## 3. Выписанные принципы (чек-лист для v4)

- **P1. Ширина панели** — 50–65% ширины экрана (не 80%). Цель FantasyDisk:
  модалка ≈ 55–60% ширины (напр. ~1120 px @1920, ~1490 px @2560), высота по
  контенту, не «на весь экран».
- **P2. Двухколоночная сетка `label | control`** — единая колонка меток слева,
  единая колонка контролов справа; правые края контролов выровнены.
- **P3. Фиксированная ширина контролов** — дропдауны/поля/кнопки НЕ
  `EXPAND_FILL`; одна ширина для всех однотипных (напр. дропдаун 420 px,
  слайдер-трек 360 px, action-кнопка 240 px). Контрол ≤ ~55% ширины контент-зоны.
- **P4. Единый вертикальный ритм** — одинаковый шаг между рядами (напр. 16–20 px),
  одинаковая высота ряда (напр. 56–64 px). Никаких разнобойных 420/520/560.
- **P5. Читаемый шрифт** — эффективный кегль метки ≥ 16 px @1080p; высокий
  контраст текста к фону; без декоративных «мыльных» шрифтов в мелком.
- **P6. Группировка ≤6–7 пунктов** — 3 вкладки (Экран/Звук/Управление)
  сохраняем; в каждой — короткий сгруппированный список.
- **P7. Контент не на орнаменте рамки** — весь интерактив только в пустой
  safe-зоне рамки (правило AGENTS.md/qa_protocol); заголовок в верхней safe-зоне.
- **P8. Состояния кнопок** — у каждой кнопки видимые normal/hover/pressed
  (+disabled/focus); немедленный визуальный отклик.
- **P9. Никакого растяжения ассета** — арт рисуется/нарезается в НАТИВНОМ
  размере или честный 9-slice без искажения углов/орнамента; не тянуть источник
  640–688 px в 2048 px (текущая «мыльность/жир границ»).
- **P10. Консистентный визуальный язык** — те же рамки/кнопки/шрифты, что и в
  остальных меню FantasyDisk (пауза, главное меню).

## 4. Как это отменяет текущие болячки v3

- EXPAND_FILL у OptionButton → **P3** (фикс. ширина, убрать EXPAND).
- Модалка 80% ширины → **P1** (55–60%).
- Разнобой ширин 420/520/560 → **P3+P4** (единая сетка).
- Источник 640–688 px растянут в 2048 px → **P9** (нативный размер / 9-slice).
- Мелкий кегль свитчера (base 12) → **P5** (кегль по сетке, ≥16 эфф.).
