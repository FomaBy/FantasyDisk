## Что сделано (сводка)

- Полный редизайн settings-блока `scripts/ui_screens.gd` с нуля: дизайн-лист
  1420×1060, единый скейл s, сетка label(380)|control(560), фикс-размеры.
- 27 новых ассетов `assets/sprites/ui/frames/settings_v5/` (OpenAI gpt-image-2
  по пайплайну HUD v2 + PixelLab контент-панель; рамка — bluescreen-вырезание
  + despill + erode; жёлоб/чип перегенерены без орнаментов).
- Мокапы и листы состояний: `references/settings_v5/` (6 файлов).
- Смоук-контракты обновлены под v5: свитчер = 3 самостоятельных пластины
  340×84 (runtime_smoke), слайдер-контракт SCRUM-674 сохранён по смыслу
  (компакт ≤460×46, видимый жёлоб ≥8px, видимое заполнение — текстурное).
- v4-ассеты воркера остаются на диске (dormant, откат-путь); v3 не тронуты.
