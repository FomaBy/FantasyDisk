## 1. Модель сравнения

Класс = комплект 3 оружий. Четыре оси: solo (1t), aoe (5t), crowd (20t), defense (EHP).
Скор класса по оси = среднее 3 оружий / медиана ростера. **Ось нормируется профилем**:
`axis_norm = axis_score / profile_target` (CLASS_BUDGET_PROFILES: solo_target, aoe_target;
crowd наследует aoe_target; defense_target по survival-профилю, §1.2). Специализация
(assassin solo 1.30 / aoe 0.70) — легальна; наказывается отклонение от СВОЕГО профиля.
