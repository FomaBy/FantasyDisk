## Acceptance Criteria

- Every Codex left tab uses `text/main_menu_380x104`; `minimal/codex_tab` is removed from runtime and from accepted test contracts.
- Pause dossier actions preserve the main-menu source aspect instead of shrinking a 380×104 plate into arbitrary 220×72/260×72 rectangles.
- Compact dossier targets use a vertical right action rail; 1080p/2K use a horizontal footer with uniform main-menu scaling.
- All five states keep identical Control geometry and safe content margins.
- 1152×648, 1280×720, 1600×900, 1920×1080, 2560×1440 and live resize pass without clipping, overlap or frame-border intrusion.
- Focused Codex/dossier/button-family, no-overlap, gamepad, UI smoke and full runtime smoke pass.

## Result

- Codex tabs use `text/main_menu_380x104` in all five states; the old yellow
  runtime/test exception is gone. Compact captions `Параметры` and
  `Возвыш.` keep the label lane inside the plate at 648p/720p.
- Dossier actions use ratio-preserving targets in a right compact rail and a
  horizontal 1080p/2K footer. Texture and content margins share one scale.
- Compact derived chips switch to one internal lane and omit redundant group
  captions at 720p, so stats and full tooltips remain visible without scroll.
- Responsive action geometry lives in
  `scripts/ui/pause_dossier_action_layout.gd`, keeping the Pause monolith below
  its repository line-count ratchet.

  `build/qa/scrum983/` and `build/qa/scrum954/`.
- Passed: button-family, Codex layout, Escape dossier five-target/live-resize,
