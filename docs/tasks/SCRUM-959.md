## Context / Problem

Текущий пул артефактов (71 запись в `ProgressionData.ARTIFACTS`) — смесь
generic-статов, легаси классовых affinity-предметов, активных артефактов и
смешанного англо-русского нейминга. `class_affinity` не фильтрует выдачу
(классовые падают всем), `affinity_mods` применяются всем. Редизайн требует:
универсальный пул с редкостным скейлом для всех статов/атрибутов, ≥5 уникальных
классовых артефактов на класс за Возвышение 5 и снос легаси.

## Required Change

Финальная дизайн/data-спека новой системы артефактов до реализации:

- Универсальные семьи на все 8 базовых статов и все 24 атрибута `ATTRIBUTE_REGISTRY`
  с роллом редкости при выдаче (tier 1/2/3 = обычный/редкий/эпический).
- Единое правило скейла: статы +2/+4/+7; процентные +10%/+18%/+30%;
  плоские ≈0.75×/1.25×/2.0× level-up карточки.
- Ровно 5 классовых артефактов × 17 классов, `class_affinity=[class_id]`,
  `requires_ascension: 5`, механики из драфт-матрицы Jira без потерь.
- Гейтинг через `is_reward_relevant()` + ascension-параметр в сэмплерах (дефолт 0).
- Миграция универсалов в семьи с сохранением id/иконок; удаление 16 легаси
  классовых id; одно явное cross-class исключение (`stolen_crest`).
- Контракты и зависимости для SCRUM-960/961/962/963/964.

## Acceptance Criteria (Jira)

- [x] Финальная матрица существует в docs с каноничными id, русскими именами,

  производные атрибуты реестра (24).

  не остаётся неизменным случайно (16 id + swift_ink-дубль, §1.6 матрицы).
- [x] Спека фиксирует зависимости для бекенда, генерации иконок, интеграции
  и QA (§7 матрицы: сигнатуры, файлы, тесты).
