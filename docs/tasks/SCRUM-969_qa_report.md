### BUG-1 (FAIL): music_elite_duel_300.ogg — не луп-редакция, провал музыки в бою

- Файл 78.92 c: музыкальный контент кончается на ~69.9 c, дальше фейд-аут и **3.95 c
  цифровой тишины (нули) до EOF** (74.96–78.92 c). Голова набирает громкость за 0.35 c.
- `MUSIC_META`: loop=true, loop_offset=0 → луп играет и тишину. Элитный бой 300 c =
  3.8 прохода: **провал музыки ~9 c (фейд+тишина) на ~70–79, ~149–158, ~228–237 c боя**.
  По AC это «broken loop»: игрок слышит, как музыка полностью умирает посреди дуэли.
- Длина 78.9 c вне целевой 100–130 c (±15% → низ 85 c) — §2 спеки.
- SOURCES.md заявляет «Medieval: Battle — полная (лупящаяся) версия целиком»: фактически
  замастерена версия с авторским концертным фейд-аутом, не loop-версия.
- Репро: элитный узел (или dev-консоль `~`), дождаться ~70-й секунды боя.
- Followup (для оркестратора): пере-редактировать `music_elite_duel_300.ogg` — взять
  loop-версию источника либо loop-edit текущей (срез фейд-аута ~69.9 c, кроссфейд шва
  0.4–0.8 c по методике пака), длина к 100–130 c (или честный луп ~70 c); обновить
  loop_offset в MUSIC_META при появлении интро + замеры в SOURCES.md; критерий — replaced-gap
  ≤0.03, без тишины >0.2 c внутри луп-региона.
