## Context / Problem

Текущий пул — 29 событий ровного качества «плейсхолдер+» (`scripts/event_data.gd`).
Нужно меньше, но лучше: яркая фэнтези-ситуация, ровно 3 осмысленных выбора с разным
интентом/риском/исходом, вариативные награды, скрытые исходы, поддержка act-тегов.

## Required Change

Заменить `RANDOM_EVENTS` на **пак из 12 событий** (≥6 по AC; 12 держит инвариант
runtime_smoke «≥10»). Состав пака закреплён оркестратором (id менять нельзя —
на них завязан арт SCRUM-998 и маппинг фонов SCRUM-997):

Требования к каждому событию:
- Ровно **3 выбора** с различимым интентом (безопасный / рискованный / умный-чековый
  или моральная альтернатива), разными типами наград и внятным риском.
- Вариативность наград по паку: золото, статы, урон/HP-цена, доступ к магазину,
  артефакт/лут, бой, «ничего» при провале — всё должно встречаться.
- Скрытые исходы (`hidden`) — минимум в 3 событиях; каждый скрытый исход обязан
  иметь `outcome_text`, честно объясняющий результат постфактум.
- `tags`: у всех событий проставить `{"acts": [], "biomes": []}` (пустые = любой акт)
  — структура обязательна, наполнение придёт с актами.
- Копирайт: сжатый, играбельный русский; title ≤ ~40 симв., story 2-4 предложения,
  choice title ≤ ~28 симв., description 1 предложение. Без англицизмов в
  player-facing строках.
- Баланс: EV-инвариант «риск ≥ безопасно» в золото-эквиваленте
  (`tests/event_risk_reward_ev_test.gd`) обязан выполняться; difficulty чеков 1..12
  (реально 6-9 по прогрессии); только валидные mods
  (`tests/event_data_contract_check.gd:11-19`).
- Старые события, не вошедшие в пак, УДАЛИТЬ из `RANDOM_EVENTS` (легаси не
  выбирается — AC). Реворк-события (sudden_fork и пр.) переписать до планки, не
  копипастить.

## Acceptance Criteria (Jira)

- Активный пул = только новые/переписанные события; старые плейсхолдеры не выбираются.
- У каждого события 3 выбора с различимым интентом, риском и исходом.
- Награды вариативны: золото, статы, урон/HP, магазин, артефакт/лут, бой, «ничего» при провале.
- Есть видимые и скрытые исходы; скрытые честны и объяснимы после резолва (outcome_text).
- В определениях — act/biome-теги (стартовый пак разрешён в любом акте).
- Тексты сжатые, player-facing, на русском.
- Балансовый док перечисляет каждое событие: выборы, чеки, награды, уровень риска.
