## Context / Problem

Экран события — обычная menu-панель (`_create_menu_box(..., "event", _atlas_chip_style)`,
`ui_screens.gd:8477`) с общим фоном `ui_backdrop_arcane_lab.png` (делит с upgrade/level_up,
`main.gd:99`). Нужен отличительный стиль: иллюстрированная встреча — фон-иллюстрация
события, текст истории в боковой диалог-панели, ровно три решения снизу.

## Required Change

1. **Mockup/спека ПЕРЕД кодом**: `docs/design/mockups/scrum997_event_dialog/spec.md`
   — все зоны, safe-margins, responsive-правила 1280×720 / 1920×1080 / 2560×1440,
   состояния карточек (normal/hover/focus/disabled), reveal-состояние.
2. **Лейаут (контракт закреплён оркестратором, согласован с артом SCRUM-998):**
   - Фон: иллюстрация события на весь экран (в рамках общего menu/gold-frame
     семейства — внешняя рама/виньетка допустима, контент НЕ на орнаменте рамки).
   - **Диалог-панель СПРАВА**: ~34-38% ширины экрана, вертикально от верхней зоны
     до верха нижнего ряда; внутри — титул события (золотой) + story-текст;
     полупрозрачная тёмная подложка в стиле atlas-chip/gold-frame, чтобы читалось
     поверх любого фона. Иллюстрация слева НЕ перекрывается текстом.
   - **Три карточки выбора ВНИЗУ**: горизонтальный ряд, нижние ~20-24% высоты,
     на всю safe-ширину; каждая карточка: title выбора, строка интента/описания,
     строка «награда/чек-хинт» (видимая награда ИЛИ «Проверка: Сила 7» ИЛИ
     загадочная формулировка unknown_hint для hidden — точный текст исхода не
     раскрывать). Hover/focus/click-состояния обязательны (кант как у
     `_apply_atlas_choice_card_theme`, `ui_screens.gd:11837`).
   - **Reveal-состояние** (из SCRUM-996): story-текст в диалог-панели заменяется на
     outcome_text, ряд карточек скрыт, одна кнопка «В путь» в нижней зоне; стилизовать.
   - Кнопка «Назад» (allow_skip) — не поверх иллюстрации и орнамента.
3. **Фоны per-event**: динамический выбор фона по `event.id` из манифеста SCRUM-998
   (`assets/backgrounds/events/event_bg_<id>.png`); фолбэк на текущий
   `ui_backdrop_arcane_lab.png` для незамапленных id. hazard/altar-узлы получают фон
   своего события (sudden_fork/sacrifice_altar).
4. Фокус-цепь клавиатура/геймпад сохранить (карточки+назад, SCRUM-477; reveal —
   фокус на «В путь»).
5. Соблюдать правило safe-зон рамок (AGENTS.md: контент только в пустой зоне, не
   на орнаменте) и матричный гейт no-overlap.

## Acceptance Criteria (Jira)

- Экран события — полированная иллюстрированная встреча, не текущая плоская панель.
- Story/диалог-текст в боковой панели, читается и не закрывает главную иллюстрацию.
- Три выбора внизу с явными hover/focus/click-состояниями.
- Карточки умеют: известная награда / чек-хинт / намеренно загадочная формулировка.
- Правило gold-frame/menu соблюдено; контент не перекрывает орнаменты.
- Лейаут работает на 1280×720, 1920×1080, 2560×1440.
- Mockup/спека, safe-зоны и responsive-правила задокументированы ДО имплементации.

## Итог

Экран события переделан в иллюстрированную встречу (спека ДО кода:
`docs/design/mockups/scrum997_event_dialog/spec.md`, геометрия — единственный
источник `_event_dialog_metrics()`):

- **Фон per-event**: `Main.event_background_path()` — файловая конвенция пака
  SCRUM-998 (`assets/backgrounds/events/event_bg_<id>.png`, `ResourceLoader.exists`,
  кэш `screen_background_cache["event:<id>"]`, ни одного if-а по id); фолбэк —
  прежний `ui_backdrop_arcane_lab`. Шейд 0.14 над родным артом / 0.44 над фолбэком.
  hazard/altar-узлы получают арт своих событий через тот же маппинг (event_id).
- **Диалог-панель СПРАВА**: `MenuPanel_event` = чип Атласа 0.90 на ручном rect,
  ширина `clamp(0.36·W, 330, 980)` (36.0% на 720/1080/1440), от верхней safe-зоны
  до нижней полосы; внутри `EventContent` → золотой `EventTitle` (ужимка шрифта
  под самое длинное слово — «жертвоприношений» не рвётся), латунная линия
  `EventTitleRule`, светлый `EventStory` (длинный текст скроллится). Иллюстрация
  слева текстом не перекрывается.
- **Нижняя полоса** `clamp(0.22·H, 142, 320)` (21.9–22.0% высоты): `EventChoiceRow`
  — ровно 3 карточки `_make_economy_choice_card` + новая hint-строка
  (`EventChoiceButtonNHint`): «Проверка: <Стат> N» / компактная награда
  («+12 зол. · Лечение 15%», «Бой — награда за победу», «Лавка торговца»,
  «Случайный исход», «−N% HP», «Без последствий») / «Исход скрыт» для hidden
  (цена — в unknown_hint по контракту SCRUM-996). Hover/focus/click/disabled —
  канты `_apply_atlas_choice_card_theme`, недоступные по золоту — disabled+тултип.
  Плита «Назад» 260×action-height у правого safe-края полосы.
- **Reveal (SCRUM-996)**: outcome_text + строка проверки в диалог-панели,
  карточки/«Назад» скрыты, `EventContinueButton` («В путь») по центру полосы,
  фокус на ней, соседи замкнуты. Фокус-цепь SCRUM-477 сохранена (карточки ↔
  назад, стартовый фокус на первой выбираемой).
- **Фиттер карточек**: событийный deferred-пост-фит после первого лейаута
  (ready-мерка autowrap врёт) — сброс premature-ужимок, гарантированная строка
  описания (EXPAND_FILL-ребёнок больше не «исчезает»), при оверфлоу desc→титул→hint,
  финально честный `max_lines` по остатку бюджета; полные тексты в tooltip.
- **Матрица**: event-блок переписан под новый контракт (панель справа 0.30–0.42·W,
  контент в чип-зоне, ряд в нижней полосе и вне панели, hint/title/action внутри
  карточки, «Назад» в полосе вне ряда/панели, фон присутствует, UpgradeFabButton
  запрещён).
