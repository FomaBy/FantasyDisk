**Технические требования (канон паков фонов):**
- PNG **2560×1440** (16:9), как существующие `assets/backgrounds/ui/ui_backdrop_*.png`;
  вес разумный (~<6 МБ). Полноэкранный opaque арт, БЕЗ прозрачности, БЕЗ вшитого
  текста/рамок/UI.
- **Safe-зоны композиции (контракт с SCRUM-997):** главный сюжет/фокус — в левых
  ~55-60% ширины и верхних ~70% высоты; **правые ~38% ширины** (диалог-панель) и
  **нижние ~24% высоты** (ряд выборов) — спокойные, низкодетальные, темнее (текст
  должен читаться поверх при полупрозрачной подложке). Важные объекты не прятать
  в этих зонах.
- Единый стиль пака: painterly dark fantasy D&D, палитра проекта (тёмный фон,
  тёплые акценты золото/огонь, фиолетовые магические акценты), консистентность
  между фонами.
- Генерация — скилл `fantasydisk-asset-generator` (OpenAI gpt-image); ПЕРЕД батчем
  проверить квоту/биллинг (память: hard limit 2026-07-01 блокировал батчи; ключ в
  `~/.codex/.env`). Если квота мертва — зафиксировать блокер в Jira-комментарии,
  пометить задачу blocked, сгенерить нисколько (не жечь ретраи).

**Раскладка файлов:**
- Runtime: `assets/backgrounds/events/event_bg_<id>.png` (+ `.png.import` сайдкары —
  прогнать Godot `--import` через `tools/godot_gate.py`, коммитить ПАРОЙ png↔import).
- Референсы/исходники: `docs/design/references/events_backgrounds_pack/` (копии +

  не скрыт.
