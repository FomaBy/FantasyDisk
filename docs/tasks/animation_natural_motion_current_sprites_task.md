Статус: done 2026-06-11. Результат: текущие polished sprites используются через нарезанный cutout rig с pivot-based limbs, readable archetype motion, flying hover/flap, boss/elite parts, smoothed facing/walk blends и weapon socket follow. ## Autonomy / Approval

Пользователь заранее одобрил все изменения в рамках этой задачи. Не спрашивай подтверждение: выбери лучший animation-подход, переделай нужные сцены/ассеты/скрипты, обнови тесты и документацию. Спрашивать нужно только при реальном блокере, обязательной sandbox/security эскалации или потенциально разрушительном действии вне scope.

## Контекст

Текущее движение персонажей и монстров выглядит игрушечно и недостаточно натурально. Нужно улучшить движение, используя текущие спрайты, новую визуальную схему и практики 2D-анимации.

Цель не в том, чтобы сделать фотореализм. Нужно сделать движение более живым, плавным, естественным и менее игрушечным.

## Главная Цель

Сделать движение персонажей, монстров, элиток и боссов более натуральным:

- меньше игрушечного скольжения;
- меньше дерганых поворотов;
- меньше ощущения, что части тела оторваны;
- больше плавных переходов;
- взгляд/поворот тела должен зависеть от направления движения;
- конечности должны двигаться естественнее;
- animation speed должен соответствовать actual movement speed.

## Основной Подход

Сначала попробовать улучшить анимацию из текущих спрайтов:

- разрезать спрайты на части, если это улучшит движение;
- подложить body/base/background parts так, чтобы не было видно разрезов;
- двигать конечности через pivot-точки;
- добавить secondary motion для плащей, волос, крыльев, брони;
- менять направление взгляда/головы по направлению движения;
- использовать разные pose/lean для движения вверх, вниз, влево, вправо;
- добавить плавные transition states;
- не ломать hitbox/hurtbox и gameplay scale.

## Требования К Направлениям

Для игрока:

- движение вправо/влево должно менять facing;
- движение вверх/вниз должно отличаться хотя бы позой/наклоном/направлением головы;
- idle должен быть живым, но спокойным;
- attack/cast/shoot не должны конфликтовать с walk;
- Берсерк должен корректно держать отдельное оружие.

Для монстров:

- melee враги должны иметь тяжелое преследование;
- ranged враги должны двигаться осторожнее;
- быстрые враги должны иметь частые шаги или рывковую пластику;
- жирные враги должны ощущаться тяжелыми;
- summoner/shaman должны двигаться менее физически, более ритуально;
- flying enemies должны летать/парить, а не ходить;
- элитки должны иметь более выразительную пластику;
- боссы должны иметь anticipation/recovery для сильных паттернов.

## Технические Варианты

Разрешено использовать:

- cutout animation;
- 2D skeleton;
- AnimationPlayer;
- AnimationTree;
- AnimatedSprite2D/SpriteFrames;
- procedural polish поверх нормальной анимации;
- helper scripts для animation state.

Не использовать procedural bob/scale как единственную основу, если это выглядит дешево.

## Дополнительный Вариант Если Не Получается Красиво

Если из текущих top-down/angled спрайтов невозможно сделать красивую натуральную анимацию:

1. Зафиксировать проблему в документации.
2. Подготовить короткий handoff для Design: нужно перерисовать всех персонажей и монстров во фронтальном/более animation-friendly виде.
3. Сформулировать, какие именно позы и части нужны:
   - front/side readable body;
   - separate limbs;
   - head directions;
   - idle/walk/attack/cast pose refs;
   - clean overlap areas, чтобы не было видно разрезов.
4. Не сдавать плохую анимацию как финальную. Лучше честно перейти на redesign path.
