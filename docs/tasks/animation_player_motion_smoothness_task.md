Handoff по правилам docs/process/agent_role_boundaries_and_handoffs.md.

## Контекст
Решения пользователя:
1. Движение персонажа и его оружия должно стать «чуть плавнее».
2. У Берсерка меняются формы атак (см. `backend_berserk_weapon_identity_rebalance_task.md`):
   меч — узкая длинная полоса (быстрый укол/росчерк), топор — широкая дуга,
   молот — слабый круговой удар. Замахи должны читаться по-разному.
3. Walk-анимация Темного Мага «мутная в ногах» — Design перерисовывает спрайт
   (`design_dark_mage_sprite_legs_rework_task.md`), после этого нужен новый walk-цикл.

## Требования
1. **Плавность движения** всех трех персонажей: сгладить переходы idle↔walk,
   убрать рывки при смене направления (easing/blend, lean корпуса по направлению).
2. **Плавность оружия**: оружие в руках не должно телепортироваться между кадрами;
   замах → удар → возврат с естественными ускорениями (ease-in/out).
3. **Замахи Берсерка под новые формы**:
   - меч — быстрый узкий росчерк/укол вперед по линии атаки;
   - топор — размашистая горизонтальная дуга;
   - молот — вертикальный удар сверху вниз с короткой отдачей.
   Тайминги синхронизировать с `fire_interval` из backend-конфигов (источник истины — код).
4. **Walk-цикл Мага**: после нового спрайта от Design переделать ходьбу так,
   чтобы шаг читался чисто (контакт стопы, перенос веса), без «каши» в ногах.
5. Совместимость с pause/game state; базовые состояния не ломать.
6. Обновить `tests/animation_smoke_test.gd` под новые/измененные состояния.
