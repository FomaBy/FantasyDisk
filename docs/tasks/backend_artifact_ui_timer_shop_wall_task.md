## Контекст
Решения пользователя:
1. Во время игры подобранные артефакты должны быть видны **списком иконок** на HUD.
2. В меню паузы у артефактов должно быть **свое место**.
3. В магазине артефакты должны размещаться в зоне фона, которая выглядит как
   пустая стена (большой светлый пергамент правее торговца на
   `assets/sprites/ui/screens/screen_shop_background.png`, примерно 45-83% ширины
   и 5-75% высоты кадра — уточни по фактическому изображению).
4. Таймер боя — стилизованный, **по центру сверху**; когда остается **5 секунд
   и менее** — подсвечивается красным.

Текущее состояние: `player.artifacts` хранит только titles (`scripts/player.gd:71,349`) —
для иконок нужны id. `artifact_label`/`timer_label` — простые Label в `scripts/main.gd:241,248`.
Иконки: `assets/sprites/ui/icons/artifacts/artifact_<id>.png`, маппинг уже есть в
`scripts/ui_screens.gd:8,676`.

## Требования

### Артефакты
1. Хранить у игрока id артефактов (не только title) — поправить
   `scripts/player.gd` (artifacts.append) с сохранением совместимости.
2. **HUD**: ряд иконок подобранных артефактов (~40px), ненавязчиво (например,
   верхний левый/правый угол), с переносом при большом количестве; tooltip с
   названием и эффектом при наведении. Обновлять только при изменении списка.
3. **Пауза**: отдельный блок «Артефакты» в pause/stats меню — сетка иконок
   с названиями и эффектами (`scripts/pause_stats_menu.gd` или ui_screens).
4. **Магазин**: товары-артефакты разместить в зоне «пустой стены» фона —
   сетка слотов (рамки `ui_shop_artifact_slot_frame/hover` уже есть) поверх
   пергамента; остальной layout магазина не ломать.

### Таймер
5. Перенести таймер боя в **верхний центр** экрана, оформить через ассет
   `assets/sprites/ui/hud/timer_frame.png` от Design (до готовности — стилизованная
   панель кодом).
6. При `time_left <= 5.0`: цифры и рамка подсвечиваются красным (модуляция или
   alarm-ассет), допустима легкая пульсация. На босс-файтах без таймера — не показывать тревогу.
7. Подсветка уважает паузу и сбрасывается при новом бое.
