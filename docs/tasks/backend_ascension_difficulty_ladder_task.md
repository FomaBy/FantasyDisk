## Контекст (решение пользователя)
Возвышение — режим усложнения как «heat» в Hades / Ascension в Slay the Spire:
1. 10 уровней; уровень N включает ВСЕ модификаторы уровней 1..N (кумулятивно).
2. Возвышения делают игру сложнее и ОТКРЫВАЮТ мета-прогрессию.
3. Мета-прогрессия выдается после убийства финального босса — ПОКА ЗАГЛУШКА,
   но хук должен работать.
4. На экране выбора персонажа каждый герой может начать забег на любом
   ДОСТУПНОМ ему уровне возвышения (0..открытый максимум; прогресс — по персонажу).

ВАЖНО — конфликт с текущей системой: сейчас ASCENSION_LEVELS — это БАФФЫ игрока
(+урон/+HP за уровень). Переработать: старые баффы НЕ выбрасывать, а перевесить
в наградный трек меты (см. ниже).

## 10 Возвышений (кумулятивные усложнения)

| # | Название | Эффект |
| --- | --- | --- |
| 1 | Закалённые враги | Монстры +15% HP и +10% урона |
| 2 | Жадные торговцы | Все цены (магазин/докачка/reroll) +25% |
| 3 | Быстрая орда | Спавн волн чаще, плотность +20% |
| 4 | Свирепые элитки | Элитки: +20% HP, вторая фаза открывается сразу |
| 5 | Скудные трофеи | Золото и опыт с боёв −20% |
| 6 | Истончённая плоть | Всё лечение (зелья/регенерация/вампиризм/drain) −30% |
| 7 | Эхо бездны | В обычных волнах может появиться мини-элитка со свитой |
| 8 | Длинная вахта | Таймер боя +25% (дольше выживать), спавн не ослабевает |
| 9 | Гнев стража | Босс: +1 фаза опасных зон, +20% HP, телеграфы короче |
| 10 | Грань безумия | Игрок: −20% макс. HP; стартовая волна каждого боя усилена |

## Требования
1. **Данные**: `ASCENSION_MODIFIERS` (10 записей выше) — глобальные, data-driven,
   кумулятивное применение (уровень N = сумма 1..N). Канонические ID и имена —
   в content_registry.
2. **Прогресс по персонажу**: переиспользовать существующий
   `meta_progression.gd` (levels per character уже хранится): победа над
   финальным боссом на уровне N → открывается N+1 для ЭТОГО персонажа.
3. **Мета-награда (заглушка с работающим хуком)**: при победе на возвышении N
   персонаж получает свой старый бафф `<класс>_asc_N` (бывшие ASCENSION_LEVELS —
   теперь это наградный трек меты, применяется на старте забега постоянно).
   Экран «мета-прогрессия» после босса — заглушка-уведомление «Открыто: …»
   (полноценный экран меты — будущая задача).
4. **Выбор уровня на старте**: в выборе персонажа (инфо-панель героя) — селектор
   уровня возвышения 0..открытый максимум персонажа, со списком активных
   модификаторов выбранного уровня (кумулятивный список читаемым текстом).
   Текущий уровень виден на карточке (например «Возвышение III»).
5. **Применение в бою**: модификаторы влияют на combat_director/enemy/boss/цены/
   лечение строго в момент забега; уровень 0 = ничего не меняет (текущая игра).
6. **HUD**: индикатор активного возвышения в забеге (римская цифра у таймера),
   тултип со списком модификаторов.
7. **Кодекс/доки**: раздел «Возвышения» в кодексе со всеми 10.
8. **Тесты**: кумулятивность (на уровне 3 активны 1+2+3), разблокировка после
   босса, награда-бафф выдается, селектор не дает выбрать закрытый уровень,
   уровень 0 не меняет числа; все smoke зеленые.
