## Контекст
Баг: при движении часть оружия атакует по направлению движения персонажа,
а не по ближайшему монстру. Источник найден PM:

- `scripts/melee_weapon.gd:37-38` — `_last_direction = owner_node.velocity.normalized()`
- `scripts/class_weapon.gd:71-72` — то же
- `scripts/berserk_weapon.gd:53-54` — то же

Направление атаки перетирается вектором скорости перед выстрелом/ударом.

## Требования
1. Все оружия игрока должны целиться **в ближайшего живого врага** в радиусе
   действия, независимо от направления движения персонажа.
2. Приоритет выбора направления:
   1) ближайший враг в `attack_range`;
   2) если врагов в радиусе нет — ближайший враг на арене (для направленных
      оружий, чтобы удар не уходил «в никуда»);
   3) если врагов нет вообще — последнее направление атаки (не двигаться от velocity).
3. Анимация атаки (`play_action_animation("attack", direction)`) и VFX должны
   использовать то же направление, что и расчет урона.
4. Проверить аналогичную логику у всех классов: Берсерк (melee/berserk_weapon),
   Маг и Гитарист (class_weapon), summoner-оружия — единообразное поведение.
5. Поведение «смотрит куда идет» оставить только для walk-анимации персонажа,
   не для атак.
