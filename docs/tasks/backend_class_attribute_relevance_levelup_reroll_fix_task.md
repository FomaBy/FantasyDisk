Пользователь заранее одобрил все изменения. Не останавливаться для подтверждений.

## Контекст
Два решения пользователя.

**1. Логика атрибутов сломана по классам.** Сейчас:
- магический урон и звуковой урон дают прирост физического урона Берсерку —
  не должны (и превью изменений это пишет);
- физический урон засчитывается в превью Магу и Гитаристу — а у них он низкий
  и не их параметр; прирост им давать не должен.

**2. Баг-эксплойт реролла уровней.** Если переоткрыть окно повышения уровня,
оно каждый раз показывает НОВЫЙ набор апгрейдов — можно бесплатно перебирать,
пока не выпадет нужный.

## Требования

### Классовая релевантность атрибутов
1. Зафиксировать в данных карту релевантности параметров урона:
   - `berserk` → физический урон (damage/strength-ветка);
   - `dark_mage` → `magic_damage`;
   - `guitarist` → `sound_wave_damage`.
2. **Применение**: нерелевантный классу параметр урона не дает классу никакого
   прироста силы (ни прямого, ни через производные формулы). Проверить
   `stat_formulas.gd` и применение статов в `player.gd` — источники утечки,
   где magic/sound урон конвертируется в общий/физический урон.
3. **Превью изменений** (окно атрибутов, level-up, экран статов): показывать
   только реальные изменения для текущего класса. Нерелевантный параметр:
   либо не показывать в превью вовсе, либо показывать «без эффекта для класса»
   серым — выбери единый вариант и применяй везде.
4. **Предложения**: окна выбора атрибутов/апгрейдов не должны предлагать
   нерелевантные классу параметры урона (Берсерку не предлагать +magic_damage
   и т.п.). Универсальные статы (HP, скорость, защита и пр.) — для всех.
5. Согласовать с механикой class_affinity артефактов (та же философия —
   честный расчет): артефактные пометки уже работают, атрибуты должны
   вести себя так же.
6. Проверить все три класса: каждому предлагается и засчитывается только своя
   ветка урона; превью числа совпадают с фактическим изменением DPS-статов.

### Фикс реролла окна уровня
7. Набор предложений level-up должен **генерироваться один раз** на каждый
   полученный уровень и сохраняться до выбора: закрытие/переоткрытие окна
   показывает тот же набор.
8. Проверить аналогичный эксплойт во всех окнах с выбором: окно докачки
   атрибутов после боя (там reroll платный — переоткрытие не должно давать
   бесплатный реролл), награды, магазин (ассортимент узла фиксирован до
   покупки/ухода с узла).
9. Сохраненные наборы корректно сбрасываются там, где это легально
   (новый уровень — новый набор; новый узел магазина — новый ассортимент).

## Acceptance Criteria
- [ ] Берсерк не получает силы от magic/sound урона; маг и гитарист — от физического.
- [ ] Превью во всех окнах показывает только реальные для класса изменения.
- [ ] Нерелевантные параметры урона не предлагаются классу в выборах.
- [ ] Переоткрытие окна уровня показывает тот же набор апгрейдов (для каждого уровня — свой фиксированный).
- [ ] Переоткрытие окна докачки/магазина не дает бесплатных реролов.
- [ ] Smoke-тесты зеленые + тесты: фиксация набора level-up при переоткрытии; отсутствие прироста от нерелевантного стата для каждого класса.
