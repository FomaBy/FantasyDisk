## Контекст
Решение пользователя: в главном меню нужен «Кодекс» — внутриигровая энциклопедия,
чтобы у всех сущностей игры были видимые канонические названия и описания,
на которые можно ссылаться (в обсуждениях, задачах, балансе).

Источники данных уже есть: `scripts/progression_data.gd` (персонажи, оружие,
артефакты, характеристики, апгрейды) и `docs/design/content_registry.md`
(канонические ID/имена монстров, элиток, боссов, способностей).

## Требования

### Экран
1. Кнопка **«Кодекс»** в главном меню (рядом с настройками).
2. Экран с вкладками/разделами, скроллируемые списки, выход назад в меню.
   Стиль — существующий UI игры (панели/рамки как в настройках/статах).
3. Управление: мышь + клавиатура (как остальные экраны меню).

### Разделы и наполнение
4. **Персонажи**: 3 класса — имя, спрайт, краткое описание стиля игры,
   сильные/слабые стороны, список оружия с названиями и кратким описанием.
5. **Монстры**: все обычные враги, элитки, боссы. Для каждого: каноническое
   имя (RU) + id, спрайт, краткое описание поведения, **умения с названиями**
   (например: Железный Оплот — «Сотрясающий Удар» (Slam), «Железный Щит»;
   Ночной Сталкер — «Теневой Удар» и т.д.).
   Если у умения еще нет канонического имени — придумать в стиле игры и
   **зарегистрировать в content_registry.md** (это главная ценность задачи:
   пользователь будет ссылаться на эти названия).
6. **Артефакты**: все 46 — иконка, название, эффект (тянуть из ARTIFACTS и
   магазинных/ивентовых предметов progression_data, не дублировать строки руками).
7. **Характеристики и атрибуты**: краткое описание каждой характеристики
   (Сила, Ловкость, Интеллект, Восприятие, Энергия, Знание, Выносливость,
   Лидерство — и производные параметры: урон, скорость атаки, HP и т.д.) —
   что дает игроку, на что влияет по формулам из `stat_formulas.gd`/mechanics_extract.

### Данные
8. Контент кодекса — **data-driven**: единый словарь/ресурс (например,
   `scripts/codex_data.gd`), собирающий записи из существующих констант, а не
   копипаста строк по UI-коду. Новые тексты описаний живут там же.
9. Названия и id обязаны совпадать с `content_registry.md` (источник истины).
   Все новые имена умений — добавить в registry в этой же задаче.

### Качество
10. Открытие кодекса не должно фризить меню (ленивое построение разделов).
11. Тексты на русском, в тоне игры (дарк-фэнтези, без канцелярита).
