## Контекст (запрос пользователя, 2026-06-12)
«Пересмотреть количество дропа с разных мобов: увеличить с жирных и сложных
монстров дроп опыта и денег, но при этом увеличить и стоимости всего в игре
за золото». Сейчас дроп слабо дифференцирован по «жирности» — сложные цели
невыгодны относительно затраченного времени.

## Требования
1. **Дифференциация дропа по сложности цели.** Ввести/пересмотреть множители
   XP и золота по классам целей: обычный моб (база) < жирный моб (танк/бугай)
   < мини-элитка < элитка < босс. Ориентир PM (исполнитель уточняет балансом):
   жирные мобы ×1.5-2 от базы, мини-элитки ×3-4, элитки ×6-10, боссы — крупный
   фикс + множитель этапа. Дроп жирной цели должен ОЩУЩАТЬСЯ (заметная горсть
   орбов/монет, не одна).
2. **Подорожание всего за золото.** Согласованно поднять цены: магазин
   (товары/реролл если есть), докачка атрибутов, цена услуг событий — так,
   чтобы суммарная покупательная способность за забег выросла ЛИШЬ умеренно
   (~+10-15%), несмотря на возросший дроп: больше золота — но и дороже всё.
   Кривую цен по этапам (stage_scale) сохранить/перекалибровать.
3. **Темп прокачки.** Возросший XP-дроп с жирных целей не должен ломать кривую
   уровней: при необходимости поднять XP-требования уровней, цель — общее
   число level-up за забег примерно прежнее (±10-15%), но охота на сложные
   цели заметно выгоднее слабых.
4. Синхронизация с параллельными задачами: SCRUM-149 (ребаланс выживаемости —
   не конфликтовать по файлам прогрессии: если задача ещё in_progress,
   дождаться её done или согласовать через board) и задача ростера
   мини-элиток (новые виды получают свой дроп-класс).
5. **Баланс-отчёт:** harness/симуляция до/после — золото и XP за типовой забег,
   таблица множителей по типам целей в build/balance_report.md.
6. Тесты: дроп-таблицы (фактический спавн орбов/монет по типам целей в smoke),
   цены этапов монотонны.
7. CHANGELOG; балансовые доки.
