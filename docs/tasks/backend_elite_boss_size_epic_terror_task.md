# Задача Для Back-end-Агента: Элитки И Боссы — Крупнее, Эпичнее, Ужаснее

Статус: new
Создано: 2026-06-12
Автор: PM

## Autonomy / Approval
Пользователь заранее одобрил, включая усиление скиллов. Числа — твои, целевые
ощущения — ниже.

## Контекст (решение пользователя)
Увеличить размер Элиток и Босса, и их хитбоксы тоже. Они должны быть сложнее,
ЭПИЧНЕЕ и УЖАСНЕЕ. Можно усилить их скиллы. (Элитки уже укрупнялись до ~x1.35
от моба и недавно ужесточались — это следующий шаг поверх.)

## Требования

### Размер и хитбоксы
1. **Элитки**: визуальный масштаб до ~x1.6-1.8 от обычного моба (поверх текущего);
   **боссы**: ощутимо доминируют на арене — ~x2.2-2.5 от моба. Подобрать так,
   чтобы не ломалась навигация по арене (босс не застревает у стен).
2. **Хитбоксы согласованно**: collision shape, contact_range, hurtbox (зона, по
   которой попадает игрок) — растут вместе с визуалом; «урона по воздуху» и
   непопадания по гиганту вплотную быть не должно (проверить melee-полосой меча
   и снарядами).
3. Если при новом масштабе спрайты мылятся — handoff Codex Design на апскейл-
   перегенерацию (элитки 384-512px, боссы 512-768px, D&D-канон, с референсами),
   интеграция через Claude-Designer; до прихода арта — программный масштаб.

### Сложнее: усиление скиллов
4. Элитки: ускорить ротацию уникальных атак (~-20% кулдауны), добавить каждой
   ВТОРОЕ применение способности в фазе 2 (например: Оплот — двойная волна,
   Сталкер — серия из двух ударов из тени, Пророк — лужи крупнее, Маршал —
   веер + кольцо). Свита/мини-фаза — согласовать с уже сделанным в
   enemy_scaling-задаче, не дублировать.
5. Боссы: +1 опасный паттерн каждому (волна зон по таймеру независимо от фаз),
   короче окна безопасности между атаками.
6. Баланс-рамки: бой с элиткой остается выигрываемым на возвышении 0 со средним
   билдом (целевое: 60-120 сек активного уворота); кривая возвышений множит
   поверх — проверить, что на В4+ («Свирепые элитки») не возникает невозможных
   комбинаций (две атаки одновременно перекрывают всю арену — запрещено,
   всегда должен оставаться безопасный коридор).

### Эпичнее и ужаснее (подача)
7. **Появление**: элитка — рык + краткая вспышка имени (баннер с именем элитки
   в стиле UI), у босса — затемнение, тряска камеры, крупный титул-баннер.
8. **Бой**: тряска камеры на slam/детонациях (короткая, ~0.2с, с отключалкой в
   настройках «Тряска камеры»), у боссов — пульс виньетки на смене фаз.
9. **Смерть элитки/босса**: жирная детонация + замедление времени ~0.3с
   (hit-stop) — момент триумфа перед окном награды.
10. Эффекты подачи уважают паузу и не роняют FPS (без аллокаций в кадре).

### Тесты
11. Хитбокс-тесты: попадание по элитке/боссу вплотную и на границе видимого
    силуэта; контакт-урон по игроку соответствует касанию.
12. Геймплей-тесты усиленных скиллов (двойные применения в фазе 2, новый
    паттерн босса); «безопасный коридор» на В4 — проверка перекрытия зон.
13. Все smoke зеленые; замеры TTK элитки/босса до/после — в отчет.

- [ ] Скиллы усилены (вторые применения, новый паттерн босса), безопасный коридор гарантирован.
- [ ] Подача: баннеры появления, тряска (с тумблером), hit-stop на смерти.
