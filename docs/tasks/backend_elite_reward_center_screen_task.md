## Контекст (решение пользователя)
После убийства элитки награда должна появляться ПО ЦЕНТРУ ЭКРАНА, и это должны
быть артефакты. Механика «1 из 3 артефактов за элитку» уже реализована
(backend_enemy_scaling_elite_boss_difficulty) — задача про подачу.

## Требования
1. Сразу после смерти элитки (и короткой паузы-фанфары ~0.5с) — модальное окно
   по центру экрана: **3 карточки артефактов** (иконка крупно ~96-128px, название,
   тир цветом, эффект, классовая интерпретация), выбор одной.
2. Окно центрировано на ЛЮБОМ разрешении, бой вокруг приостановлен (как level-up),
   Escape не закрывает без выбора (выбор обязателен), геймпад/клавиатура — стрелки+Enter.
3. Оформление — UI-кит (рамки card/panel, D&D-стиль); карточка целиком кликабельна,
   hover-подсветка.
4. Если элитка умерла одновременно с концом таймера боя — окно показывается ДО
   экрана победы (награда не теряется).
5. Тесты: окно появляется по центру, выбор выдает артефакт, остальные два не
   выдаются; кейс «смерть элитки на последней секунде»; smoke зеленые.
