## Контекст
Запрос пользователя (2026-06-12): Escape-пауза должна быть «карточкой решения» —
в любой момент игрок жмет Escape и видит, что у него есть, чтобы принять решение
(в магазине, при выборе характеристик на level-up, у события). Сейчас:
- `scenes/PauseStatsMenu.tscn` + `scripts/pause_stats_menu.gd` — статы, артефакты,
  6 derived-групп; уже неплохая база.
- НО Escape работает только в бою: `ui_screens.gd:1194` — guard
  `game._is_gameplay_paused() and game.combat_active`. В магазине, на route map,
  в level-up окне посмотреть свои статы НЕЛЬЗЯ.
- Приоритетные для класса атрибуты никак не выделены — все статы выглядят
  равнозначно, игроку трудно понять, что «его».

## Требования
1. **Приоритеты класса.** Завести данные приоритета атрибутов per-класс
   (например `ATTRIBUTE_PRIORITIES` в `scripts/progression_data.gd`: для каждого
   из 9 классов 3-5 ключевых атрибутов, согласованных с формулами
   `derived_parameters`/`CLASS_INTERPRETATIONS` и оружейными механиками —
   strength для физических, intelligence/energy для магов и т.д.).
2. **Выделение в паузе — понятно и компактно.** В PauseStatsMenu приоритетные
   атрибуты класса визуально выделены (акцентный цвет/бейдж/порядок «приоритетные
   сверху»), НЕ раздувая экран: один взгляд — понятно, что качать. Тултип
   объясняет почему (текст уже есть в CLASS_INTERPRETATIONS — переиспользовать).
   Помнить правило «no junk UI»: без лишних декоративных вставок.
3. **Заголовок-досье.** Сверху паузы — кто я: портрет-миниатюра, имя класса,
   оружие, уровень/XP, возвышение. Компактной строкой, не отдельным экраном.
4. **Escape доступен ВЕЗДЕ в забеге.** Открытие досье поверх: магазина, окна
   level-up (выбор характеристик), окна докачки, события, награды элитки,
   route map. Поверх текущего экрана (стек пауз `push_pause`/`pop_pause` уже
   есть — использовать отдельный ключ), повторный Escape закрывает досье и
   возвращает к подлежащему экрану, НЕ ломая его состояние (выбор в level-up
   не сбрасывается, кнопки магазина живы).
5. В главном меню/выборе героя Escape ведет себя как раньше (не открывать досье
   вне забега).
6. Кнопки «Продолжить/Настройки/Покинуть забег/Главное меню» — пересмотреть
   уместность по контексту: вне боя «Покинуть забег» опасно-бессмысленна или
   требует подтверждения (решение исполнителя, зафиксировать в отчете).
7. Тесты: smoke на (а) открытие/закрытие досье поверх магазина и level-up без
   поломки их состояния (фактическое дерево узлов и работающие кнопки после
   закрытия); (б) наличие выделенных приоритетных атрибутов для 2-3 классов.
8. CHANGELOG (Unreleased 0.1.4) + документация.
