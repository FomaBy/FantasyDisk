## Контекст
Решение пользователя: «включить все атрибуты в игру, чтобы все работало по балансу».
Источник истины формул — `docs/design/mechanics_extract.md` (таблица производных
параметров из балансовой таблицы: Crit Chance, Crit Damage Multiplier, Attack Speed,
HealthPoint, Dodge, Ultimate Multiplier, DoT, Knockback, Move/Projectile Speed,
Pickup/Aura Radius, Defense и весь остальной список `assets/sprites/ui/icons/derived/attr_*.png`).

## Требования
1. **Аудит**: построить таблицу «производный параметр → формула из mechanics_extract →
   где реализован в stat_formulas.gd/player.gd → статус (работает / частично / не подключен)».
   Таблицу — в отчет и в mechanics_extract.md.
2. **Подключить все неработающие** параметры по формулам таблицы. Если формула
   в таблице противоречит уже реализованному балансу — реализованный приоритетнее,
   расхождение зафиксировать в mechanics_extract (она же дополняется как
   актуальная истина).
3. Каждый параметр должен реально влиять на геймплей у всех классов, где он
   релевантен (с учетом STAT_CLASS_RELEVANCE), отображаться в экране статов,
   кодексе и превью изменений.
4. Параметры, которые в дизайне есть, но механики под них еще нет в игре
   (например Ultimate Multiplier, если ультимейтов нет) — подключить расчет,
   пометить в кодексе «зарезервировано», зафиксировать в отчете список таких.
5. Тесты: для каждого подключенного параметра — проверка влияния
   (поднять стат → производный параметр изменился по формуле).
