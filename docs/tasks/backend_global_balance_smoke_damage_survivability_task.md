## Требования
1. **Глобальный DAMAGE smoke**: прогон balance_harness по ВСЕМ парам класс×оружие
   (1-цель и 5-целей DPS), ассерт отклонения в заданном коридоре от эталона
   (Берсерк-меч) — целевой коридор зафиксировать (например ±20%). Выброс = красный
   тест с указанием пары.
2. **Глобальный SURVIVABILITY smoke**: сценарии (fragile/steady/sturdy/tank +
   roster projection) — TTD/митигация в коридорах; после нерфа регена/вампиризма
   и баланса абсорба/уворота бессмертие недостижимо (проверяемо числами).
3. Сделать эти два сьюта ОТДЕЛЬНЫМИ запускаемыми тестами (или секциями), которые
   гоняются в CI/локально; отчёты в build/.
4. Все балансовые задачи 0.1.5 ссылаются на эти гейты в своих Acceptance.
5. CHANGELOG; docs (как запускать гейты).
