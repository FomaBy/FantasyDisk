## Требования
1. **Во весь экран**: экран выбора героя занимает всю площадь окна (как карта),
   а не центральную колонку.
2. **Сетка без скролла**: все 9 классов помещаются на экране одновременно —
   сетка 3x3 при 16:9 (на других пропорциях допустимо 3 ряда с равными
   карточками). Скролл убрать.
3. **Портреты крупнее**: портрет персонажа — доминанта карточки (рекомендация:
   высота портрета ~50-60% высоты карточки), выровнены по базовой линии.
4. **Ужать тексты**: на карточке — имя, ОДНА строка описания стиля,
   «Сильные: …» и «Слабые: …» по одной короткой строке каждая (сократить
   формулировки в данных, не обрезать многоточием). Полные статы (Сила/Ловкость/…)
   с карточки убрать — показывать в тултипе при наведении или в нижней панели
   выбранного героя.
5. **Баг переполнения** (виден на скриншоте): текст не должен вылезать за рамку
   карточки ни при каком разрешении из настроек — clip + автоперенос; проверить
   1280x720 и 2560x1440.
6. Кликабельность карточки целиком и hover сохранить; Escape = назад.
