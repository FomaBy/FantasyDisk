## Требования

### Компоновка
1. Экран выбора остается fullscreen. Слева ~40% ширины — крупный портрет
   выбранного героя во всю высоту зоны (full-art спрайт, без обрезки, с легким
   пьедесталом/тенью); справа — досье.
2. **Досье справа**: имя, описание стиля, сильные/слабые стороны, оружие (3),
   текущий уровень возвышения с селектором (сохранить функциональность из
   ascension-задачи), роза ветров (ниже), кнопка «Выбрать».
3. **Навигация по 9 героям**: лента миниатюр-портретов внизу или сбоку
   (кликабельны, активный подсвечен) + стрелки клавиатуры/Escape-назад.
   Выбор героя лентой мгновенно обновляет портрет/досье/розу без мерцания.

### Роза ветров (радар)
4. Радар-диаграмма по 8 основным характеристикам (Сила, Ловкость, Интеллект,
   Восприятие, Энергия, Знание, Выносливость, Лидерство) из BASE_STATS героя:
   оси подписаны (иконки статов + значения), заливка полупрозрачная в цвет
   класса, сетка-паутинка в стиле UI-кита.
5. Нормировка осей: общий максимум по всем героям (чтобы радары были сравнимы
   между героями, а не каждый «во весь круг»).
6. Рисовать программно (Polygon2D/draw) — без генерации картинок; стиль линий/
   подписей из UI-кита. Должна читаться на 1280x720.
7. При смене уровня возвышения роза НЕ меняется (это базовые статы героя).

### Качество
8. Тексты не вылезают (урок прошлых итераций), проверка 1280x720 и 2560x1440.
9. Тесты: выбор каждого из 9 через ленту, радар строится для всех, выбор
   запускает флоу оружия; smoke зеленые. Скриншоты двух разрешений в лог.
