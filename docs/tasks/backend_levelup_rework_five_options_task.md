# Задача Для Back-end-Агента: Переработка Level-Up — 5 Вариантов, Один Выбор За Уровень, Красивые Кнопки

Автор: PM

## Autonomy / Approval
Пользователь заранее одобрил.

## Контекст (решения пользователя)
1. Нарисовать красивые кнопки повышения уровня.
2. Убрать возможность апаться больше 1 раза за уровень.
3. Если окно закрыли не выбрав — внизу экрана должна быть кнопка, чтобы
   вернуться и апнуться.
4. На выбор — **5 вариантов**: улучшения, атрибуты или РЕДКО — основные
   характеристики.

## Требования

### Логика выбора
1. **Один выбор на один уровень**, строго: уровень дает ровно 1 пик; набор из
   5 вариантов фиксируется на уровень (анти-реролл уже есть — распространить
   на новый размер). Несколько накопленных уровней = несколько последовательных
   окон, по одному пику каждое.
2. **Состав 5 вариантов**: микс из пула улучшений оружия/класса и вторичных
   атрибутов; **редко** (порядка 10-15% на слот) — основная характеристика
   (Сила/Ловкость/Интеллект/Восприятие/Энергия/Знание/Выносливость/Лидерство).
   Редкие слоты пометить визуально (рамка/свечение тира).
3. **Отложенный выбор**: окно можно закрыть (Escape/кнопка «Позже») — пики НЕ
   сгорают; внизу экрана (в бою и вне боя) появляется заметная кнопка
   «Повышение уровня (N)» — открывает окно с тем же зафиксированным набором.
   Существующую FAB-стрелку прокачки согласовать с этой кнопкой (не дублировать:
   FAB и есть точка возврата — переоформить и закрепить внизу).

### Вид
4. **Красивые кнопки-карточки**: 5 карточек в ряд (или 3+2 на узких экранах)
   в UI-ките D&D — иконка, название, описание эффекта, превью чисел; hover/
   pressed состояния; карточка кликабельна целиком.
5. Если текущих рамок UI-кита не хватает для «красиво» — заказ нового арта
   ТОЛЬКО задачей для Codex Design (железное правило, D&D-стиль, с референсами),
   handoff-файлом; интеграция после.
6. Тесты: 1 пик за уровень (второй раз окно не дает выбрать), фиксация набора
   при закрытии/возврате, очередь из нескольких уровней, редкость основных
   характеристик (статистически на большом сэмпле), кнопка возврата появляется/
   исчезает; smoke зеленые.

## Files / Assets / IDs
- `scripts/ui_screens.gd` (окно level-up, кнопка возврата, FAB),
  `scripts/player.gd`/`scripts/progression_data.gd` (пики, пул 5, редкость),
  UI-кит `assets/sprites/ui/frames/global/`.

## Acceptance Criteria
- [ ] Ровно один выбор за уровень; 5 вариантов; характеристики выпадают редко и помечены.
- [ ] Закрыл — не потерял: кнопка внизу возвращает к тому же набору.
- [ ] Карточки красивые (UI-кит/новый арт через Codex), кликабельны целиком.
- [ ] Тесты логики и редкости; smoke зеленые.
