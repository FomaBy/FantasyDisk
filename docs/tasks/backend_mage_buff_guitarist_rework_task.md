## Контекст
Решения пользователя:
1. Маг сейчас слабее Берсерка — усилить: «увеличить базовое количество лучей или AoE-взрывов».
2. Бас-гитара Гитариста — «полная калька Берсерка» (круговой пульс как молот):
   урон убрать в минимум, гитарам дать скорость.
3. Усилитель (sound_amp) должен оставаться на земле какое-то время, и их
   количество должно расти от параметра Лидерство (механика уже есть для
   саммонов: `scripts/player.gd:437` — `base_max_summons + floor(leadership / 4)`).

Конфиги: `scripts/progression_data.gd` — DARK_MAGE_WEAPONS (dark_book 1.05/1.31s,
cursed_skull 0.75/0.99s + 4 DoT, dark_wand beam 1.18/1.54s pierce 5),
GUITARIST_WEAPONS (electric_guitar 1.0/0.96s, bass_guitar pulse 0.92/1.34s radius 280,
sound_amp 0.82/1.60s).

## Требования

### Темный Маг — усиление
1. `dark_wand`: базовое количество лучей 1 → **2** (веер с небольшим углом между лучами);
   при необходимости чуть снизить урон одного луча, но суммарный DPS должен вырасти.
2. `dark_book`: добавить **+1 одновременный AoE-взрыв** (второй снаряд в другую
   ближайшую цель) или эквивалентное усиление числа взрывов.
3. `cursed_skull` — по усмотрению: легкое усиление (например, +1 DoT-тик), если
   после пп.1-2 он станет очевидным аутсайдером.
4. Целевой баланс: скорость зачистки стандартной волны Магом сопоставима с
   Берсерком с мечом (±15%).

### Гитарист — идентичность
5. `bass_guitar`: `damage_multiplier` 0.92 → **~0.30** (минимальный урон).
   Взамен — скорость: `fire_interval` 1.34 → **~0.85** и/или passive
   `attack_speed_multiplier` вместо текущего `defense_flat`. Контроль (knockback)
   сохранить — идентичность баса: частый слабый пульс-контроль.
6. `electric_guitar`: тоже сдвинуть в скорость — passive attack_speed 1.08 → **~1.15**
   или ниже `fire_interval`; урон не повышать.
7. `sound_amp`: переделать в **деплойный объект**:
   - усилитель ставится на землю и **остается жить ~6-8 секунд**, пульсируя самостоятельно;
   - **одновременное количество усилителей** = 1 + floor(Лидерство / 4)
     (переиспользовать паттерн max_summons из `scripts/player.gd:437`);
   - при превышении лимита — самый старый исчезает;
   - усилители должны корректно чиститься при смене экрана/паузе/конце боя.
