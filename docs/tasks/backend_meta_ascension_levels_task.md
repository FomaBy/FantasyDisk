# Back-end Task: Метапрогрессия — 10 Уровней Возвышения

Статус: выполнена 2026-06-10. ASCENSION_LEVELS (10 уровней x 3 персонажа) в progression_data.gd, сохранение в user://fantasydisk_meta.cfg через scripts/meta_progression.gd, применение бонусов при старте забега, ascension на карточке персонажа и экране победы, smoke test tests/meta_progression_smoke_test.gd, реестр обновлен.
Роль: Back-end (числа и состав наград согласовать с Design при необходимости)
Создано: 2026-06-10

## Проблема

GDD задает метапрогрессию как 10 уровней возвышения на персонажа, где каждый следующий уровень включает бонусы предыдущих. Сейчас реализован только первый шаг для Берсерка (открытие ascension-уровня после победы над боссом).

## Цель

1. Data-driven таблица ascension-уровней (1-10) для Берсерка, Темного мага и Гитариста в `scripts/progression_data.gd` (или отдельном конфиге): каждый уровень — стабильный ID, название, описание и бонусы (стартовые статы/моды).
2. Meta points начисляются за победу над боссом; сохранение между сессиями (ConfigFile/user://).
3. Применение суммарных бонусов открытых уровней при старте забега.
4. UI: отображение текущего уровня возвышения на карточке выбора персонажа.

## Требования

- Все ascension-уровни заносятся в `docs/design/content_registry.md` со стабильными ID.
- Баланс бонусов — рабочий первый проход, отметить в `docs/design/mechanics_extract.md`.
- Smoke-тест на загрузку/применение мета-сейва, оба существующих smoke-теста зеленые.
- Обновить `docs/design/current_game_state.md` (раздел «Метапрогрессия»).

## Критерий приемки

- Победа над боссом увеличивает meta-прогресс, виден следующий уровень.
- Перезапуск игры сохраняет прогресс.
- Бонусы уровней реально влияют на стартовые статы забега.
