## Контекст (запрос пользователя)
«Пересмотреть очки для мета-прогрессии: давать 1 очко за прохождение возвышения
любым классом (новое возвышение)».

Сейчас (scripts/meta_progression.gd `record_boss_victory` 138-151):
- +1 `meta_points` и +1 `skill_points` за КАЖДУЮ победу над боссом (даже повторную
  на уже пройденном уровне → можно фармить очки на одном уровне);
- отдельно растёт `ascension_levels[character_id]`: если `run_level == completed`
  (бой на текущем максимуме класса), `completed += 1` (открывается новое возвышение).

## Требования
1. **Очко меты давать ТОЛЬКО за НОВОЕ возвышение**: +1 очко (meta/skill point)
   начисляется, когда персонаж ВПЕРВЫЕ проходит ещё не пройденный уровень
   возвышения (т.е. в ветке, где `completed` инкрементится — `run_level == completed`).
   Повторная победа над боссом на УЖЕ пройденном уровне → **0 очков** (без фарма).
2. «Любым классом»: засчитывается для каждого класса по его прогрессу возвышений
   (per-character `ascension_levels`), суммарно по всем классам. Первый клир,
   открывающий возвышение 1, считается «новым возвышением» (тоже +1).
3. Не давать очки за то, что не является новым прогрессом (повторы/гринд).
4. Согласовать экономику древа меты: поскольку очков станет МЕНЬШЕ (нет фарма),
   при необходимости пересмотреть стоимость узлов/выдачу, чтобы прогрессия дерева
   оставалась осмысленной (координация с SCRUM-360 классовой прогрессией и
   SCRUM-358 ребалансом возвышений). Решение по балансу задокументировать.
5. Сохранение/загрузка meta_points/skill_points/ascension_levels не сломать;
   обратная совместимость со старыми сейвами.
6. Тест (meta_progression smoke): первое прохождение нового уровня даёт +1 очко;
   повтор того же уровня даёт 0; разные классы копят независимо; суммарный потолок
   очков = сумма max-возвышений по классам. runtime_smoke зелёный.
7. CHANGELOG; current_game_state; systems/progression_balance.
