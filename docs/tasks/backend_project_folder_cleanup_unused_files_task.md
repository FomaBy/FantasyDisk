## Требования

### Что считать мусором (категории)
1. **Неиспользуемые ассеты**: файлы в `assets/**` без ссылок из `scenes/*.tscn`,
   `scripts/*.gd`, `tests/*.gd`, `tools/*`, `project.godot`, `export_presets.cfg`
   с учетом ДИНАМИЧЕСКИХ путей (artifact_<id>.png, cutout/<entity>_*.png,
   shop_*, attr_*, stat_*, system_* — каталоги с шаблонной загрузкой сверять
   по игровым ID из progression_data/event_data/манифестов, а не тупым grep).
   Обнови/переиспользуй `tools/audit_unused_assets.py`.
2. **Хвосты арт-итераций**: старые превью/контрольные листы в `assets/`
   (artifact_*_preview.png разных проходов, debug sheets), которые не грузятся
   игрой — превью место в `docs/design/previews/` или в backup.
3. **Осиротевшие метафайлы**: `.import` без исходного файла, `.uid` без скрипта.
4. **Случайный мусор по всему дереву**: `.DS_Store`, `*.swp`, `icon 2.svg` и
   подобные дубликаты в корне, временные файлы инструментов.
5. **build/** (gitignored): старые backup-каталоги прошлых чисток и rig_debug
   старше текущей итерации — можно чистить с диска (но build/qa/ не трогать —
   это артефакты QA).
6. НЕ ТРОГАТЬ: `docs/**`, `tools/*.py|*.gd|*.sh` (рабочие инструменты),
   `tests/**`, `source_docs/**`, `releases/**`, `.claude/**`, `keep-awake.sh` —
   это файлы разработки, а не игры; «не используются в игре» к ним не применяется.

### Процедура (безопасная)
7. Сначала полный отчет-список кандидатов (путь + категория + причина) —
   в `docs/process/project_cleanup_report_2026_06_12.md`.
8. Кандидаты из git-отслеживаемых путей — `git rm` с перемещением копии в
   `build/cleanup_backup_2026_06_12/` (структуру сохранить); неотслеживаемые —
   просто переместить туда же.
9. После чистки: ВСЕ 4 smoke-теста + оконный запуск с проходом меню → выбор героя →
   карта → бой → магазин → кодекс: ни одной missing-texture (розовые квадраты),
   ни одной ошибки загрузки ресурсов в консоли.
10. Сверка с content_registry: всё оставшееся в assets/ должно быть либо в
    реестре, либо технически обосновано; расхождения — в отчет.
11. Коммит в dev: «chore: чистка проекта от неиспользуемых файлов (N файлов, отчет)».
