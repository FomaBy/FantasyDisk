## Autonomy / Approval
Пользователь заранее одобрил все изменения, включая merge в main, тег и сборки.

## Контекст
В dev накоплен большой пакет поверх v0.1.0 (экономика с тирами артефактов,
флоу забега, кодекс-энциклопедия, UX-навигация, новые иконки, анимации,
фиксы прицеливания/атрибутов/реролла). Пользователь решил выпустить это как
**0.1.1** (нумерацию не оспаривать — заголовок Unreleased в CHANGELOG
переименовать с «готовится 0.2.0» на 0.1.1).

## Требования (по порядку)

### 1. Предрелизная проверка (code freeze)
1. `git status` чистый; на доске нет задач in_progress твоей роли (если есть —
   сначала доведи/останови их).
2. Прогнать ВСЕ тесты headless: runtime, animation, meta_progression,
   melee_weapon_targeting — все зеленые. Любой красный — чинить до релиза.
3. Быстрый ручной прогон: меню → кодекс → выбор персонажа → карта → бой →
   победа → окно докачки → магазин — без ошибок в консоли.

### 2. Версия
4. `project.godot`: `config/version` 0.1.0 → **0.1.1**.
5. Версии в экспорт-пресетах: macOS `short_version`/`version`, Windows
   `file_version`/`product_version` → 0.1.1 (file_version формата 0.1.1.0).
6. `CHANGELOG.md`: раздел Unreleased → `## [0.1.1] — <сегодняшняя дата>`
   (свести дубли, читаемые формулировки); создать новый пустой Unreleased сверху.
7. `docs/design/current_game_state.md`: версия проекта 0.1.1.
8. Коммит в dev: `release: bump version to 0.1.1`.

### 3. Merge и тег
9. `git checkout main` → `git merge dev --no-ff -m "Release v0.1.1"` →
   `git tag v0.1.1` → `git checkout dev`. Конфликтов быть не должно (main не
   менялся с v0.1.0); если вдруг есть — разрешить в пользу dev.
10. Убедиться, что рабочая ветка снова dev (в каталоге работают другие агенты).

### 4. Сборки
11. `tools/build_release.sh 0.1.1` → `releases/v0.1.1/`:
    - `FantasyDisk-0.1.1-macos.dmg` (ad-hoc подпись);
    - `FantasyDisk-0.1.1-windows-setup.exe` (NSIS; помни про LC_ALL=en_US.UTF-8 — уже зашито в скрипт);
    - `FantasyDisk-0.1.1-windows.zip`.
    Скрипт собирает из тега через worktree — проверь, что он взял v0.1.1.
12. Проверка: dmg смонтировать, запустить до главного меню, в меню видна версия
    0.1.1 (если версия в меню еще не выводится — добавить мелким текстом, это
    одна строка из ProjectSettings). Windows-артефакты — собрались ненулевыми.
