2. Код-ревью изменений ui_screens/progression_data: стиль проекта, нет регрессий

3. Smoke + ручной запуск с визуальной проверкой экрана.

## Часть 2 — Уникальность классов (backend_class_identity_unique_patterns_task.md, сейчас in_progress у Codex)
4. Дождаться его done (проверять статус файла задачи; если завис >2 часов без
   движения — сообщить PM).

   незавершенной работой; перед коммитом свериться с git status.
