## Требования

### 1. Явная победа на узле
1. После успешного боя — **затемнение экрана + крупная надпись «Победа»**
   (стиль игры, золото/дарк-фэнтези), пауза ~1-1.5с или клик для продолжения,
   затем существующий флоу наград. Аналогично проверить, что поражение тоже
   читается явно (если уже есть — не трогать).

### 3. Окно докачки атрибутов за деньги после боя
2. После каждого боя (после «Победы», до/вместе с экраном наград — реши сам,
   что органичнее) показывать окно: **выбор 1 из 2 характеристик** (Сила,
   Ловкость, Интеллект, Восприятие, Энергия, Знание, Выносливость, Лидерство)
   за деньги. +1 к выбранной характеристике за покупку.
3. Кнопка **«Обновить» (reroll)**: заменяет пару предложений, доступна **2 раза**
   за окно, за деньги (дешевле покупки).
4. Цены: масштабировать от route_stage так, чтобы покупка была ощутимой тратой,
   но доступной каждые 1-2 боя (учитывай подорожание магазина из параллельной
   задачи `backend_economy_artifact_power_class_affinity_task.md`).
5. Окно можно закрыть без покупки (кнопка «Пропустить»).

### 4. Кнопка прокачки на всех экранах
6. **Желтая кнопка-стрелка вверх** (⬆, золото/желтый, заметная) доступна на всех
   экранах игры: карта, магазин, событие, костер, пауза, экраны наград.
7. Поведение: открывает экран прокачки персонажа (level-up выборы / характеристики),
   чтобы качаться можно было в любой момент, а не только когда игра заставит.
8. Если есть непотраченные level-up выборы/очки — кнопка пульсирует или имеет
   бейдж с числом; если качать нечего — кнопка видна, но открывает экран
   статов без выборов (или приглушена — реши по UX, зафиксируй).
9. В бою кнопку не показывать (там свой level-up флоу), не ломать его.
