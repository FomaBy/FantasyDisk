## Контекст (решение пользователя)
1. Вторичные (производные) атрибуты должны быть ВИДНЫ: появляться на артефактах,
   в прокачке уровня, с иконками — игрок всегда видит, что качает.
2. ВАЖНОЕ ИЗМЕНЕНИЕ ФИЛОСОФИИ: политика «нерелевантные статы скрываются от класса»
   (STAT_CLASS_RELEVANCE, задача backend_class_attribute_relevance...) ЗАМЕНЯЕТСЯ:
   теперь ВСЕ атрибуты доступны ЛЮБОМУ классу и каждый ПОЛЕЗЕН — у чужих
   атрибутов появляется классовая интерпретация. Пример пользователя:
   «количество призывов» Берсерку дает шанс призвать дополнительное оружие
   и ударить им.

## Часть 1 — Видимость вторичных атрибутов
1. Иконки `assets/sprites/ui/icons/derived/attr_*.png` показывать ВЕЗДЕ, где
   атрибут упоминается: карточки level-up, окно докачки, эффекты артефактов
   (строка эффекта с иконкой атрибута), экран статов, кодекс, тултипы.
2. Артефакты: эффекты, дающие вторичные атрибуты, должны существовать в пуле
   (аудит: каждый производный параметр встречается хотя бы на 1-2 артефактах;
   недостающие — добавить новые артефакты или расширить существующие).
3. Прокачка уровня: в пуле наград level-up есть карточки вторичных атрибутов
   с иконками и честным превью эффекта.

## Часть 2 — Универсальная полезность (матрица интерпретаций)
Каждый «классово-чужой» атрибут получает интерпретацию для каждого класса.
Направление от PM (расширяй, балансируй, придумывай лучше):

| Атрибут | Для «чужих» классов превращается в |
| --- | --- |
| Призывы/Лидерство | berserk: шанс при ударе призвать призрачное эхо-оружие, бьющее повторно (пример пользователя); assassin: фантом-двойник, дублирующий бросок чакрама; ranger: сокол, помечающий цель (+урон по ней); knight: знаменосец-аура защиты; mage/chemist: автономный фамильяр-снаряд |
| Магический урон | физикам: зачарование оружия — часть урона повторяется магическим взрывом/искрой по области |
| Звуковой урон | не-гитаристам: «боевой клич» — периодическая волна отталкивания/стана вокруг героя, сила от sound_wave_damage |
| Физический урон | магам/гитаристу: «весомость» снарядов — крупнее снаряды, больше knockback и пробой |
| Энергия | всем: ускоряет перезарядку УНИКАЛЬНОЙ механики класса (заряд рейнджера, контратака рыцаря, рывок ассасина, комбо-окно химика, drain-тик доктора) |
| DoT-параметры | не-DoT классам: удары оставляют кровотечение/ожог малой силы |
| Радиус ауры | не-ауровым: зона подбора + мини-аура замедления врагов вплотную |

4. Реализовать интерпретации в коде (player/class_weapon/derived), показать их
   ТЕКСТОМ в тултипах: игрок Берсерком видит у «+1 Призыв» описание «Шанс 15%
   призвать эхо-оружие» — никакой магии вслепую.
5. Пометки «Не работает на текущем классе» уходят в прошлое: артефакты с
   классовыми модами показывают интерпретацию для текущего класса. Механику
   affinity_mods переработать соответственно.
6. Баланс: интерпретация по силе ~эквивалентна прямому эффекту у «родного»
   класса (±25%); замеры по 2-3 атрибутам на класс — в отчет.
7. Тесты: для каждого класса — минимум 3 «чужих» атрибута дают измеримый
   эффект (эхо-оружие срабатывает, клич толкает, зачарование взрывается);
   превью совпадает с фактом.

## Результат 2026-06-12

Back-end implementation complete:
- `STAT_CLASS_RELEVANCE` больше не фильтрует rewards: все stats/rewards доступны всем классам.
- Добавлена `CLASS_INTERPRETATIONS` и вывод интерпретаций в level-up, докачке атрибутов, артефактных tooltip/notes, магазине/HUD/pause и кодексе.
- Level-up pool расширен прямыми derived-card наградами: crit, dodge, range, DoT, projectile speed, aura, buff, summon, absorb, regeneration, vampirism, ultimate scaling.
- `UIIconRegistry` покрывает все активные derived parameters; для недостающих уникальных PNG используются documented fallback-icons из существующего набора.
- Runtime hooks: magic enchant splash, universal DoT, leadership echo-hit, battle shout для sound/aura; Energy ускоряет Assassin dash, Knight counter и Ranger charge.
- `class_affinity` теперь тематика/источник артефакта, а не запрет; `affinity_mods` применяются любому классу через интерпретацию.
- Smoke coverage расширен проверкой universal interpretations, icon coverage и доступности derived rewards.

Баланс-замер/оценка: интерпретации сделаны мягче прямых «родных» механик, чтобы не ломать class identity: magic enchant у физиков ~18% magic damage, universal DoT ~14% dot damage per tick, leadership echo ~34% class damage с частотой от summon amount, battle shout gated cooldown/radius. Для родственных классов коэффициенты выше или прямые механики уже остаются в weapon kit.
