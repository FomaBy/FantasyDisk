## Требования

### Дисплей
1. **Выбор монитора**: дропдаун со списком экранов (`DisplayServer.get_screen_count()`,
   имена/номера + разрешение каждого); окно переносится на выбранный экран
   (windowed — по центру экрана, fullscreen/borderless — на него же).
   Скрывать опцию, если экран один.
2. **Оконные разрешения починить**: выбор разрешения в windowed-режиме должен
   реально применять размер окна с учетом масштаба ОС и не давать окну
   вылезать за пределы выбранного монитора; разрешения больше текущего экрана —
   скрывать или дизейблить. После смены — окно по центру выбранного монитора.
3. Комбинации проверять явно: windowed/borderless/fullscreen x смена монитора
   x смена разрешения; настройки сохраняются и восстанавливаются при запуске
   (user://settings, как текущие).

### Звук
4. Слайдеры громкости: **Общая**, **Музыка**, **Эффекты** (0-100%, шаг 5,
   применять через AudioServer bus volume; у AudioManager уже есть шины/каналы —
   проверь scripts/audio_manager.gd и доведи до шин Master/Music/SFX, если их нет).
5. Чекбоксы **«Музыка вкл/выкл»** и **«Эффекты вкл/выкл»** (mute шины, слайдер
   при этом дизейблится, значение не теряется).
6. Изменения слышны сразу (играющая музыка меняет громкость без перезапуска),
   сохраняются в user:// и применяются при старте.

### UX
7. Экран настроек — в общем стиле (панели, Escape = назад по навигационному стеку),
   разделы «Экран» и «Звук» визуально разделены.
