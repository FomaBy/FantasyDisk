## Контекст (скриншот пользователя, вкладка «Звук», 2026-06-12)
«Надо ползунок получше для изменения звука». На скриншоте видно, что слайдер
фактически нечитаем и неудобен:
- У «Общая громкость» виден ТОЛЬКО грабер у левого края — ТРЕК НЕ ВИДЕН вовсе
  (нет полосы, по которой ползать); строка выглядит пустой.
- У «Музыка»/«Эффекты» грабер прижат к правому краю, трека тоже не видно —
  непонятно, где начало/конец шкалы и сколько сейчас выставлено без чтения
  процентов.
- Подпись чекбокса «звук» не объясняет, что это (mute?).

Код: `ui_screens.gd::_add_volume_row` (~1146, 1253-1259), ассеты
`assets/sprites/ui/icons/system/ui_slider_track.png` / `ui_slider_grabber.png`
(стайлбоксы могли не примениться или трек прозрачный/нулевой высоты).

## Требования
1. **Видимый трек на всю ширину слайдера** с заливкой до текущего значения
   (filled-часть визуально отличается от пустой) — на любом разрешении и в
   любой теме. Понять и исправить, почему сейчас трек не отрисовывается.
2. **Удобное управление**: клик по любому месту трека ставит значение; драг
   плавный; зона хвата грабера крупная (не меньше 32px); стрелки клавиатуры
   меняют значение при фокусе; шаг 5% оставить или уменьшить до 1-2%.
3. Процент значения — рядом со слайдером (уже есть), обновляется живо при
   драге; звук меняется в реальном времени, не после отпускания.
4. Чекбокс «звук» переименовать понятно («Выкл.» / иконка перечеркнутого
   динамика) и убедиться, что mute и слайдер не конфликтуют (снятие mute
   возвращает прежнее значение).
5. Единый вид всех трёх рядов (Общая/Музыка/Эффекты): одинаковая геометрия,
   выравнивание ползунков по одной сетке (на скриншоте мастер-ряд выглядит
   иначе, чем остальные).
6. Тест (smoke): фактическое дерево — у каждого VolumeSlider_* есть видимый
   стайлбокс трека ненулевой высоты, значения связаны с настройками
   (изменение слайдера меняет user://settings.cfg значение).
7. CHANGELOG (Unreleased).
