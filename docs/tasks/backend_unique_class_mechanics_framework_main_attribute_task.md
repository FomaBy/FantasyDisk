## Контекст (запрос пользователя)
«Придумать МАКСИМАЛЬНОЕ количество уникальных геймплейных механик для персонажей,
переделать их поведение, оружие и анимации. Геймплей на всех персонажах должен
быть уникальным и на любом оружии тоже. Сфокусироваться на ОСНОВНОЙ характеристике
персонажа и в её стиле делать скилы».

## Требования
1. Для КАЖДОГО из 17 классов определить ОСНОВНУЮ характеристику (из конфигов) и
   уникальную геймплейную идентичность В ЕЁ СТИЛЕ: набор скиллов/механик,
   вытекающих из главного атрибута (сила → телесный напор; ловкость → скорость/
   мобильность; интеллект → магия/контроль; знание/восприятие → точность/крит и
   т.д.). Зафиксировать таблицу «класс → основной атрибут → механ-идентичность».
2. **Максимум уникальных механик**: каждому классу — отличный от остальных набор
   (не дублировать паттерны). Переделать поведение там, где сейчас generic.
3. **Уникальность на каждом оружии**: 3 оружия класса дают РАЗНЫЙ стиль игры
   внутри идентичности класса (не три варианта одного и того же).
4. Это РАМОЧНАЯ задача: спроектировать систему/таблицу и список под-задач
   (по классам/архетипам), часть реализации вынести в дочерние таски
   (melee/summoner/auras/анимации/арт) — создать их как 0.1.5.
5. Все механики проверяются глобальным balance smoke (урон/выживаемость) — без
   выбросов за коридоры.
6. CHANGELOG; mechanics_extract (идентичности классов); docs.
