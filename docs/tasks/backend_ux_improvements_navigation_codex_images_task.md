## Требования

### Конкретные правки (обязательные)
1. **Escape = назад**: на каждом экране Escape возвращает на предыдущий экран
   (настройки → меню, выбор оружия → выбор персонажа, кодекс → меню, магазин/
   событие/костер → карта, где это уместно). Единый навигационный стек, а не
   ad-hoc обработчики. В бою Escape — пауза (как сейчас), не ломать.
2. **Выбор персонажа/оружия — кликабельный весь фрейм**: вся карточка персонажа
   (и оружия) — одна большая кнопка с hover-состоянием (подсветка рамки),
   а не маленькая кнопка справа/снизу. Курсор pointer, клик в любом месте карточки.
3. **Крупнее картинки**:
   - в **Кодексе**: спрайты персонажей/монстров/боссов и иконки артефактов
     заметно крупнее (сущности ~128-192px, артефакты ~96px в списке), чтобы было
     видно, что и как выглядит и используется;
   - в **игре**: проверить и увеличить, где мелко: иконки артефактов в HUD/паузе,
     иконки предметов в магазине, иконки статов — должно быть видно без прищура
     на 1600x900 и выше.

### UX-аудит (исследование)
4. Пройти все экраны игры (меню → настройки → выбор персонажа → оружие → карта →
   бой → level-up → пауза → магазин/событие/костер → победа/смерть → кодекс) и
   составить список UX-проблем по критериям: лишние клики, неочевидные действия,
   отсутствие hover/нажатых состояний, несогласованные кнопки «назад», мелкий текст,
   отсутствие подтверждений где нужно (выход из забега) и лишние подтверждения где
   не нужно.
5. Исправить найденные **дешевые и безопасные** улучшения сразу в этой задаче.
   Крупные/спорные — оформить списком в отчете для решения PM/пользователя.
6. Новый фон карты: когда Codex положит `assets/backgrounds/route_map_backdrop.png`
   (задача `codex_design_route_map_background_task.md`) — подключить его фоном
   экрана маршрутной карты (затемнение/виньетка по вкусу, узлы должны читаться).
   Если файла еще нет — заложить подключение по пути с graceful fallback на текущий фон.

## Отчет UX-Аудита (Back-end, 2026-06-11)

### Исправлено в этой задаче
1. **Escape-стек**: единый механизм `main.ui_escape_action` (Callable, сброс в _clear_ui). Настройки/кодекс/выбор персонажа -> меню; оружие -> персонажи; магазин -> покинуть узел; костер -> уйти без бонуса (симметрично пропуску магазина); победа/смерть -> меню. Событие — Escape осознанно отключен (выбор с риском обязателен по дизайну). Бой — пауза, как раньше.
2. **Карточки персонажей** — целиком Button с hover-подсветкой (золотая рамка), pointer-курсор, стрелка-индикатор вместо кнопки «Выбрать»; портрет увеличен 112->128. Выбор оружия уже был полнокнопочным — получил pointer.
3. **Pointer-курсор** на всех кнопках через _make_button.
4. **Размеры картинок**: кодекс 176/150/96px (персонажи/монстры/артефакты), HUD-артефакты 48px, пауза 56px, магазин 100px (слот 164x186).
5. **Фон карты** route_map_backdrop.png подключен с затемнением 0.62 и graceful fallback (файла пока нет — включится сам при появлении).
6. Кнопка настроек «Back» -> «Назад» (была единственная англоязычная среди русских).
7. Подтверждение «Завершить забег» — проверено: уже реализовано (_show_end_run_confirm в pause_stats_menu), не дублировал.
8. Smoke-тест дополнен цепочкой Escape-навигации и проверкой кликабельности/hover карточки.

### Отложено на решение PM/пользователя (спорное или крупное)
- Подсказка «Esc — назад» на экранах: полезно новичку, но визуальный шум; если делать — единым стилем через Design.
- Экраны победы/смерти: по одной кнопке; стоит развести «Новый забег» и «В главное меню» как отдельные действия.
- Экран настроек: тексты подсказок rebind на английском — нужна общая локализация настроек.
- «Кодекс» доступен только из главного меню — из паузы в забеге был бы полезен (нужно вписать в стек паузы аккуратно).
- Магазин: в tooltip предмета не видно текущего значения изменяемого стата (сравнение «было -> станет»").
- Route map: при debug free pick индикатор F12 виден, но в обычном режиме хоткей нигде не подсказан (намеренно — debug), оставить как есть.
