## Контекст
Запрос пользователя (2026-06-12): «В конце успешного забега на экране завершения
показывать только информацию для пользователя, убрать системную информацию,
оставить только русский язык».

Сейчас `_show_victory_screen()` (ui_screens.gd:2268-2289) показывает игроку
системщину:
- англоязычное `"Meta points: %d"` (ui_screens.gd:2276);
- сырой внутренний ID баффа: `"Награда меты: бафф %s_asc_%d (применяется на
  старте забега)"` → игрок видит «бафф berserk_asc_2» (ui_screens.gd:2274);
- fallback на `character_id` вместо русского имени, если title отсутствует
  (ui_screens.gd:2270).

## Требования
1. Переписать текст экрана победы целиком по-русски, человеческим языком,
   без внутренних идентификаторов, англицизмов и технических терминов:
   - «Meta points» → русское понятие (например «Очки меты: N» — сверить термин
     с кодексом/мета-экраном, чтобы везде одинаково);
   - награда меты — описать СМЫСЛ баффа по-человечески (что именно усилится в
     будущих забегах), не имя `<id>_asc_N`; если у баффа есть описание в данных
     прогрессии — использовать его;
   - имя героя — только русский title из конфига (без fallback на id; если
     title пуст — это дефект данных, чинить данные).
2. Проверить тем же критерием ВЕСЬ текст экрана победы и баннера «ПОБЕДА»
   (`_show_victory_banner`) и экран поражения `_show_death_screen` (reason
   приходит строкой — убедиться, что все источники reason русские и без
   системщины).
3. Никакой отладочной/служебной информации на экранах конца забега (id, числа
   без подписи, технические скобки).
4. Тест (smoke): на victory-экране фактический текст Label НЕ содержит
   латинских подстрок служебного вида (`asc_`, `_id`, `Meta points`) и содержит
   ожидаемые русские заголовки. Ассертить фактическое дерево узлов/текст.
5. CHANGELOG (Unreleased) + docs/design/current_game_state.md (раздел экранов
   конца забега), если описание там есть.
