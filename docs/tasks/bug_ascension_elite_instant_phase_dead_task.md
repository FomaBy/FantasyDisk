# BUG: Возвышение 4 «Свирепые элитки» — «боевая фаза открывается сразу» не реализовано (dead modifier)

Статус: done 2026-06-12. Фикс: enemy.gd потребляет мету ascension_instant_phase (lazy в _update_elite_attack, ordering-proof — мета ставится combat_director после _ready): при true один раз обнуляет стартовый кулдаун элитки, боевая фаза (спец-атака) открывается сразу. Тест: элитка с метой на первом физтике не остаётся idle с большим кулдауном. Smoke зелёный.
Приоритет: high
Роль: Back-end
Найдено QA при тестировании: `docs/tasks/qa_review_backend_ascension_difficulty_ladder_task.md`
(исходная фича: `docs/tasks/backend_ascension_difficulty_ladder_task.md`)

## Воспроизведение
1. Старт забега на Возвышении 4 (или выше).
2. Дождаться появления элитки.
3. Наблюдать: элитка проходит обычный windup/первую фазу, НЕ открывает боевую
   фазу мгновенно.

## Ожидание / Реальность
- Ожидание (модификатор уровня 4): «Элитки: +20% HP, боевая фаза открывается
  СРАЗУ» (`elite_instant_phase = 1.0`).
- Реальность: модификатор мёртвый. `scripts/combat_director.gd:426` лишь ставит
  мету `elite.set_meta("ascension_instant_phase", ...)`, но эту мету
  `ascension_instant_phase` НИКТО не читает (grep по всему `scripts/` — единственное
  упоминание). HP-часть (`elite_hp_mult`) работает, фазовая часть — нет.

## Влияние
Возвышение 4 реализовано наполовину: вместо «+HP и моментальная фаза» даёт только
+HP. Нарушает критерий «10 кумулятивных усложнений работают и применяются».

## Предлагаемое направление фикса (для исполнителя)
В `enemy.gd` (логика фаз элитки) читать `get_meta("ascension_instant_phase")` и
при `true` пропускать windup/открывать боевую фазу немедленно. Добавить тест,
проверяющий фактический эффект (сейчас тестов на это нет).

## Окружение
Godot 4.6.3.stable. Коммит 8d5e489 (+ незакоммиченные правки). Класс — любой,
уровень возвышения ≥ 4.


## QA-Вердикт

QA: passed 2026-06-12. Фикс enemy.gd:346-348 верифицирован: lazy-потребление меты `ascension_instant_phase` в idle-ветке _update_elite_attack, single-shot через `_elite_instant_phase_applied`, ordering-proof (мета ставится combat_director после _ready). При true стартовый кулдаун обнуляется → спец-атака открывается на первом же тике в trigger_range. runtime_smoke + 5 сьютов зелёные. Багов нет.
