# BUG: Селектор возвышения позволяет выбрать закрытый уровень (кнопка «+» не клампится)

Статус: done 2026-06-12. Фикс: кнопка «+» в селекторе клампит к максимуму selectable среди всех героев (ui_screens), плюс защитный кламп в main.reset_run_ascension к ascension_selectable_max выбранного героя — даже если уровень выставлен программно, забег не стартует на закрытом уровне. Тест: reset_run_ascension режет уровень 9 до selectable_max берсерка. Прогрессия не затрагивалась (и не была сломана). Smoke зелёный.
Приоритет: normal
Роль: Back-end
Jira: SCRUM-61
Найдено QA при тестировании: `docs/tasks/qa_review_backend_ascension_difficulty_ladder_task.md`
(исходная фича: `docs/tasks/backend_ascension_difficulty_ladder_task.md`)

## Воспроизведение
1. Свежий профиль/персонаж (ни одной победы над финальным боссом → `selectable_max = 1`).
2. Экран выбора героя → выбрать персонажа → жать кнопку «+» возле «Возвышение».
3. Счётчик растёт до 10 (жёсткий кап), а не до `selectable_max` персонажа.
4. Нажать «Начать» — забег реально стартует на выбранном (незаоткрытом) уровне.

## Ожидание / Реальность
- Ожидание (критерий исходной задачи): «Селектор возвышения в выборе героя НЕ
  даёт выбрать закрытый уровень» — кнопка «+» должна упираться в
  `ascension_selectable_max(character_id)`.
- Реальность: `scripts/ui_screens.gd:303` —
  `game.selected_ascension_level = mini(game.selected_ascension_level + 1, 10)`
  (жёсткий 10, без клампа к selectable_max). Переклампивание есть только при
  СМЕНЕ персонажа (`scripts/ui_screens.gd:1159`), но не при нажатии «+» и не при
  старте забега: `apply_ascension_bonuses → reset_run_ascension()`
  (`scripts/main.gd:460`, `:446`) берёт `selected_ascension_level` как есть.

## Влияние
Прогрессию/сейв НЕ ломает: победа над боссом всё равно даёт максимум +1
(`meta_progression.gd:55-56`), пропустить ступени разблокировки нельзя. Игрок лишь
добровольно усложняет себе забег. Но нарушает явный acceptance-критерий фичи.

## Предлагаемое направление фикса (для исполнителя)
В обработчике «+» (`ui_screens.gd:303`) заменить жёсткий `10` на
`game.ascension_selectable_max(game.selected_character_id)`. Для подстраховки —
клампить `selected_ascension_level` к selectable_max и в `reset_run_ascension()`.

правки `scripts/main.gd`, `scripts/cutout_rig_2d.gd`). Разрешение/класс — любой.
