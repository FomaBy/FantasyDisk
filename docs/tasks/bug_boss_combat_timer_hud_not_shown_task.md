# Баг: HUD-таймер боя не отображается на босс-файтах (не виден 5-мин kill-timer)

Версия: 0.1.8 · Роль: bug · Контур: Claude · Приоритет: P2 · foma · Эпик: Интерфейс, экраны, локализация
Статус: done · Спринт: 0.1.8
Jira: SCRUM-799
Owner: Backend / Claude
Locked paths: scripts/ui_screens.gd (_create_combat_timer_panel)

## Что и зачем
После внедрения SCRUM-785 (элитка/босс — таймер 300с «убей или проиграл») босс
теперь проигрывается по истечении 5 минут. Но на экране во время босс-файта **нет
видимого таймера** — игрок не видит обратный отсчёт и внезапно проигрывает на 5:00
без предупреждения. Логика поражения работает, не хватает только ОТОБРАЖЕНИЯ
панели таймера в боссе. Нужно показывать обратный отсчёт 5:00 во время боя с боссом
(и элиткой) так же, как в обычном бою.

## Текущее состояние в коде
`scripts/main.gd` (SCRUM-785): в `_process` `round_time_left` декрементится во ВСЕХ
боях, включая боссовый; поражение при истечении с живым боссом/элиткой.

`scripts/ui_screens.gd`:
- `_update_hud()` (≈9599–9631) — УЖЕ считает `timer_seconds` для любого боя:
  `if game.combat_active: timer_seconds = maxi(int(ceil(game.round_time_left)),0)`
  (есть коммент «SCRUM-785: таймер показываем во всех боях, включая боссовый»),
  затем `_update_combat_timer(timer_seconds)`.
- `_create_combat_timer_panel(root)` (≈8913–8945) — ПРОТИВОРЕЧИТ этому: содержит
  ранний выход для босса:
  ```
  # На босс-файтах таймера нет — панель не создается вовсе.
  if game.boss_combat_active:
      game.timer_label = null
      return
  ```
  → на боссе `CombatTimerPanel`/`timer_label` не создаются, `_update_combat_timer`
  обновлять нечего, отсчёт не виден. Рассинхрон появился при SCRUM-785 (правка
  `_update_hud` попала, а `_create_combat_timer_panel` осталась со старым гейтом —
  правку HUD снесло rebase-конфликтом при мердже 36b05c66).

## Что сделать — по шагам
1. Убрать (или инвертировать) ранний выход по `boss_combat_active` в
   `_create_combat_timer_panel` — панель таймера должна создаваться и для боссовых
   (и элитных) боёв тоже. `game.timer_label` должен ссылаться на валидный Label.
2. Убедиться, что формат обратного отсчёта корректен для 300с (показывает `5:00`…`0:00`,
   формат M:SS), а не только SS. Проверить `_update_combat_timer` (≈9656) на форматирование
   минут (если сейчас только секунды — добавить M:SS для значений ≥60с).
3. Проверить «alarm»-состояние (мигание/цвет при малом остатке) — работает для боссового
   таймера тоже (последние ~10–15с).
4. Не ломать раскладку/скейл HUD (SCRUM-666/778). Панель таймера уже позиционируется
   в `_apply_combat_hud_layout` (≈9077) — она найдётся по имени `CombatTimerPanel`,
   т.к. теперь создаётся и в боссе.
5. Прогнать smoke/HUD-тесты headless (один инстанс, `FSD_GODOT_SLOTS=1`).
