## Контекст
Задача backend_elite_reward_center_screen помечена done, автотест ассертит
PRESET_CENTER/якоря — но РЕАЛЬНЫЙ рендер (скриншот пользователя, оконный запуск
из редактора Godot) показывает: окно «Трофей элитки» прижато к правому нижнему
углу, большая часть панели за пределами экрана, виден только левый верхний кусок.

## Воспроизведение
1. Запустить игру (из редактора, окно ~1469x908 по скриншоту).
2. Убить элитку в бою.
3. Окно «Трофей элитки» появляется не по центру, а в правом нижнем углу,
   карточки обрезаны краем экрана.

## Ожидание / Реальность
- Ожидание: модальное окно с 3 артефактами строго по центру вьюпорта на ЛЮБОМ
  размере окна.
- Реальность: окно смещено вправо-вниз, выходит за экран.

## Подсказки по корню (проверить)
- PRESET_CENTER применен ДО задания size/custom_minimum_size → якорные офсеты
  посчитаны от нулевого размера; при реальном размере панель уезжает.
  Правильно: задать размер, потом центрировать, или anchors 0.5/0.5 +
  offset = -size/2, или контейнер-CenterContainer на весь экран.
- Возможен конфликт со stretch-режимом viewport (canvas_items) при нестандартном
  размере окна редактора.
- ВАЖНО: предыдущий автотест прошел, а рендер сломан — тест проверял пресет,
  а не фактическую позицию. Новый тест должен ассертить ФАКТИЧЕСКИЙ rect:
  panel.get_global_rect().get_center() ≈ viewport_size/2 (допуск ±2px) при
  нескольких размерах окна (1280x720, 1469x908, 2560x1440).

## Требования
1. Починить центрирование на любом размере окна (включая нестандартные размеры
   окна редактора).
2. Тест на фактический global_rect-центр при 3 размерах вьюпорта.
3. РЕАЛЬНЫЙ скриншот оконного запуска с окном награды по центру — в build/qa/
   (если оффскрин-кадр в окружении не снимается — зафиксировать global_rect
   числами в логе и пометить, что пиксельная сверка за плейтестом).
4. Проверить этим же паттерном ДРУГИЕ модальные окна (level-up, докачка, мета-
   заглушка) — не центрируются ли они тем же сломанным способом.

## Результат

Done 2026-06-12.

- `EliteArtifactRewardPanel` больше не центрируется через `PRESET_CENTER` до расчета размера. Панель теперь лежит внутри full-rect `CenterContainer` (`EliteArtifactRewardCenter`), поэтому фактический `global_rect` центрируется layout-системой на любом размере viewport.
- `tests/runtime_smoke_test.gd` расширен regression-проверкой фактического `panel.get_global_rect().get_center()` против `viewport_size / 2` для `1280x720`, `1469x908` и `2560x1440` через изолированные `SubViewport`; также проверяется, что панель целиком остается внутри viewport.
- Другие модалки проверены на этот паттерн: `AttributeShopPanel`, `LevelUpPanel` и generic `_create_menu_box` используют явные `0.5` anchors + симметричные offsets, а не сломанный `PRESET_CENTER` + deferred min-size подход.
- Headless screenshot в окружении не снимался; вместо него оставлен числовой QA-log: `build/qa/elite_reward_window_offcenter_rect_log.md`.
