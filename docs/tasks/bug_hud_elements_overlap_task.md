## Контекст
Скриншот пользователя (бой, широкое окно): панель таймера (центр-верх)
НАПОЛЗАЕТ на панель ULT (правый край левого ресурсного HUD). Ресурсный HUD
анкорится слева (ui_screens.gd:3646, Vector2(20,18)), таймер — к центру
(anchor 0.5, offset ±86): при недостаточной ширине окна зоны пересекаются.
Также проверить правый верх: ряд иконок артефактов (ArtifactHudRow, правый
край) может пересекаться с HP-барами врагов — это world-space, не чинить, но
плашки HUD между собой пересекаться не должны.

Одновременно вводится ПРАВИЛО (см. qa_protocol.md): элементы интерфейса не
должны наползать друг на друга — на любом поддерживаемом разрешении.

## Воспроизведение
1. Запустить бой в окне, где (ширина/2 - 86) < правый край ресурсного HUD
   (например ~1900x573 как на скриншоте, или 1280x720 — проверить).
2. Таймер перекрывает панель ULT.

## Требования
1. Починить верхний HUD: ресурсная панель, таймер, бейдж возвышения, ряд
   артефактов НЕ пересекаются ни при каком поддерживаемом размере окна
   (минимум 1152x648/1280x720 до ultrawide). Решение — на выбор исполнителя:
   единый HBox-лейаут верхней полосы, либо таймер уступает (сдвиг вправо от
   ресурсной панели при нехватке места), либо адаптивное сжатие ресурсной
   панели. Зафиксировать выбор в отчёте.
2. **Общий тест-хелпер «no-overlap»**: функция, собирающая видимые top-level
   Control-плашки HUD и ассертящая попарную непересекаемость их фактических
   `global_rect` (допуск 0-2px). Прогнать в smoke для боевого HUD на
   3 размерах окна (1152x648, 1280x720, 2560x1440) и для боя с боссом
   (там вместо таймера — бейдж возвышения).
3. Хелпер сделать переиспользуемым для других экранов (магазин, hero select)
   — подключение к остальным экранам можно отдельным шагом, но API готово.
4. CHANGELOG; скриншот/дамп rect'ов в build/qa/.
