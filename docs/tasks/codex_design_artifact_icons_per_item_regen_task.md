## Цель (решение пользователя)
Взять КАЖДЫЙ артефакт ПО ОЧЕРЕДИ и перерисовать его с нуля. Картинка артефакта:
**полноценная и законченная** (предмет целиком, ничего не обрезано), **без фона**,
**цельная** (один связный предмет) и **без лишних деталей** (никаких пьедесталов,
осколков, брызг, частиц вокруг, парящих фрагментов). Образ предмета — от его
НАЗВАНИЯ и эффекта, стиль — общий стиль персонажей и монстров игры.

## Список
Все `artifact_<id>.png` в `assets/sprites/ui/icons/artifacts/` (52 шт.).
Название и эффект каждого id — `ProgressionData.ARTIFACTS` в `scripts/progression_data.gd`
(+ `docs/design/content_registry.md`).

## Требования К Каждой Иконке
1. **Один цельный предмет**, соответствующий названию (Fox Boots — пара сапог,
   Cursed Crown — корона, Glass Orb — сфера на простой подставке, если подставка
   часть предмета). Ничего вокруг: ни земли, ни камней, ни летающих кусочков.
2. **Законченность**: предмет целиком в кадре с запасом, никакая часть не
   уходит за край канвы (bbox предмета не касается краев).
3. **Без фона**: полностью прозрачный фон; без белых/светлых ореолов по контуру;
   допустимо только легкое цветное свечение, если оно по смыслу предмета
   (магический кристалл и т.п.), и оно тоже не касается краев.
4. **Стиль**: как персонажи/монстры игры — мрачное фэнтези, живописная отрисовка,
   глубокие тени, один источник света сверху-слева. Референсы:
   `assets/sprites/characters/berserk_unarmed.png`, `assets/sprites/elites/*.png`.
5. **Без лишних деталей**: минимум декора, читаемый силуэт; узнаваемость
   при 40px обязательна.
6. Технически: PNG 256x256 RGBA, замена на месте, имена не менять, `.import`
   не трогать, без текста/watermarks.

## Порядок Работы (поштучно!)
1. Идти по списку по одному артефакту: сгенерировать → самопроверка ЭТОЙ иконки
   (размер 256x256, alpha-фон, bbox не касается краев, один связный объект,
   соответствие названию) → следующий. Не генерировать пакетно без проверки.
2. Вести в этом файле прогресс-лог: каждые 10 закрытых id дописывать строку
   «обработано N/52».
3. После всех 52: контрольный лист-сетка (256 и 40px) в
   `assets/sprites/ui/icons/artifact_per_item_preview.png`, smoke-тест.
4. Коммит НЕ делать (sandbox). Статус: review + резюме (сколько перегенерировано,
   какие id потребовали повторов).
