## Контекст
Решение пользователя (№5): новое — третье и целевое — направление иконок
артефактов. Предыдущее (мрачный дарк-фэнтези набросок) заменяется.

**Целевой стиль — как иконки интерфейса здоровья/опыта/денег и статов:**
- `assets/sprites/ui/icons/derived/attr_health_point.png` — глянцевая колба-сердце;
- `assets/sprites/ui/icons/stats/stat_leadership.png` — богатое знамя с золотом;
- остальные в `assets/sprites/ui/icons/stats/` и `derived/`.
Это сочные, живописные RPG-иконки предметов: яркий объем, глянцевые блики,
читаемый силуэт, насыщенный цвет, темный тонкий контур.

## Требования
1. Перегенерировать все иконки `assets/sprites/ui/icons/artifacts/artifact_*.png`
   (те же имена, замена на месте, 256x256 PNG, прозрачный фон).
2. **Предмет должен быть мгновенно узнаваем**: меч — меч, сапоги — сапоги,
   плащ — плащ, монета — монета. Тип предмета бери из названия/эффекта
   (`scripts/progression_data.gd` ARTIFACTS) — там же смотри поле **tier**.
3. **Чем выше tier — тем круче выглядит** (главное требование пользователя):
   - **Tier 1**: простой добротный предмет — чистые материалы, без украшений;
   - **Tier 2**: зачарованный — магическое свечение, орнамент, самоцвет;
   - **Tier 3**: легендарный — богатая отделка (золото, филигрань), выраженная
     аура/частицы, драгоценные камни; иконка должна «кричать», что предмет особенный.
   Визуальный язык тиров единый по всему набору (одинаковый тип свечения/отделки).
4. Один источник света, единая степень детализации, без текста и watermarks.
5. Читаемость при 40px (HUD) обязательна.

## Design Review / 2026-06-11 — Changes Requested (раунд 2)

Техническая часть принята: 52 файла, 256x256, RGBA, имена сохранены, тиры из данных
подхвачены, smoke зеленый. Механика тиров работает и различима (чистый предмет ->
цветной ободок/самоцветы -> аура с частицами) — сохранить.

НЕ принят арт-стиль — главное требование пользователя (v3 = сочный глянцевый RPG-стиль
референсов) не выполнено. Доказательства: side-by-side `build/rig_debug/v3_vs_refs.png`
(референсы яркие, глянцевые, полный диапазон от глубокой тени до белого блика —
v3 приглушенно-матовый, коричнево-серый, по факту продолжение отклоненного v2);
`build/rig_debug/v3_40px_dark.png` (tier-1 в 40px сливается с темным фоном паузы).
Грейдинг-пасс проверен и не спасает (`v3_gloss_test.png`) — матовая отрисовка в основе.

Конкретные remarks для перегенерации:
1. НАСЫЩЕННОСТЬ И ДИАПАЗОН: локальные цвета материалов в полную силу (золото — желтое,
   кровь — алая, лед — голубой, кожа — теплая коричневая); диапазон значений от почти
   черной тени до белого блика. Сверить гистограмму с `attr_health_point.png`.
2. ГЛЯНЕЦ ОБЯЗАТЕЛЕН: на каждом предмете specular-блик (яркий мазок/точка как на
   колбе-сердце) + светлая кромка сверху-слева. Никаких матовых поверхностей.
3. ЧИТАЕМОСТЬ НА ТЕМНОМ: светлота самого предмета (не ободка) должна держать силуэт
   на темно-фиолетовом фоне паузы при 40px. Tier-1 сейчас проваливается.
4. ТИРЫ: механику оставить как есть, НО tier-1 должен быть сочным сам по себе;
   tier-3 — золото/филигрань НА предмете, аура вторична.
5. УЗНАВАЕМОСТЬ (точечно): `old_codex` — опять панель, нужна закрытая книга
   (корешок, страницы, застежка); `phantom_step` — сапоги не читаются (темное на
   темном + аура съедает силуэт); `blood_pact` — табличка без признаков «договора»,
   добавить свиток/печать/кровавую подпись.
6. Не менять: размеры/имена/alpha/preview-процедуру — техчасть в порядке.

Набор НЕ закоммичен (рабочее дерево). После round 2 — повторное Design review.
