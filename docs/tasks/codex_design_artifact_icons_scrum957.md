## Explicit OpenAI Images Override

The active Jira issue explicitly requests OpenAI Images. This is the recorded
exception to the normal PixelLab-first icon route. Each icon is generated by a
separate call through
`skills/codex/fantasydisk-asset-generator/scripts/generate_asset.py` using
`gpt-image-2`, `quality=high`, `1024x1024`, and `--no-task`. A flat removable
chroma background is required; no PixelLab/manual fallback is allowed if the API
is unavailable.
