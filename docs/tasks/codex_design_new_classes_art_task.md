## Технические Требования
1. Единый стиль с существующими персонажами (палитра, детализация, контур).
2. Прозрачный фон, без текста/watermarks, один источник света (сверху-слева).
3. У персонажей ноги в нейтральной стойке, разделены (под cutout-нарезку
   `tools/slice_rig_cutouts.py` — торс/руки/ноги должны быть различимы).
4. Коммит НЕ делать (sandbox): статус review + резюме в этом файле,
   ревью/нарезку/коммит делает Claude-Designer.
