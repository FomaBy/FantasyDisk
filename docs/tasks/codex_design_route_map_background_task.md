## Цель
Сгенерировать фоновое изображение для экрана вертикальной маршрутной карты:
**нейтральное, жутковатое** (creepy), в дарк-фэнтези стилистике игры.

## Спецификация
1. Файл: `assets/backgrounds/route_map_backdrop.png`, PNG **2560x1440**.
2. Настроение: мрачная пустошь/туманное предгорье в сумерках — выжженная земля,
   кривые мертвые деревья, намеки на кости/руины в тумане, низкая видимость.
   Жутко, но **нейтрально**: без конкретных монстров, лиц, текста, сюжетных объектов.
3. Референсы стиля: `assets/backgrounds/field_*.png` (боевые фоны),
   `assets/sprites/ui/screens/screen_event_background.png`, элитки/боссы.
4. КРИТИЧНО — низкий контраст и затемненность: поверх фона рисуются узлы карты,
   линии маршрута и иконки — фон не должен с ними спорить. Центральная вертикальная
   полоса (~50% ширины) — самая спокойная зона (там идет маршрут), детали — по краям.
   Общая яркость заметно темнее боевых фонов.
5. Без швов и артефактов; допустим легкий градиент тумана снизу вверх.
