## Контекст (что сейчас)

Боевой HUD (верхняя полоса во время боя) громоздкий: карточная структура с четырьмя
отдельными фреймами-рамками занимает много места и перекрывает игровое поле.

Текущая реализация — `scripts/ui_screens.gd`:
- `_create_hud()` — точка входа (≈ стр. 9214).
- `_create_resource_hud_panel()` + `_add_hud_resource_card()` / `_add_hud_money_card()`
  (≈ 9683–9846): панель `RunResourceHud` 820×84 @2K, внутри 4 карточки-PanelContainer
  (HP 250×56, XP 220×56, Gold 195×56, ULT 260×56), у каждой свой фрейм
  `ui_frame_combat_hud_card_*.png` 616×286 — те самые «лишние фреймы».
- `_create_combat_timer_panel()` (≈ 9243–9285): `CombatTimerPanel` 310×144 @2K
  (фрейм `ui_frame_2k_chud_timer.png`) + `AscensionHudBadge` 164×164 @2K справа
  (2280, 52) с римской цифрой: `const ROMAN_NUMERALS := ["0","I",...]` (стр. 9240),
  `asc_text.text = ROMAN_NUMERALS[clampi(game.selected_ascension_level, ...)]` (стр. 9256).
- Обновление значений: `_update_hud()` (≈ 9965–9983), `_update_combat_timer()` (≈ 9986–10007,
  alarm-режим ≤5 сек: красный текст + пульс Tween — сохранить).
- Масштабирование: система SCRUM-666, база 2560×1440, `_scrum666_hud_scale()` (стр. 9312),
  `_layout_combat_hud()` (9393–9429), автоперелайаут на `root.resized`.

## Цель (голосовое ТЗ пользователя)

Перерисовать верхний боевой HUD: **компактно, красиво, интуитивно**, в стилистике игры
(dark fantasy / D&D), **без лишних фреймов-рамок**. На любом разрешении HUD не должен
заметно перекрывать игру.

Требования по элементам:
1. **HP — тонкий лайн-бар** с маленькой иконкой (сердце/рубин) и цифрами HP.
2. **XP — тонкий лайн-бар** с иконкой и уровнем.
3. **Ультимейт — тонкий лайн-бар** с иконкой; читаемое состояние «готов / заряжается»
   (сохранить текущую логику READY).
4. **Деньги — без бара**: маленькая иконка монеты + число.
5. **Таймер — красивый и компактный**, сохранить alarm-режим (≤5 сек: алый + пульс).
6. **Возвышение — обычная (арабская) цифра вместо римской**, с понятной мини-иконкой,
   чтобы игрок сразу понимал, что это уровень возвышения.

## Дизайн-спека (target)

Единый компактный кластер в левом-верхнем углу + таймер по центру сверху:

- Левый кластер (одна слим-подложка или вовсе без подложки, полупрозрачная тёмная
  плашка): вертикальный стек из 3 лайн-баров высотой ~14–18 px @2K трека:
  - HP (красный филл, иконка-сердце 28×28, текст «cur/max» поверх бара справа),
  - XP (изумрудный/зелёный филл, иконка-фолиант/звезда, текст «Lv N»),
  - ULT (фиолетово-синий филл, иконка-молния/руна, «READY» с мягким свечением при заряде).
- Под барами (или справа от них) строка: иконка монеты + число золота; рядом бейдж
  возвышения: мини-эмблема (крылья/пик) + арабская цифра уровня.
- Таймер: по центру сверху, компактная плашка ~200×64 @2K с мини-орнаментом
  (песочные часы), моноширинные цифры M:SS.
- Суммарная высота HUD-кластера ≤ ~120 px @2K (сейчас панель 84 + карточки в 2 слоя +
  таймер 144) — визуально ощутимо меньше и без тяжёлых рамок.
- Бар-филлы отрисовываются StyleBoxTexture без неравномерного растягивания генерённого
  арта (правило: runtime не чинит aspect растяжением по одной оси).
- Контент строго в безопасной зоне подложек (frame-content-safe-area-rule).

## Ассет-план (OpenAI + PixelLab)

Генерация двухступенчатая, как просил пользователь: реалистично-красивая база через
OpenAI gpt-image-2 (стиль существующего leather/gold UI-кита), поверх — пиксель-арт
из PixelLab MCP для мелких иконок (пиксель-арт читается чётко в 24–32 px).

- PixelLab `create_map_object` (иконки, прозрачный фон): сердце-рубин, фолиант/звезда XP,
  золотая монета, руна/молния ульты, песочные часы, эмблема возвышения (крылатый пик).
- OpenAI gpt-image-2: слим-подложка кластера (тёмная кожа+латунь, full-bleed, под 9-slice),
  трек+филл лайн-баров (HP/XP/ULT), компактная плашка таймера. Прозрачный фон,
  alpha-cleanup border-connected flood-fill (НЕ регенерация) при запечённом фоне.
- Существующие филлы `assets/sprites/ui/hud/combat_hud/ui_hud_bar_fill_*.png`
  переиспользовать, если лягут в слим-формат; иначе заменить новыми.
- Новые ассеты: `assets/sprites/ui/hud/combat_hud_v2/` + `.import`-сайдкары в коммит.
