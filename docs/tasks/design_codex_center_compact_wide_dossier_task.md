## Source Request

Прямая директива пользователя (чат, 2026-07-08, follow-up к SCRUM-879): «в кодексе
на центральном элементе я бы хотел очень краткое описание элемента и его картинка
(без превью) а блок справа надо расширить в 2 раза по горизонтали и добавить более
глубокое описание (персонажа, артифакта, монстра и т.д.)».

## Решение

1. Центральная колонка: убрать большую полупустую сцену-превью; компактный блок
   «картинка элемента (фикс-бокс, KEEP_ASPECT_CENTERED, NEAREST) + очень краткое
   описание (1–2 строки, ellipsis)»; освободившуюся высоту отдать списку записей.
2. Правая панель досье: ширина ×2 (clamp(940·s, 420, 960)); глубокое
   структурированное описание ТОЛЬКО из существующих данных (codex_data,
   ProgressionData, конфиги): персонажи — идентичность, сильные/слабые, статы,
   3 оружия с механиками, ульта; монстры — поведение и боевые параметры;
   артефакты — полный эффект/редкость/триггеры; секции с бронзовыми
   заголовками, скролл внутри.
3. Тест-контракт (matrix codex-блок, смоук) обновить под новую геометрию;
   object-first ассерты SCRUM-850 скорректировать по директиве пользователя.
