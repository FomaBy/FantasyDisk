## Source Request

Прямая директива пользователя (чат, 2026-07-08, follow-up к SCRUM-881): (1) «Пересмотри
экран кодекса, убери предпросмотр элемента на центральном блоке — там должен просто
список»; (2) «На экране глоссарий не надо всплывающие окна с подсказками по всем
терминам»; (3) «В целом в центре в кодексе надо краткое описание, справа подробное
с картинкой, а слева список разных тем»; (4) «В атласе персонажа слева, где список
героев, надо сделать чтобы все герои помещались в 2 столбца иконок».

## Решение

- Кодекс (агент): удалить центральный блок предпросмотра (CodexCenterOverviewRow:
  стейдж+сводка) — центр = только список карточек с краткими описаниями на всю
  высоту; глоссарий — термины обычными карточками списка, выбор показывает
  определение в правом досье, тултип-панель глоссария удалить; право — подробное
  досье с картинкой (как есть, SCRUM-881); лево — категории (как есть).
  Тест-контракты (ветка codex матрицы + смоук) обновить: убрать ассерты
  сцены/сводки, list host на всю колонку, глоссарий-карточки как обычные ряды.
- Атлас (оркестратор): лента классов слева — GridContainer в 2 столбца, все 17
  медальонов видимы без скролла на всех вьюпортах матрицы (масштаб медальона
  от высоты safe-зоны).

- [ ] Центр кодекса — только список (без стейджа/сводки), право — досье с
