# Задача Для Claude-Designer: Переосмысление Рамок, Кнопок И Окон — Контекстный D&D-Стиль

Статус: new
Создано: 2026-06-12
Автор: PM
Тип: концепт + ресёрч + арт-направление. Генерация изображений — через Codex Design
(железное правило), мышление/ресёрч/спека/ревью/интеграция — Claude-Designer.

## Autonomy / Approval
Пользователь заранее одобрил, явно попросил ПОФАНТАЗИРОВАТЬ и разрешил
подсмотреть референсы в существующих источниках в интернете (WebSearch/WebFetch —
смотреть подходы D&D/tabletop UI: официальные D&D-интерфейсы, Baldur's Gate 3,
Divinity, Darkest Dungeon и т.п. — изучать ПОДХОДЫ и настроение, не копировать
ассеты пиксельно: всё своё, сгенерированное).

## Контекст (решение пользователя)
Текущий UI-кит единый для всех экранов. Требуется переосмысление:
1. **Убрать вставки без смысла** — декоративные элементы, которые ничего не
   сообщают (случайные заклёпки, пустые виньетки, орнамент ради орнамента).
   Каждая деталь рамки должна работать на настроение конкретного экрана.
2. **Контекстные рамки/кнопки/окна** — стиль зависит от смысла экрана:
   - старт/главное меню — живое: лианы/ветви дерева оплетают кнопки;
   - смерть — жуткое: кость, трещины, тлен, холодная гамма;
   - и так далее по экранам (фантазировать).

## Требования

### Фаза 1 — Ресёрч и концепт (артефакт приёмки)
1. Изучить референсы D&D/tabletop UI в интернете (5-10 источников), выписать
   приёмы: как контекст меняет рамку, как делают «живые» обрамления.
2. Концепт-документ `docs/design/ui_contextual_concept.md`: карта экранов →
   настроение → мотив обрамления. Стартовое направление PM (улучшай):
   - **Главное меню/старт**: живая природа — лианы и ветви оплетают кнопки,
     листья на углах панелей;
   - **Смерть/поражение**: кость и тлен — рамки из потрескавшейся кости,
     кнопки-надгробия, холодный пепельный тон;
   - **Победа/награды**: лавры, золото, тёплое свечение;
   - **Магазин**: тавернное дерево/латунь (текущий кит близок — уточнить);
   - **Бой (HUD)**: минимализм — кожаные ремни/металл, ничего лишнего;
   - **Кодекс**: пергамент/книга — рамки-страницы, кнопки-закладки;
   - **Карта**: походное — верёвки, колышки, проштампованные узлы.
3. В концепте — список текущих «вставок без смысла» на удаление (аудит кита).

### Фаза 2 — Спека и генерация
4. Спека ассетов: какие 9-patch рамки/кнопки/окна нужны по контекстам
   (переиспользовать базу там, где контекст не требует своего — не плодить
   сущности: 3-4 контекстных варианта поверх базового кита достаточно).
5. Codex-задача(и) на генерацию с обязательными референсами-изображениями
   (свои источники из ресёрча — как mood, текущий кит — как технический формат).

### Фаза 3 — Интеграция
6. Подключить контекстные киты к экранам (темы в ui_screens), убрать
   бессмысленные вставки, проверить читаемость текста и кликабельные зоны.
7. Скриншоты всех ключевых экранов до/после — в лог задачи; 720p и 1440p.
8. Smoke зеленые; content_registry (новые киты), CHANGELOG.

## Acceptance Criteria
- [ ] Концепт-документ с ресёрчем, картой контекстов и списком удаляемого декора.
- [ ] Минимум 3 контекстных варианта обрамления реализованы (старт-лианы,
      смерть-кость + ещё один на выбор) поверх базового кита.
- [ ] Бессмысленные вставки удалены; каждый элемент рамки оправдан настроением.
- [ ] Скриншоты до/после; тексты читаемы, зоны кликов не уменьшились; smoke зеленые.
