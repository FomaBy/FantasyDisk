## Роль И Границы
Ты — Design-агент (спрайты, арт). Саму анимацию делает Animator,
интеграцию — Back-end. Handoff по правилам docs/process/agent_role_boundaries_and_handoffs.md.

## Контекст
Пользователь: у анимации движения мага «с ногами муть какая-то». Анимация ходьбы
не читается, потому что на спрайте ноги стоят неудобно для анимирования
(закрыты мантией / слиты / неясная постановка). Решение: перерисовать спрайт
персонажа так, чтобы ноги были удобны для анимации в будущем.

## Требования
1. Перерисовать спрайт `dark_mage` так, чтобы:
   - обе ноги были **визуально различимы** (не слиты в мантию единым пятном);
   - постановка ног — нейтральная стойка, пригодная для walk-цикла
     (ноги под корпусом, виден просвет или явная граница между ними);
   - низ мантии не скрывал колени/стопы полностью.
2. Сохранить узнаваемый дизайн и палитру персонажа, стиль игры
   (см. `docs/design/fantasydisk_design_brief.md`, правило full-art спрайтов
   в `docs/design/content_registry.md`).
3. Тот же размер и путь файла, что у текущего спрайта (замена на месте).
4. Если для walk-цикла нужны отдельные части (ноги отдельным слоем) — подготовить
   их в `assets/sprites/characters/rig_parts/` и описать в content_registry.
5. Без артефактов: лишних пикселей, halo, обрезков по краям.
