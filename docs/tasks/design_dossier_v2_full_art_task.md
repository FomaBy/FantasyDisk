## Дефект (унаследован от SCRUM-890)

Value-метки derived-чипов и рядов «Выживания» имеют `clip_text = true` БЕЗ
`custom_minimum_size.x` → в HBox рядом с именем (`SIZE_EXPAND_FILL`) метка
схлопывается в 0 px: текст установлен (headless-ассерт по `.text` зелёный),
но не рендерится. У базовых статов минимум 52 px задан — они видны.
Канон-грабли: [[godot-label-render-wider-than-string-size]].

## Решение

1. **Значения**: `custom_minimum_size.x` для value-меток derived (≥84 px)
   и «Выживания» (≥96 px); регресс-ассерт в смоуке — минимум ширины > 0.
2. **Рама**: EscapeStatsPanelFrame из плоского чипа → полая рама meta40
   (frame_border.png, draw_center=false, маргины 160·vp/base) поверх дима 0.86 —
   имя узла сохраняется (непрерывность матрицы/дампов).
3. **Портрет**: крупный (~200 px) в новой парадной раме dossier_portrait_frame
   (PixelLab, полая середина), герб класса meta40/crest_<class> в шапке карточки,
   имя героя золотом крупнее.
4. **Заполнение пустоты**: правая зона тянется на всю ширину/высоту safe-зоны;
   под сеткой 2×2 боевых параметров — панель «Снаряжение забега»: чипы
   артефактов из `player.artifacts` (icon+title, flow), пусто → приглушённая
   строка «Артефакты ещё не найдены».
5. **Плотность**: divider_ornament между секциями карточки героя, ряды 40–44 px,
   кегль ≥12, золотые значения (VALUE_*-палитра уже есть).
