## Реализация — ЗАЛОЧЕННЫЙ подход (PM продумал)
**Принцип:** макап = фон экрана (`contain-fit` под вьюпорт, тёмная подложка вокруг),
живой контент накладывается по нормализованным зонам относительно отображаемого
прямоугольника макапа → всё ровно на любом разрешении, «именно он, ничего лишнего».
- Зоны/сабзоны и аксессоры данных — в `zones_normalized.json`.
- 5 строк статов: значения живьём в бары; подписи 1-4 совпадают, 5-я (УДАЧА)
  перекрывается живой подписью; роза несёт полный профиль из 8 статов.
- **Карусель с прокруткой:** 9 видимых слотов, состояние `{offset, selected}` в
  Dictionary (мутабельно для лямбд), стрелки ◄► сдвигают окно по 17 героям (clamp),
  клик по слоту → выбор → refresh портрета/досье/розы/подсветки.
- Точка входа: `_show_character_select` сохраняет run-init, далее
  `_build_character_select_v4()`; v3-вёрстка ретайрится.
- Замена v3 + ретайр старых `HERO_SELECT_V3_*` зон после приёмки.
