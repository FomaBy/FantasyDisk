## Source Request

Прямая директива пользователя (чат, 2026-07-08, голосом): «сгенерируй реалистичную
иконку/логотип игры FantasyDisk красивым эпичным Dungeons&Dragons шрифтом в
Dark Fantasy стиле, надпись Fantasy Disk, и поменяй логотип внутри главного меню —
сейчас не нравится, как выглядит. Должно быть красиво, эстетично; надеюсь на твой
вкус».

## Решение

1. gpt-image-2 (канон-пайплайн: маджента-кей → global wipe → erode → кроп 8:3,
   tools/generate_game_logo_openai.py): 3 арт-направления одной надписи
   «FANTASY DISK» — ember-steel / molten-gold / arcane-obsidian; палитра увязана
   с фоном меню (фиолетовый аркан + янтарь), у всех рунический диск за буквами
   (отсылка к имени игры).
2. Выбор лучшего — визуально оркестратором (проверка точности надписи!),
   установка в тот же путь main_menu_title_fantasy_disk.png (слот
   MAIN_MENU_LOGO_RECT 720×270 не трогаем, тесты name-based).
3. Windowed-капчер главного меню на 2560/1920, визуальная приёмка по
   [[windowed-capture-only-visual-qa]].
