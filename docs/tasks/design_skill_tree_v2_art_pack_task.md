## Контекст

Для редизайна экрана «Древо умений» (общее дерево умений в стиле Path of Exile 1/2, граф узлов со
связями) нужен набор пиксель-арт UI-ассетов в едином Dark Fantasy / D&D стиле игры. Ассеты
интегрирует UI-таск `skill_tree_v2_ui_redesign` (`scripts/ui_screens.gd`). Вся графика — пиксель-арт
через Pixel Lab MCP (`create_ui_asset`/`create_map_object`), прозрачный фон, см.
[[pixellab-mcp-asset-gen]] и [[asset-generator-skill]].

## Образ (арт-дирекция)

- Тёмное «созвездие/гримуар» как полотно дерева пассивок ПоЕ, но компактнее и теплее (Dark
  Fantasy, тёмное дерево, кованый металл, золотой орнамент, пергамент/звёздная пыль).
- Высокое разрешение (вьюпорт 2560x1440), чёткие nearest-спрайты, читаемо.
- Единый язык с принятыми UI-паками (codex SCRUM-684, level-up SCRUM-682/683): те же шрифты,
  кнопки, палитра. Контент строго в безопасной зоне фрейма (frame-content-safe-area-rule).

## Обязательное правило размеров UI-ассетов

- Нельзя генерировать элементы интерфейса "примерно", а затем растягивать или сжимать их под слот.
- Все final Pixel Lab UI-ассеты дерева умений должны быть сгенерированы сразу в правильном aspect ratio и целевом размере: предпочтительно отдельные target assets/spec для `2560x1440` и `1920x1080`; допустимый fallback — один нативный 2K (`2560x1440`) source package с последующим только пропорциональным downscale до 1080p.
- Запрещён one-axis stretch/squash для фона, рамок, узлов, кнопок, бейджей, иконок, орнамента и коннекторов. Для 9-slice/tileable деталей разрешено адаптировать только плоский/повторяемый центр; углы, борта, декоративные элементы и content zones должны оставаться нативными/пропорциональными.
- Спека art-пака обязана перечислить source size, 1080p target size or scale factor, aspect ratio, margins/content zones и allowed scaling mode для каждого ассета, чтобы UI-таск подключил их без догадок и без деформации.

## Требуемые ассеты

1. **Фон/полотно дерева** — тёмный задник-«созвездие» (тайлящийся или большой), на котором лежит граф.
2. **Узлы (node frames)** — для трёх типов × трёх состояний:
   - типы: `minor` (мелкий), `notable` (средний, орнамент), `keystone` (крупный, акцент);
   - состояния: выделен (allocated, золото/зелёное свечение), доступен (allocatable, мягкая подсветка),
     заблокирован (locked, тусклый);
   - (опц.) пустые «гнёзда» под иконку эффекта, чтобы UI клал поверх иконку атрибута.
3. **Коннекторы (рёбра)** — сегмент линии/«цепи» между узлами: вариант «потушен» (locked) и
   «активен» (соединяет выделенные/доступные). Желательно тайлящийся/растягиваемый сегмент.
4. **Маркер точки входа класса** — свечение/печать, подсвечивающее стартовый узел текущего класса.
5. **Бейдж метаочков** + рамка шапки (заголовок «Древо умений», счётчик «X / 100», глобальный уровень).
6. **Кнопки**: Назад, инфо (?), зум +/−, «Сбросить дерево» — в стиле принятых UI-кнопок (или
   переиспользовать существующие, если подходят — тогда указать какие, новый арт не плодить).

## Design Result

Все ассеты — пиксель-арт, прозрачный фон, единый Dark Fantasy / D&D язык (тёмный металл, золото,
бронза, синяя/пурпурная стеклянная вставка). Сгенерированы через Pixel Lab MCP

### Native-size spec (правило размеров UI-ассетов — обязательная таблица)

Все ассеты — **нативный 2K source package** (рассчитаны под вьюпорт `2560×1440`). 1080p target =
**пропорциональный downscale ×0.75** (`1920/2560 = 1080/1440 = 0.75`) — единый коэффициент по обеим
осям, без one-axis stretch/squash. UI-таск (SCRUM-698) подключает source как есть для 2K и масштабирует
×0.75 для 1080p (или включает `TextureRect.expand_mode = keep_aspect` с тем же коэффициентом).

### Узлы (3 типа × 3 состояния) — фиксированные эмблемы (НЕ 9-slice)
Центр каждого узла — тёмное «гнездо»; UI кладёт иконку атрибута поверх по центру (см. рекомендованную
зону иконки = квадрат ~58% от стороны, центрирован).

| Тип | allocated (выделен) | available (доступен) | locked (заблокирован) | Размер | Зона иконки |
|---|---|---|---|---|---|
| **minor** | `node_state_purchased.png` *(v1, reuse)* | `node_state_available.png` *(v1, reuse)* | `node_state_locked.png` *(v1, reuse)* | 148×148 | центр ~86×86 |
| **notable** | `node_notable_allocated.png` | `node_notable_available.png` | `node_notable_locked.png` | 192×192 | центр ~110×110 |
| **keystone** | `node_keystone_allocated.png` | `node_keystone_available.png` | `node_keystone_locked.png` | 256×256 | центр ~130×130 |

- minor = существующие v1-октагоны (золотой starburst / зелёный чек / тусклый) — НЕ плодил дубли, переиспользуем как мелкий тип.
- notable = 8-конечная октагональная рама с золотыми гем-акцентами, тёплое золото (allocated) / бледная подсветка (available) / тёмное железо (locked).
- keystone = крупная круглая руническая рама с самоцветом, золотое свечение / бледная подсветка / тусклое железо.
- Состояния можно также эмулировать модуляцией (modulate) одного спрайта, но отдельные арт-стейты читаемее.
