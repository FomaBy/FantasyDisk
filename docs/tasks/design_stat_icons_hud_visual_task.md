# Задача Для Design-Агента: Иконки Характеристик И Красивый In-Game HUD

Статус: done
Дата: 2026-06-10

## Autonomy / Approval

Пользователь заранее одобрил все изменения в рамках этой задачи. Не спрашивай подтверждение: нарисуй ассеты, подключи их где нужно для preview/проверки, обнови документацию. Спрашивать нужно только при реальном блокере, обязательной sandbox/security эскалации или потенциально разрушительном действии вне scope.

## Контекст

В игре есть много характеристик, производных атрибутов и UI-состояний, где игрок видит параметры персонажа: меню по Escape, level-up rewards, описание статов и другие элементы интерфейса.

Сейчас визуальная подача характеристик недостаточно красивая и цельная. Нужно нарисовать набор красивых иконок для всех характеристик и атрибутов персонажа, а также новый красивый боевой HUD в стиле FantasyDisk.

Важно: текущий боевой HUD должен быть минимальным. В бою на основном экране не нужно показывать весь список характеристик и атрибутов. Нужны только:

- HP;
- Опыт;
- Деньги.

Все подробные характеристики должны оставаться в специальных UI-местах: Escape stats menu, level-up, tooltips, rewards.

## Главная Цель

Создать красивый UI asset pack:

1. Иконки для всех базовых характеристик.

3. Красивый in-game HUD только для HP, опыта и денег.
4. Визуальные состояния/варианты, которые backend сможет использовать в Escape menu, level-up и игровом HUD.

## HUD Во Время Игры

Нарисовать красивый in-game HUD в стиле игры, но без лишней информации.

На боевом экране должны быть только:

- HP;
- Опыт;
- Деньги.

Требования:

- HP должен быть красным/жизненным и очень читаемым.
- XP должен быть отдельной красивой полосой или индикатором прогресса.
- Деньги должны иметь понятную иконку монеты/валюты.
- HUD должен быть компактным, но не мелким.
- HUD должен работать на `1600x900`, `1920x1080`, `2560x1440`.
- HUD не должен перекрывать персонажа, врагов, projectiles и level-up choices.
- UI должен ощущаться как часть FantasyDisk, а не default Godot controls.

## Использование Иконок

Подготовить ассеты так, чтобы backend мог использовать их:

- в Escape stats menu;
- в level-up reward cards;
- в tooltips характеристик;
- в shop/reward descriptions, если там показывается стат;
- в in-game HUD для HP/XP/money.

## Стиль

Стиль должен быть:

- stylized fantasy cartoon;
- чистый, читаемый, красивый;
- достаточно детальный, чтобы не выглядеть placeholder;
- без визуального шума;
- совместимый с текущими спрайтами персонажей и монстров;
- единый для всех иконок.

Нельзя:

- использовать generic emoji;
- использовать default UI icons;
- делать все иконки одинаковыми с перекраской;
- делать слишком мелкие детали, которые не читаются в игре;
- копировать чужие ассеты.

## Формат Ассетов

Рекомендуемая структура:

```text
assets/sprites/ui/icons/stats/
assets/sprites/ui/icons/derived/
assets/sprites/ui/hud/
```

Рекомендуемые размеры:

- stat icons: `64x64`;
- derived icons: `64x64`;
- HUD icons: `64x64` или `96x96`, если нужно для качества;
- прозрачный фон;
- PNG.

Если нужен другой размер для качества, выбери лучший вариант и зафиксируй в документации.

## Имена Файлов

Файлы должны иметь стабильные имена по ID:

```text
stat_strength.png
stat_agility.png
stat_intelligence.png
...
attr_damage.png
attr_magic_damage.png
...
hud_hp.png
hud_xp.png
hud_money.png
```

## Acceptance Criteria

Задача готова, если:

- есть иконки для всех 8 базовых характеристик;
- есть иконки для всех производных атрибутов;
- есть красивые HUD-ассеты для HP, XP и денег;
- стиль единый и подходит FantasyDisk;
- иконки читаются в маленьком и среднем размере;
- нет default/emoji/placeholder иконок;
- файлы лежат в понятной структуре;
- backend может однозначно подключить каждый asset по ID;
- документация обновлена.
