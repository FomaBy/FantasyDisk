## Source Request

Прямая директива пользователя (чат, 2026-07-08, вторая волна фидбека к SCRUM-879):
1. Настройки: табы «Экран/Звук/Управление» — в стиле кнопки «Назад», текст и
   иконка должны помещаться внутри.
2. Настройки: блок элементов сдвинуть правее — колонка настроек по центру
   экрана, выравнивание элементов внутри по левому краю.
3. Hover-эффект кнопок немного ярче и заметнее (не сильно).
4. Выбор героя: «Выбрать» — под превью персонажа и возвышением, за основу
   кнопка главного меню (шире).
5. Выбор героя: «Назад» в едином стиле, поднять выше; фрейм описания на одном
   уровне с превью персонажа; фрейм описания чуть меньше по высоте.
6. Карусель героев: явно показывать, сколько ещё героев доступно кроме
   видимых четырёх.
