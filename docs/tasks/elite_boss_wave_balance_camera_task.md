# Задача для агента: элитки, боссы, волны, плотность монстров, камера и масштаб игрока

Autonomy / Approval:
- Пользователь заранее одобрил все изменения в рамках этой задачи.
- Не спрашивай подтверждение на реализацию: сделай изменения, обнови тесты, запусти проверки и обнови документацию.
- Спрашивать нужно только при реальном блокере, обязательной sandbox/security эскалации или потенциально разрушительном действии вне scope.

Контекст:
- Проект Godot 4, FantasyDisk.
- Перед началом прочитай:
  - `docs/design/fantasydisk_design_brief.md`
  - `docs/design/gdd_source.md`
  - `docs/design/mechanics_extract.md`
  - `docs/design/FantasyDisk_Design_Document_RU.docx`
- Цель: сделать бои более осмысленными, с редкими, но опасными элитками, двумя разными боссами, более жирными врагами, меньшей хаотичной плотностью и ощущением большой карты.

## Главная цель

Переработать баланс врагов и структуру боев так, чтобы:
- элитки были случайными, редкими и примерно в 10 раз сложнее обычных монстров;
- разные элитки атаковали по-разному и имели уникальные паттерны поведения;
- на boss node появлялся случайный босс: 1 из 2;
- оба босса имели свои уникальные способности, абилки и attack patterns;
- обычные монстры, элитки и боссы стали сильно жирнее по HP;
- монстры стали немного медленнее;
- общее количество монстров уменьшилось, особенно на ранних уровнях;
- количество монстров постепенно увеличивалось с каждой следующей волной;
- игрок мог бегать от монстров, собирать их в кучки и находить проходы;
- монстры не наплывали со всех сторон так, что невозможно пройти мимо;
- карта ощущалась большой;
- камера была дальше от игрока;
- текстура игрока стала меньше на 20-30%, но монстров уменьшать не нужно.

## 1. Элитные монстры

### Требование

Сделать элитных монстров случайными и существенно сложнее обычных.

Элитка должна быть не просто обычным врагом с большим HP, а отдельной угрозой с собственным поведением.

### Сложность элиток

Элитные монстры должны быть примерно в 10 раз сложнее обычных монстров того же типа.

Это не обязательно означает ровно `x10 HP`; сложность может складываться из:
- HP;
- урона;
- защиты;
- особого поведения;
- щита;
- ауры;
- призыва;
- рывков;
- AoE;
- projectile pattern.

Рекомендуемая база:
- HP elite: `обычный HP * 8-12`;
- damage elite: `обычный damage * 1.5-2.5`;
- speed: не выше обычного слишком сильно, чтобы не ломать читаемость;
- награда: лучше, чем за обычный бой.

### Случайность

При генерации elite fight выбирать случайную элитку из пула доступных elite types.

Пример:
- `elite_armored`
- `elite_charger`
- `elite_poison`
- `elite_summoner`

Если есть несколько биомов/карт, в будущем можно фильтровать элиток по биому, но сейчас достаточно общего пула.

## 2. Уникальные паттерны элиток

Добавить минимум 4 типа элитных монстров с разными механиками.

### Elite 1: Бронированный

Роль:
- медленная, очень жирная элитка;
- проверяет DPS игрока;
- заставляет держать дистанцию.

Поведение:
- двигается медленно;
- имеет очень много HP;
- имеет повышенную защиту;
- периодически получает временный щит;
- щит снижает входящий урон или блокирует часть урона.

Паттерн:
- идет на игрока;
- раз в несколько секунд активирует shield;
- при приближении наносит сильный melee hit с delay.

### Elite 2: Рывковый охотник

Роль:
- опасная мобильная элитка;
- заставляет игрока следить за дистанцией.

Поведение:
- двигается медленнее обычного во время подготовки;
- периодически делает dash/charge в сторону игрока;
- перед рывком должен быть telegraph;
- после рывка короткая пауза/восстановление.

Паттерн:
- выбирает направление на игрока;
- показывает warning;
- делает быстрый рывок;
- наносит урон при контакте;
- останавливается на cooldown.

### Elite 3: Ядовитый / проклятый

Роль:
- контролирует область;
- наказывает стояние на месте.

Поведение:
- оставляет toxic/curse zones на земле;
- атаки накладывают DoT;
- может стрелять медленным projectile, который создает лужу.

Паттерн:
- держится на средней дистанции;
- периодически стреляет projectile;
- projectile при попадании или окончании пути оставляет AoE zone;
- зона наносит DoT, если игрок стоит внутри.

### Elite 4: Командир / призыватель

Роль:
- создает дополнительное давление;
- должен быть priority target.

Поведение:
- призывает маленьких мобов пачками;
- может бафать ближайших обычных монстров;
- сам не должен быть слишком быстрым.

Паттерн:
- держится позади толпы;
- каждые несколько секунд призывает 2-4 мелких врага;
- периодически дает aura buff ближайшим монстрам;
- если вокруг слишком много призванных мобов, временно прекращает summon.

## 3. Боссы карты

### Требование

На boss node должен появляться случайный босс: один из двух.

Босс выбирается случайно при входе в boss fight.

Боссы должны отличаться:
- внешне;
- поведением;
- наборами атак;
- сильными и слабыми сторонами.

## 4. Boss 1: Хранитель Разлома

Роль:
- магический босс;
- играет через projectiles, shield, AoE и summon.

Механики:
- много HP;
- периодический shield;
- projectile volley;
- AoE круги/лужи;
- призыв мелких врагов.

Паттерны:
1. `Projectile Volley`
   - босс выпускает несколько projectiles веером;
   - projectiles должны быть читаемыми;
   - между залпами cooldown.

2. `Rift Shield`
   - босс получает щит на несколько секунд;
   - во время щита входящий урон снижен;
   - щит должен иметь визуал.

3. `Rift Zone`
   - под игроком или рядом появляется предупреждение;
   - через короткий delay появляется AoE зона;
   - зона наносит урон, если игрок остался внутри.

4. `Summon Riftlings`
   - босс призывает небольшую пачку мелких врагов;
   - не делать это слишком часто, чтобы не забить экран.

## 5. Boss 2: Пожиратель Диска

Роль:
- физический/хаотичный босс;
- играет через рывки, slam и взрывы.

Механики:
- много HP;
- сильный melee pressure;
- charge attack;
- circular slam;
- explosive projectiles или взрывные зоны.

Паттерны:
1. `Charge`
   - босс показывает направление рывка;
   - делает быстрый рывок;
   - после рывка есть recovery window.

2. `Disk Slam`
   - босс бьет по земле вокруг себя;
   - AoE круг с telegraph;
   - урон только после delay.

3. `Shard Burst`
   - босс выпускает несколько осколков/projectiles вокруг себя;
   - projectiles не должны превращать бой в bullet hell.

4. `Enrage`
   - при низком HP босс немного ускоряет паттерны;
   - не увеличивать плотность до нечитаемого хаоса.

## 6. HP и скорость всех врагов

### Требование

Сделать всех врагов жирнее по HP и немного медленнее.

Применить ко всем категориям:
- обычные монстры;
- элитные монстры;
- боссы.

Рекомендация:
- обычные монстры: HP увеличить в `2-4 раза`;
- жирные монстры: HP увеличить в `3-5 раз`;
- элитки: HP относительно обычных `x8-x12`;
- боссы: HP увеличить так, чтобы бой был заметным финальным encounter, но не затянутым;
- скорость обычных врагов уменьшить примерно на `10-20%`;
- скорость жирных врагов еще ниже;
- скорость быстрых врагов можно уменьшить меньше, чтобы они сохраняли роль.

Важно:
- Не делать врагов настолько медленными, что они перестают быть угрозой.
- Не делать HP настолько высоким, что бой превращается в скучный гринд.
- Настроить ощущения через playtest.

## 7. Количество монстров и волны

### Проблема

Сейчас монстров может быть слишком много и они могут наплывать со всех сторон без возможности пройти мимо, особенно на первых уровнях.

### Требование

Уменьшить количество монстров в начале игры и сделать рост количества постепенным.

Игрок должен:
- иметь пространство для маневра;
- иметь возможность пробегать между группами;
- собирать монстров в кучки;
- не быть сразу запертым со всех сторон;
- особенно на первых уровнях.

### Wave scaling

Добавить увеличение количества монстров в каждой следующей волне.

Пример:
- wave 1: мало врагов, простые melee;
- wave 2: чуть больше врагов;
- wave 3: появляются пачки мелких;
- wave 4: добавляется shooter или bruiser;
- поздние waves: больше плотность, но все еще с проходами;
- elite wave: меньше обычных монстров, но есть elite.

### Active enemy cap

Добавить или настроить лимит активных врагов.

Пример:
- early stage: `max_active_enemies = 12-18`;
- mid stage: `20-30`;
- late stage: `35-50`;
- elite fight: обычных врагов меньше, потому что elite уже опасная.

Точные значения подобрать после теста.

### Spawn pacing

Спавн должен быть волнами, а не постоянным бесконечным потоком без пауз.

Рекомендация:
- короткий spawn burst;
- пауза;
- следующий burst;
- увеличение burst size по wave number.

Маленькие монстры могут появляться пачками, но:
- пачки не должны появляться прямо на игроке;
- пачки не должны полностью окружать игрока с первого уровня;
- между пачками нужны интервалы.

## 8. Spawn direction

Монстры не должны постоянно наплывать со всех сторон одновременно.

Требования:
- выбирать 1-2 активные стороны для конкретной волны;
- иногда менять стороны между волнами;
- не спавнить врагов так, чтобы игрок сразу был закрыт со всех направлений;
- на ранних уровнях избегать полного окружения.

Пример:
- wave 1: враги приходят справа и сверху;
- wave 2: враги приходят слева;
- wave 3: пачки снизу и сверху;
- boss/elite fights могут иметь отдельные правила.

## 9. Камера и ощущение большой карты

### Требование

Увеличить зум камеры так, чтобы карта чувствовалась большой.

Здесь под "увеличить зум камеры" имеется в виду показать больше карты вокруг игрока, то есть камера должна быть дальше от персонажа.

Требования:
- игрок должен видеть больше пространства вокруг;
- движение и spawn должны ощущаться просторнее;
- карта должна чувствоваться большой;
- границы карты не должны ломаться;
- камера не должна выходить за пределы карты.

Если используется `Camera2D.zoom`:
- в Godot меньшее значение zoom обычно показывает больше мира;
- подобрать значение вручную.

Acceptance:
- на 1600x900 и 2K видно достаточно пространства;
- игрок может планировать маршрут между группами врагов;
- монстры не появляются внезапно вплотную из-за узкого обзора.

## 10. Уменьшить текстуру персонажа

### Требование

Уменьшить только главного персонажа, не монстров.

Размер персонажа должен быть меньше на `20-30%`.

Требования:
- уменьшить визуальную текстуру игрока;
- collision/hurtbox привести к новому размеру;
- не уменьшать монстров вместе с игроком;
- weapon socket проверить после scale;
- атаки игрока и hit visuals не должны ломаться;
- UI/иконки персонажа не обязательно уменьшать, только игровой sprite на карте.

Важно:
- Если игрок станет меньше, проверить, что он все еще читается на карте.
- Камера будет показывать больше пространства, поэтому персонаж не должен стать совсем микроскопическим.

## 11. Баланс ощущений

Итоговый бой должен ощущаться так:
- врагов меньше, но они заметно жирнее;
- игрок может маневрировать;
- можно собирать врагов в кучки;
- нельзя просто стоять на месте;
- на ранних уровнях есть пространство для ошибок;
- на поздних волнах становится плотнее;
- элитки редкие, но страшные;
- боссы уникальные и запоминающиеся;
- карта ощущается большой.

## 12. Технические требования

Желательно сделать data-driven настройки:

```gdscript
const ENEMY_BALANCE := {
    "melee": {
        "hp_multiplier": 3.0,
        "speed_multiplier": 0.85
    },
    "shooter": {
        "hp_multiplier": 2.5,
        "speed_multiplier": 0.8
    },
    "bruiser": {
        "hp_multiplier": 4.0,
        "speed_multiplier": 0.75
    }
}
```

Для волн:

```gdscript
const WAVE_SETTINGS := {
    "base_spawn_count": 4,
    "spawn_count_per_wave": 2,
    "base_active_cap": 14,
    "active_cap_per_wave": 4
}
```

Для elite:

```gdscript
const ELITE_TYPES := [
    "armored",
    "charger",
    "poison",
    "commander"
]
```

Для boss:

```gdscript
const BOSS_POOL := [
    "rift_warden",
    "disk_devourer"
]
```

Не хардкодить все в одном огромном методе, если уже есть конфиги/ресурсы.

## 13. Тесты

Добавить или обновить проверки:
- elite fight выбирает случайный elite type;
- elite enemy имеет повышенный HP и уникальный behavior flag;
- boss fight выбирает 1 из 2 boss types;
- оба boss type могут загрузиться без ошибок;
- enemy HP multiplier применяется;
- enemy speed multiplier применяется;
- active enemy cap работает;
- количество врагов растет по wave number;
- player visual scale уменьшен;
- camera показывает больше карты и не выходит за bounds;
- smoke test проходит.

## 14. Acceptance Criteria

Готово, если:
- элитки выбираются случайно;
- элитки примерно в 10 раз опаснее обычных монстров;
- у разных элиток разные attack patterns;
- есть минимум 4 elite behavior types;
- boss node выбирает случайного босса 1 из 2;
- оба босса имеют уникальные способности;
- обычные монстры стали сильно жирнее по HP;
- элитки и боссы тоже стали жирнее;
- монстры немного замедлены;
- общее количество монстров уменьшено;
- количество монстров растет с каждой следующей волной;
- на первых уровнях игрок не зажимается со всех сторон;
- есть пространство, чтобы бегать, обходить и собирать монстров в кучки;
- spawn pacing не создает постоянный нечитаемый поток;
- камера показывает больше карты;
- карта ощущается большой;
- текстура игрока на карте уменьшена на 20-30%;
- монстры не уменьшены вместе с игроком;
- collision/hurtbox игрока проверены после уменьшения;
- smoke test проходит.
