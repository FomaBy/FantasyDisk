## Scope

Заменить экран дерева v3 на «Атлас героев» (§7):

1. Один экран, две вкладки: Созвездие (по умолчанию) / Гильдия.
2. Созвездие выбранного класса целиком на экране, без пан/зума: фон-небо,
   силуэт-линии, сокеты по типам, состояния (куплен=золотая звезда,
   доступен=пульс, недоступен=тусклый, скрыт=туман «?», keystone
   активный=сапфировое сияние / купленный-неактивный=тлеет).
3. Лента классов слева: 17 медальонов-портретов, скролл, прогресс x/N и бейдж
   непотраченных эмблем на медальоне; переключение класса — 1 клик.
4. Панель узла справа: титул, тип, описание С ЧИСЛАМИ, цена, «Вложить
   эмблему»; keystone — переключатель «Активна»; скрытая — условие и прогресс.
5. Шапка: эмблемы выбранного класса + звёздная пыль + вкладка «Гильдия»;
   низ: «Респек — бесплатно» + легенда.
6. Церемонии: вспышка покупки, загорание линий, рассеивание тумана скрытой
   звезды (0.6с, скип кликом).
7. Геймпад/клавиатура: фокус по adj-соседям, Tab — вкладки.
8. Контент строго в safe-area рам (правило проекта); все тексты русские.
