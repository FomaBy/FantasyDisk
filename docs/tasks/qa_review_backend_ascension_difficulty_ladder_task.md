## Autonomy / Approval
Пользователь заранее одобрил QA-проверку всех in-scope изменений. QA не чинит
баги сам: найденные дефекты оформлять отдельными `bug_*.md` задачами на доске.

## Что Проверить
- Все acceptance criteria исходной задачи про 10 кумулятивных уровней возвышения.
- Уровень 0 не меняет параметры забега.
- Уровень N включает все модификаторы 1..N.
- Разблокировка уровня N+1 работает после победы финального босса и хранится по
  персонажу, а не глобально.
- Старые ascension-баффы перевязаны в мета-награду и применяются как постоянный
  reward track.
- Селектор возвышения в выборе героя не дает выбрать закрытый уровень.
- HUD-индикатор и Codex-раздел показывают активные модификаторы.
- Документация и CHANGELOG обновлены.

## Ожидаемые Проверки
- Прочитать исходный task-файл и связанные изменения.
- Прогнать тесты, указанные исходной задачей.
- Прогнать обязательные smoke/regression проверки по `docs/process/qa_protocol.md`.
- Проверить минимум 3 edge cases: level 0, максимальный открытый уровень, победа
  финального босса повторно на уже открытом уровне.

## Acceptance Criteria
- [ ] Все пункты исходной задачи проверены фактически.
- [ ] Smoke/regression проверки зеленые или оформлены bug tasks.
- [ ] В исходный task-файл добавлен `## QA-Вердикт` по протоколу.
- [ ] Board обновлена пометкой `QA: passed` или `QA: failed`.
