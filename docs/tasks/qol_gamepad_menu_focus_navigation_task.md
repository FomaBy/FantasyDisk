## Требования
Для КАЖДОГО мета-экрана и попапа вне забега обеспечить полное управление
только со стрелок/D-pad/левого стика + Enter/A + Esc/B:
1. Экраны: главное меню `_show_main_menu()` (~617), диалог выхода
   `_show_quit_confirmation_dialog()` (~781), диалог продолжения забега
   `_show_continue_run_dialog()` (~916), выбор героя `_build_character_select_v4()`
   (карусель, возвышение +/-, старт, назад), выбор оружия `_show_weapon_select()`
   (~4712), стартовый бун `_show_start_boon_select()` (~4829), магазин атрибутов
   `_show_attribute_shop()` (~2147), дерево умений `_show_skill_tree_screen()`
   (~2376), патч-ноуты `_show_patch_notes_screen()` (~2794), кодекс
   `_show_codex_screen()`/`_show_codex_section()` (~2871/2982, все 6 секций),
   настройки `_show_settings_menu()` (~3829, все 3 вкладки — сами контролы:
   слайдеры, OptionButton, CheckBox, кнопки ребинда клавиатуры).
2. На каждом экране: при открытии `grab_focus` на первый логичный элемент;
   `focus_neighbor_*`/`focus_next/previous` покрывают ВСЕ интерактивные элементы
   (ни одного недостижимого с геймпада); фокус не «проваливается» на скрытые
   элементы; после закрытия попапа фокус возвращается на вызвавший элемент.
3. `ui_cancel` (Esc/B) везде = «Назад»/закрыть попап (то же действие, что кнопка
   Back экрана). В попапах фокус ограничен попапом (не убегает под оверлей).
4. Вкладки настроек и секции кодекса переключаются с геймпада: LB/RB
   (`JOY_BUTTON_LEFT_SHOULDER(9)`/`RIGHT_SHOULDER(10)`) — обрабатывать локально
   на экране (gui input/подписка), не глобальным экшеном.
5. Слайдеры (громкость): фокус + ui_left/ui_right меняют значение (HSlider в
   Godot делает это из коробки при FOCUS_ALL — проверить focus_mode).
6. Скроллящиеся списки (кодекс, патч-ноуты, дерево умений, магазин атрибутов):
   при переводе фокуса элемент прокручивается в видимую область
   (`ScrollContainer.ensure_control_visible`); в длинных read-only списках
   ui_up/down скроллит контент.
7. Видимость фокуса: у фокусируемых контролов различимый focus-стиль (рамка/
   подсветка существующей темы; НЕ жёлтая — курс «без жёлтых рамок», см.
   docs/tasks/yellow_frames_audit_redesign_task.md). Если в теме focus-стиль
   отсутствует — добавить единый сдержанный (светлая обводка в стиле UI-кита).
8. Мышь продолжает работать везде как раньше (гибридный ввод).
