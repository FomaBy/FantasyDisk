## Контекст

PM: «все жёлтые рамки, которые у нас есть, нужно перерисовывать; начали с HUD».
В SCRUM-806 (reopen) боевой HUD уже переведён на новый стиль: жёлтая рамка таймера
заменена тёмной кожаной подложкой с тонкой латунной линией
(`assets/sprites/ui/hud/combat_hud_v2/ui_hud_v2_cluster_bg.png`), бейдж возвышения
с жёлтым уголком заменён голым рядом пиксель-эмблем. Это принятая арт-дирекция:
**вместо ярко-жёлтых рамок — тёмная кожа + тонкая латунь, либо вовсе без рамки.**

## Что сделать (этот тикет — только аудит и план, не перерисовка)

1. Пройтись по всем экранам (main menu, hero/weapon select, shop, codex, skill tree,
   level-up, reward/event/rest/upgrade economy, settings, results, pause) и собрать
   список ЖЁЛТЫХ/ЗОЛОТЫХ рамок: путь текстуры, экраны/ноды, где используется
   (grep по `ui_frame_*`, `frames/overhaul_2k`, `minimal_metal`, стилевым хелперам).
2. Для каждой: решение — (а) заменить на кожаную подложку в стиле combat_hud_v2,
   (б) убрать рамку совсем, (в) оставить (обосновать, напр. интерактивный фокус).
3. Приложить скрин-капчи «до» по каждому экрану (есть capture-тулзы в tools/).
4. Оценить объём и нарезать волну задач по экранам (отдельные тикеты с меткой foma,
   ссылкой на этот аудит и арт-дирекцией из SCRUM-806), сгруппировав по 9-slice
   совместимости ассетов.
