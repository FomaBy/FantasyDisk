# Animation and content handoff

Give the worker one assigned `FAN-*` issue with exact source/runtime asset
scope. It must verify owner and locks, load the PixelLab animation/integration
skill, record source IDs and paths, integrate only task-owned assets, run
focused animation/runtime checks, push the exact candidate, report evidence and
cleanup, and trigger PM once. The worker does not self-select another asset pack
or issue.
