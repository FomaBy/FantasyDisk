# Developer handoff

Give the worker one assigned `FAN-*` issue. It must verify owner, acceptance
criteria, dependencies, locks, and overlap; read repo `AGENTS.md` plus the
narrow code/balance skill; implement only the owned scope; use
`tools/godot_gate.py` and the risk-appropriate quality gate; commit and push the
candidate; report exact SHA, checks, docs, risk, and cleanup; then trigger PM
once. The worker does not choose QA or another task.
